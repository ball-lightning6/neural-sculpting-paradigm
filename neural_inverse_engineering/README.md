# 神经逆向工程 (Neural Inverse Engineering)

## 项目简介 (Project Overview)

本项目旨在探索一个深刻的科学计算问题：**神经网络能否通过观察输入输出的变换，反向推导出背后的生成规则（源代码）？** 这被称为“神经逆向工程”或“规则归纳”。

在这个任务中，最大的挑战是**歧义性（Ambiguity）**。即对于有限的观测数据，可能存在多种不同的规则组合都能产生完全相同的结果。例如，在有限位宽下，“左移31位”和“右移1位”可能是等价的。

为了攻克这一难题，我们探索了两条截然不同的技术路线：

1.  **Path 1: 神经归纳器 (Neural Inducer)**
    *   **核心理念**：**数据预处理**。在数据生成阶段就通过数学方法（指纹去重）消灭所有歧义。
    *   **特点**：构建一个完美的、一一对应的“无歧义数据集”，强迫模型死记硬背规则与行为的映射。
    *   **代表脚本**：`generate_ca_meta_dataset_unique.py`

2.  **Path 2: 神经科学家 (Neural Scientist)**
    *   **核心理念**：**在线主动推理**。允许数据存在歧义，通过引入“观测集”的概念（Set-to-Sequence），让模型像科学家一样，通过阅读大量的实验数据（Observational Data），利用 Transformer 的注意力机制聚合信息，最终锁定唯一的真理。
    *   **特点**：动态数据生成，天然处理不确定性，更接近 AGI 的学习方式。
    *   **代表脚本**：`train_neural_scientist_transformer.py`

## 脚本说明 (Script Documentation)

### 1. **train_neural_scientist_transformer.py** (核心)

- **用途:** **Path 2 的集大成者**。实现了一个基于 Transformer 的完整“神经科学家”代理。
- **逻辑:** 
    1. **动态环境 (Environment)**: 在训练过程中实时随机生成规则组合（如 "Rule 110 + Shift + NOT"）。
    2. **观测 (Observation)**: 对每组规则，随机生成 $N$ 个（例如 24~48 个）输入输出对作为证据。
    3. **观察者 (Observer)**: 使用 MLP 独立编码每一个观测样本。
    4. **聚合器 (Aggregator)**: 使用 Transformer Encoder 在所有观测样本间进行交互，提取共性的“物理定律”。
    5. **决策者 (Decider)**: 解码出最终的规则序列。
- **I/O格式:**
    - 输入: [Batch, N_Obs, 60] (30位Input + 30位Output)。
    - 输出: [Batch, Rule_Bits] (预测的规则序列编码)。
- **主要参数:** `MIN_OBSERVE`, `MAX_OBSERVE` (观测样本数), `RULE_LAYERS` (规则深度)。

### 2. **analyze_rule_equivalence.py** (通用工具)

- **用途:** **规则等价性分析理论工具**。独立于任何模型，用于从数学上分析规则系统的歧义性程度。
- **逻辑:** 
    1. 遍历所有可能的规则组合（例如 $8^4 = 4096$ 种）。
    2. 对每种组合，使用一组固定的随机探针（Probes）计算其输出。
    3. 生成该规则的“行为指纹”（Fingerprint）。
    4. 统计有多少种规则拥有完全相同的指纹，从而计算由歧义导致的理论上限。
- **价值:** 它提供了 Ground Truth，告诉我们模型预测错误是因为模型笨，还是因为数学上无法区分。

### 3. **analyze_ca_inverse_ambiguity.py** (CA特定工具)

- **用途:** **元胞自动机逆向工程歧义性分析器**。
- **逻辑:** 
    - 专注于 1D 元胞自动机任务。
    - 使用**蒙特卡洛模拟** (Monte Carlo Simulation) 而非穷举。
    - 高效估算对于一个随机初始状态，其逆向推理（根据输出推断规则）的歧义概率。
    - 使用极致优化的位运算加速 (Speed: ~50k iter/s)。
- **输出:** 给出逆向工程任务中出现歧义的概率估计值（例如 P ≈ 9.53e-7）。

### 4. **generate_ca_meta_dataset_unique.py**

- **用途:** **Path 1 的数据生成器**。生成经过严格去重的、无歧义的元学习数据集。
- **逻辑:** 
    1. 预先计算所有规则组合的指纹（同上）。
    2. 发现冲突时（Rule A 和 Rule B 指纹相同），**只保留一个**作为代表，强制删除其他等价规则。
    3. 生成的数据集保证对于任何 Input/Output 行为，只有唯一正确的 Label。
- **I/O格式:** JSONL 格式，包含 `input` (初始状态), `output` (演化状态), `rule_and_layer_label` (规则标签)。

### 5. **generate_ca_meta_dataset_info_complete.py**

- **用途:** Path 1 的早期探索。尝试在**单样本**层面解决歧义。
- **逻辑:** 在生成样本时，强制检查该样本是否包含了所有可能的局部模式（例如覆盖所有 000-111 的子串）。只有“信息完备”的样本才会被保留。
- **局限:** 对于复杂规则，单样本很难做到真正的信息完备。

### 6. **generate_rule_composition_dataset.py**

- **用途:** Path 2 的静态数据版本。生成多层规则组合的训练数据。
- **逻辑:** 随机选择 $L$ 层规则（由 `NUM_LAYERS` 控制），串行执行，生成输入输出对。与 `Untitled55` 不同的是，它是离线生成文件，且通常用于简单的 MLP 训练（将多个规则的复合视为一个黑箱函数）。
- **主要参数:** `NUM_LAYERS`, `RULE_BITS`。
