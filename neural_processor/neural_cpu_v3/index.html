核心定义

网络实际学了什么

这不是把整台计算机放进一个网络。神经网络负责 32 条指令语义对应的状态变换；程序本身仍以机器码形式，由精确的外部运行时取指执行。

输入 · 51 bit

一条 16-bit 指令、3 bit 标志位（ZF、GF、CF）与 4 个 8-bit 寄存器 R0–R3。

神经核心 · MLP

51 → 1024 × 3 → 39。三个 1024 宽线性隐藏层，GELU 与 LayerNorm，dropout 0，共 2,198,567 个参数。

输出 · 39 bit

下一时刻的标志位与寄存器，以及 4 个控制信号：memory_read、memory_write、branch_taken、halt。

保持精确的外部状态：16-bit PC、取指逻辑、64 KiB uint8 RAM、地址访问与调度。LOAD 拆成两步：神经核心发出 memory_read，RAM 返回字节后由同一核心执行内部 MOVI。

相邻训练阶段的其他大样本测试曾得到 10.737B 操作 0 error 与 32.212B 操作 3 errors。这些结果来自相近但不同的 checkpoint，只能谨慎表述为：随机单步操作错误率处于每约 1010 次操作一个错误的数量级。

该数量级估计来自有限罕见事件，不是硬件级可靠性保证，也不能写成“严格保证 100 亿次不出错”。

演进

从 legacy 到 v3

核心思想没有根本变化——神经网络学习固定 ISA 的状态转移函数。v3 的差别主要在工程与验证口径：

  • 网络更小，ISA 与 CPU / 外部系统边界更明确；
  • 训练与验证脚本自包含；
  • 加入错误诊断、hard replay、动态采样与结构状态审计；
  • 训练时间明显更长（RTX 5090 约 2.5 天）；
  • 精度从概念验证提升到可支撑数十亿步真实程序轨迹与并行渲染审计。

早期方案文档： legacy README_zh.md · legacy README_en.md

一种解释

它在研究谱系中的位置

与其说它在做通常意义上的统计拟合，不如说训练过程正在根据输入输出样例，把一组程序电路“编译”进神经网络权重。

这是对现象的操作性解释，不是声称 SGD 就是传统编译器，也不是已被严格证明的等价定理。

与 Neural Turing Machine、Neural GPU 或手工构造权重的工作相比，本项目的权重全部由随机输入输出监督训练得到，程序仍以真实机器码运行在精确的 PC 与 RAM 之上，并报告长轨迹逐操作审计。
