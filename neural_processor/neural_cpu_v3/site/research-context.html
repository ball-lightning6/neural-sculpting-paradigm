研究谱系

研究位置：与既有神经计算工作的关系

神经网络承担计算并不是一个单一路线：有的工作学习可微内存与控制器，有的学习算法变换或程序调用，也有的把已知程序直接编译进权重。Neural CPU v3 关注的是另一项更窄、但可直接审计的问题：固定 ISA 的单步状态转移，能否只靠输入输出监督训练到足以长期执行真实机器码程序的精度。

神经计算机研究谱系：简短导览

下面的导览不是按“谁更像完整计算机”排名，而是把几个经常被混在一起的问题拆开：学习内存与控制、从样例学习算法、从执行轨迹学习程序、把程序编译成权重，以及把训练得到的状态转移核心接入精确运行时。

  • Neural Turing Machine 与 Differentiable Neural Computer：可微外部记忆，面向任务学习。
  • Neural GPU：用循环卷积结构学习算法变换。
  • Neural Programmer-Interpreter 等程序解释工作：程序 / 任务表征与执行轨迹学习。
  • Tracr 一类编译路线：把人类可读程序直接编译为具体 Transformer 权重，权重结构因此是已知的。
  • Percepta Transformer VM：把 WebAssembly 解释器解析为计算图，解析构造 Transformer 权重，并以 attention 管理机器状态与历史。
  • Neural CPU v3：保留精确 PC、RAM 与调度，让一个普通 MLP 只学习 16-bit ISA 的离散状态转移。
  • 本项目的 legacy 版本采用同一核心思想；v3 主要改进网络规模、训练分布、可靠性诊断和可复现工程。
一种解释

一种操作性解释

与其说它在做通常意义上的统计拟合，不如说训练过程正在根据输入输出样例，把一组程序电路“编译”进神经网络权重。

这是对现象的操作性解释，不是声称 SGD 就是传统编译器，也不是已被严格证明的等价定理。

权重来源

训练权重与手工构造权重的区别

本项目的全部核心权重来自随机输入输出监督训练：训练信号只包含（指令, 状态）→ 下一状态的样例，没有人把逻辑门、真值表或程序手工写进权重。学习对象是固定 ISA 的状态转移函数，程序本身仍以机器码形式运行。

这与 Tracr 和 Percepta Transformer VM 一类“已知程序 / 解释器 → 确定权重”的解析构造路线回答不同问题。Percepta 将 WASM 解释器写成计算图，用 MILP 把图节点排布进 Transformer 层，并构造对应权重；它还把 attention 用作历史状态寻址，以二维凸包 KV cache 加速近 hardmax 查找。本项目没有修改 attention，因为执行核心是 MLP，也不知道 SGD 选择了怎样的内部电路，只能通过独立真值生成器、结构化难例和长轨迹逐操作审计建立可靠性证据。

定位

本项目可辩护的位置与限制

  • 权重由随机输入输出监督训练得到，不是把逻辑门或程序手工烧进权重。
  • 学习对象是固定 ISA 的状态转移函数；程序本身仍然作为机器码运行。
  • 使用普通、精确的 RAM 与 PC，避免把所有系统组件都神经化。
  • 重点不是提出新的可微内存，而是把规则映射训练到足以运行真实程序和数十亿 lane-op demo 的精度。
  • 多个 demo 共享同一个 CPU 权重，不为每个任务重新训练 CPU。
  • 项目的主要价值既包括工程展示，也包括为更广泛研究提供直观证据：神经网络可以把离散、精确的变换学习到什么程度。

这不等于通用计算机的所有组件都已端到端学习，也不等于达到真实硬件 CPU 的可靠性。

仓库主题

与本仓库主题的关系

本仓库的主题是探索神经网络能否学习离散、精确的规则变换。Neural CPU v3 为这个问题提供直观证据：固定 ISA 的状态转移函数可以被训练到支撑数十亿步真实程序轨迹和并行渲染审计的精度。

因此这个项目首先是一块直观的“广告牌”，而不是对整个研究纲领的单独证明：同一套训练权重既能串行运行程序，也能作为大量独立 lane 的并行执行器。它把“神经网络究竟能把规则学得多精确”变成可直接观看、也可逐操作核验的问题。

早期版本

legacy 入口
