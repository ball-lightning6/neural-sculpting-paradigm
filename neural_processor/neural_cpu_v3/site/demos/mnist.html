MNIST 量化 CNN 推理

QAT、精确整数与 Neural CPU 三条路径对测试图像 IMAGE_INDEX = 0（标签 7）均预测 7；神经路径消耗 596,807,228 个 lane-op，0 result / flag / control error。

本页涉及两个不同的网络，不要混淆：MNIST CNN 是被推理的模型——一个经 QAT 量化训练、测试准确率 99.59% 的卷积网络；Neural CPU v3 是执行该量化 CNN 数值程序的处理器。前者决定“算什么”，后者逐条执行“怎么算”。

计算怎样映射到 ISA

CNN 中的常量权重乘法被编译成 NAF/CSD shift-add 序列：每个定点常数被分解为移位与加减构成的 16-bit 指令流，不使用任何外部乘法 LUT。

32-bit 累加、定点缩放、ReLU、max pooling 与最终 argmax 同样被拆成 ISA 操作。一次卷积或全连接输出因此展开成大量互相独立的 lane-op，由同一个神经核心批量执行。

阶段输出形状计算
Input1x28x28MNIST 灰度图，uint8 定点输入
Conv132x28x283x3，1→32，padding 1，ReLU，量化
Conv1b32x14x143x3，32→32，ReLU，2x2 max pool，量化
Conv264x14x143x3，32→64，padding 1，ReLU，量化
Conv2b64x7x73x3，64→64，ReLU，2x2 max pool，量化
FC12563136→256，ReLU，量化
FC210256→10 logits，随后用 CMP 完成 argmax

被推理的 CNN 共 870,634 个参数，在 epoch 24 达到 99.59% QAT 测试准确率。输入采用 scale=255 的 8-bit 表示；权重采用 scale=4096、范围 ±32767；ReLU 后隐藏激活采用 scale=256、范围 0..65535，bias 使用 32-bit 整数。

一次图像推理执行 596,807,228 个 lane-op。外部运行时只负责 tensor 存储、寻址、卷积窗口展开、lane 调度与条件写回；卷积和全连接的数值运算、量化、池化与分类决策均经过 Neural CPU。

由 Neural CPU 执行

  • 常量权重乘法（NAF/CSD shift-add 序列）；
  • 32-bit 累加与定点缩放；
  • ReLU 与 max pooling；
  • 最终 argmax 分类。

由外部运行时承担

  • tensor 存储；
  • 地址生成；
  • 卷积窗口展开；
  • lane 调度；
  • predicated writeback（按条件写回）。

路径 / 模式 含义 Config 开关

运行方法

python scripts/run_neural_cpu_v3_mnist_cnn.py

所有参数位于脚本顶部的 Config，最常改的几项：

参数 默认值 含义
IMAGE_INDEX 0 选择送入 Neural CPU 的 MNIST 测试图像索引。
RUN_INTEGER_TEST_SET True 先在 10,000 张测试图上交叉核对 QAT 与精确整数实现。
RUN_NEURAL True 运行 Neural CPU 前向并逐 lane-op 审计。
STOP_ON_NEURAL_ERROR True 遇到首个神经执行错误即停止。
LANE_CHUNK 131_072 每个 chunk 内按 CSD bit 分组发射的 lane 指令数。

若本地缺少 MNIST 测试文件，脚本会自动从 Config.MNIST_MIRRORS 配置的镜像下载并校验 SHA-256，无需手动准备数据。

限制与不声称的内容

  • lane-op 数与 0 error 对应所选单张图像（默认 IMAGE_INDEX = 0）的神经执行审计，不是全部 10,000 张测试图的神经执行结果。
  • 99.59% 是被推理模型（量化 CNN）的识别准确率，不是 Neural CPU 的错误率；处理器只执行指令状态转移，它并不“认识”数字。
  • 0 error 是本次审计的实测结果，不是“永不出错”的保证；全局单步错误率的口径见可靠性页。 可靠性页 →
