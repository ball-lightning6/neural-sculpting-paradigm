spigot 算法怎样映射到 16-bit ISA

Rabinowitz–Wagon spigot 的完整计算被编译成项目自己的 16-bit 机器指令，而不是用 Python 算出数字再回放。算法的寄存器算术、比较、循环条件、分支与内存控制全部以指令形式执行。

按脚本开头说明，当前汇编实现的 spigot 数组元素为 16 bit，可能溢出的临时累加器 X 为 24 bit。数组状态存放在外部 64 KiB RAM 中，读写由指令流发出的内存控制信号触发。

  1. 1000 位配置使用长度 3333 的工作数组，并先把每个 16-bit 元素初始化为 2。
  2. 每轮从数组尾部向前计算 X = 10A[i] + Q·i、除数 2i−1，再把余数写回 A[i]、商写入 Q；乘法用重复加法，除法用重复减法完成。
  3. 扫完数组后得到下一候选数字，并显式处理暂存的 9 与候选值 10 所触发的跨位进位。
  4. 确认后的十进制数字由指令写入内存映射输出端口 0xFF00，宿主只收集字节，不参与数字计算。

默认 1000 位程序只有 654 条静态机器指令；循环展开为 5,559,684,667 次动态神经操作，并逐步与精确 ISA 真值核对，最终 1000 位全部一致、0 次执行错误。

神经侧

Neural CPU 承担什么

神经核心 · MLP

以下每一步都由同一个训练权重以逐条指令的状态转移完成：

  • 寄存器算术与逻辑：R0–R3 的每一次更新；
  • 比较与标志位：CMP / CMPI 语义与 ZF、GF、CF 更新；
  • 循环条件与分支：branch_taken 及跳转方向；
  • 内存控制：memory_read / memory_write 控制信号（LOAD 拆成两步：先发 memory_read，RAM 返回字节后由同一核心执行内部 MOVI）。
外部侧

外部运行时承担什么

外部精确组件

  • 16-bit PC 与取指逻辑；
  • 64 KiB uint8 RAM 的存储与地址访问；
  • 输出显示：打印当前 pi、位数进度与一致性计数；
  • batch 模式下由精确解释器流式生成真值轨迹，并做 GPU batch 调度。
验证口径

三种模式

同一份汇编程序可以用三种方式运行或审计，区别在于是谁推进状态、以及是否加载神经权重。

模式含义
serial 神经状态按程序依赖顺序自主向前执行，最接近真实单核运行；首次出现差异时可以立即停止。单 lane 完成 1000 位会非常慢，需显式启用。
batch 默认模式。精确解释器先流式生成同一条唯一程序轨迹，再把轨迹上大量相互独立的单步输入组成 GPU batch，由神经核心逐项审计。它不改变程序答案，也不是同时计算多个 pi，而是加速验证一条很长的确定轨迹。
EXACT_ONLY 只运行 reference 逻辑，验证汇编程序本身，不代表神经执行。

三种模式覆盖同一条程序轨迹；batch 与 EXACT_ONLY 只改变验证方式，不改变 pi 的数值。

运行方法

所有可调参数集中在脚本顶部的 Config。在 neural_cpu_v3/ 目录下运行：

python scripts/run_neural_cpu_v3_pi.py
参数默认值说明
TARGET_DECIMAL_DIGITS1000计算的十进制有效数字位数
EXECUTION_MODE"batch""serial" 或 "batch"；默认 batch —— 1000 位约需数十亿次操作
EXACT_ONLYFalse设为 True 时只跑精确参考，不加载神经权重
MAX_NEURAL_OPERATIONSNone神经操作步数上限；None 表示不设上限
TRACE_BATCH / INFERENCE_BATCH262,144每块轨迹长度 / 单次 GPU 前向规模
PRINT_EVERY_DIGITS1每产生多少个数字打印一次进度

相关文件

  • scripts/run_neural_cpu_v3_pi.py — 脚本（自包含，Config 在顶部）
  • weights/neural_cpu_v3_best_balanced_model.pt — 发布权重（Config.MODEL_PATH 默认值）

输出写入 results/pi/（Config.RESULT_DIR）。

边界

限制与不声称的内容

  • 0 error 是对这次最终 demo 审计的陈述，不是对任意未来运行的保证；错误率数量级的口径与证据见可靠性页。 可靠性页 →
  • batch 模式不是同时计算多个 pi，也不是把答案从外部喂给网络：轨迹由精确解释器唯一生成，神经核心逐项接受审计。
  • EXACT_ONLY 的结果不代表神经执行质量。
  • 默认 1000 位是数十亿次操作级别的运行，面向 GPU batch 设计；serial 单 lane 完成它会非常慢。
