3x3 魔方复原视频

303 帧、640x360、24 fps（12.625 秒）的复原动画：逐像素四边形覆盖判定由 Neural CPU 执行，共 7,029,721,682 个 lane-op，0 result / load / store error。

复原序列是预先给定打乱序列（Config.SCRAMBLE）的严格逆序——每一步都是合法魔方动作，但 Neural CPU 没有自己搜索解法，本站也不声称它求解了魔方。它承担的是渲染这段过程所需的逐像素几何判定。

渲染怎样映射到 ISA

每个候选像素的四条边函数决定它属于哪个贴纸面（四边形 edge test）；相机与魔方层旋转、16-bit 坐标投影表读取与 framebuffer store enable 均由 Neural CPU 通过 LOAD/MOVI、ADD/ADC、SUB/SBC 与 RAM 中的 8-bit 乘法表执行。

打乱序列含 15 个动作；每个动作 MOVE_FRAMES = 12 帧，加上动作间暂停与首尾保持帧，合计 303 帧、12.625 秒。预先给定的打乱序列（Config.SCRAMBLE）： R U F' L2 D B' R2 U' F L' D2 B U2 R' F2

由 Neural CPU 执行

  • 相机与魔方层旋转；
  • 16-bit 坐标投影表读取（LOAD）；
  • 逐像素四边形 edge test：每个候选像素的四条边函数；
  • framebuffer store enable。

由外部运行时承担

  • 魔方动作调度（按预给逆序逐帧推进）；
  • framebuffer 存储；
  • MP4 编码。

外部固定功能不决定面覆盖关系，也不计算颜色。

审计模式

模式 含义 Config 开关
pure_flat 渲染 + 审计（默认） Neural CPU 逐像素完成四边形覆盖判定，原生帧缓冲直接编码；审计统计 result、load、store 三类错误，本次均为 0。 RENDER_MODE = "pure_flat"
REFERENCE_ONLY 只检查画面，不加载 Neural CPU。 REFERENCE_ONLY = True

运行方法

python scripts/render_neural_gpu_rubiks_cube_video.py

脚本路径为 scripts/render_neural_gpu_rubiks_cube_video.py，文件名保留历史命名；实际执行核心是 Neural CPU v3，画面由神经核心逐像素判定产生。

所有参数位于脚本顶部的 Config，最常改的几项：

参数 默认值 含义
WIDTH 640 输出帧宽（像素）。
HEIGHT 360 输出帧高（像素）。
FPS 24 视频帧率。
MOVE_FRAMES 12 每个魔方动作占用的帧数。
RENDER_MODE "pure_flat" 默认渲染路径：无光照、阴影、纹理或 OpenCV 填充。
REFERENCE_ONLY False 只检查画面，不加载神经权重。

限制与不声称的内容

  • Neural CPU 没有搜索魔方解法：复原序列是预给打乱序列的严格逆序（见页首注意条）。
  • pure_flat 模式不使用光照、阴影、纹理或 OpenCV polygon rasterizer；画面是覆盖判定的直接结果，不做美化。
  • 视频为原生 640x360 渲染并直接编码，不通过低分辨率 resize 冒充高清。
  • 0 error 是本次渲染审计的实测结果，不是一般性无错误保证；全局口径见可靠性页。 可靠性页 →
