状态转移网络与 16-bit ISA

神经网络负责指令语义对应的状态变换——不是某个演示任务的最终答案。本页给出网络的输入输出边界、它学习的 16-bit 指令集，以及它与外部精确组件的分工。

主结构：51 → 1024 × 3 → 39

51
输入 bit · 16-bit 指令 + 标志位 + 寄存器
→
1024 × 3
线性隐藏层 · GELU + LayerNorm · dropout 0
→
39
输出 bit · 下一状态 + 控制信号

每次调用输入一条 16-bit 指令和当前神经状态，输出下一时刻的寄存器、标志位与控制信号。隐藏结构为 3 个 1024 宽线性层，每层使用 GELU 与 LayerNorm，dropout 为 0；参数量 2,198,567。

02

输入 / 输出 bit 布局

输入 · 51 bit

指令16 bit ZF1 bit GF1 bit CF1 bit R08 bit R18 bit R28 bit R38 bit

51 = 16（指令）+ 3（标志位）+ 32（4 个 8-bit 寄存器）

输出 · 39 bit

ZF′1 bit GF′1 bit CF′1 bit R0′8 bit R1′8 bit R2′8 bit R3′8 bit memory_read1 bit memory_write1 bit branch_taken1 bit halt1 bit

39 = 3（下一标志位）+ 32（下一寄存器）+ 4（控制信号）；′ 表示下一时刻。

03

寄存器、标志位与控制信号

寄存器 R0–R3

4 个 uint8 寄存器，共 32 bit，是神经状态的主体；每次调用的输入与输出都包含它们。

标志位 ZF / GF / CF

3 bit 标志，与寄存器一起构成神经状态；每次状态转移都会给出下一时刻的标志值。

控制信号

memory_read、memory_write、branch_taken、halt 共 4 bit，只出现在输出侧，用来驱动外部精确组件；LOAD 的第一步就是神经核心发出 memory_read。

04

为什么 PC 与 RAM 保持精确

神经状态只有 4 个 uint8 寄存器 R0–R3 与标志位 ZF、GF、CF；16-bit PC 与 64 KiB uint8 RAM 是外部精确状态。PC、取指、地址访问与外部调度都由精确逻辑实现，不经过神经网络。

内存不做成神经网络，原因不是“做不到”：本系统已经有明确的直接寻址。把 RAM 再替换成神经网络，只会增加不必要的不确定性和计算量，也不会帮助回答“指令状态转移能否被训练到极高精度”这个核心问题。

05

四种 16-bit 编码格式

每条指令定长 16 bit，按四种格式编码；opcode 字段占 5 bit，对应 32 个槽位。

RRR  = opcode[5] + rd[2] + ra[2] + rb[2] + reserved[5]
RI8  = opcode[5] + rd[2] + reserved[1] + imm8[8]
BR11 = opcode[5] + signed relative offset[11]
JMPR = opcode[5] + ra[2] + reserved[9]

07

LOAD → RAM → 内部 MOVI

LOAD 分成两步完成，中间由精确的外部 RAM 返回字节：

  1. 神经核心发出 memory_read

    执行 LOAD 时，39 bit 输出中的 memory_read 置位，外部逻辑按地址访问 64 KiB RAM。

  2. 外部 RAM 返回一个字节

    RAM 是精确组件，不经过任何神经计算。

  3. 同一神经核心执行内部 MOVI rd, value

    返回的字节作为 value 写入目标寄存器 rd，LOAD 语义完成。

像素、卷积 MAC、筛选标记、候选几何覆盖测试或一条长轨迹中的独立审计点，可以组成大 batch，一次通过同一个 MLP。

每“在某条 lane 上执行一次 Neural CPU 指令”记为一个 lane-op。这是工作负载层面的 SIMD / SIMT 式并行。

它不是把一条有严格依赖的指令链凭空并行化，也不是一个 CPU 变成许多真实 CPU 核。

RTX 5090 适合执行这种大 batch MLP，因此图形与 CNN demo 的总 lane-op 很大，但可以批量运行。

09

设计限制：网络大小并非最小值

当前的宽度与深度是一个保守但相对随意的选择，不代表最小网络。更小的网络也可能达到相似结果；容量下限尚未被系统地搜索。
