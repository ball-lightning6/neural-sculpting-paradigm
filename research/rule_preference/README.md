# 规则偏好相变实验 (Rule Preference Phase Transition)

## 项目简介

本项目设计了一个精巧的"规则决斗"实验，探究神经网络在面对**歧义数据**时的内部决策机制。实验揭示了神经网络存在一种隐式的"简单性偏好"（Simplicity Bias），并且这种偏好表现出**相变现象**——随着竞争规则间复杂度差距的变化，模型的偏好行为会发生质变。

### 实验设计

#### 核心思想：构造"不可区分"的训练数据

我们设计了两条规则在训练集上产生完全一致的输出，使神经网络无法通过数据本身判断应该学习哪条规则：

**输入构造**：30位输入 = 15位前半段(front) + 15位后半段(back)

**规则 A（CA）**：`output = CA(front)` —— 元胞自动机Rule 110的多层演化
**规则 B（XOR）**：`output = front ^ back` —— 前半段与后半段的逐位异或

**训练集约束**：`front ^ back = CA(front)`

通过逆推构造后半段：`back = front ^ CA(front)`，确保两条规则在训练集上输出完全一致。

#### 测试集设计：打破约束，揭示偏好

测试集中，`front`和`back`独立随机生成，不再满足训练集的约束关系。此时：
- 规则A的预测：`CA(front)`
- 规则B的预测：`front ^ back`
- 两者不再相等，形成"规则竞争"

通过观察模型输出更接近哪条规则，可以判断神经网络"偏好"哪种解释。

### 核心发现：相变现象

通过调整元胞自动机的层数（`CA_LAYERS`），我们观察到一个清晰的**相变过程**：

| CA层数 | XOR准确率 | CA准确率 | 状态描述 |
|--------|----------|----------|----------|
| **1层** | ≈0% | ≈0% | **叠加态** —— 模型没有"选择"任何单一规则，而是维持了一种同时依赖两种规则的"纠缠态" |
| **2层** | ≈5-6% | ≈0% | **开始坍缩** —— 轻微偏向简单规则（XOR），但尚未完全分离 |
| **3层** | **100%** | ≈0% | **完全坍缩** —— 明确选择XOR，规则偏好完全建立 |

### 关键洞察

**1. 简单性偏好的条件性**

神经网络的"奥卡姆剃刀"并非总是生效。只有当竞争规则间的复杂度差距足够大时，模型才会表现出对简单规则的偏好。当复杂度相近时，模型不会做出选择，而是维持一种"混合计算"状态。

**2. 反直觉的"叠加态"**

在1层CA实验中，最反直觉的发现是：**模型对两条规则的OOD测试准确率都接近0%**。这表明神经网络既没有学会CA，也没有学会XOR，而是学到了某种"同时使用两种信息源"但不遵循任何单一规则的方式。

**3. 训练过程的迷惑性**

尽管测试时表现出规则偏好（或缺乏偏好），训练过程中的loss下降始终正常。这说明模型可以完美拟合训练数据，但其内部表示可能在两种解释间"振荡"或"混合"。

### 理论意义

**对神经网络归纳偏置的启示**

这个实验探索了神经网络"简单性偏好"的具体表现方式。实验表明，这种偏好并非绝对，而是具有以下特征：
- **渐进的**：随复杂度差距增大而增强
- **有条件的**：需要足够的"证据积累"才能触发
- **可能导致泛化失败**：在"叠加态"下，模型对新分布的泛化能力可能极差

**与贝叶斯奥卡姆剃刀的联系**

实验结果与贝叶斯框架下的"简单性先验"有相似之处，但揭示了神经网络实现这一机制的具体方式：通过梯度下降动态，在参数空间中逐渐"坍缩"到更容易拟合的解。

### 1. rule_preference_phase_transition.py

- **用途:** 规则偏好相变实验主程序
- **逻辑:**
    1. **数据生成**：构造满足`front ^ back = CA(front)`约束的训练集
    2. **模型训练**：使用MLP拟合数据，监控训练/验证loss
    3. **OOD测试**：在分布外数据上分别测试对规则A和规则B的遵循程度
    4. **可视化**：生成Loss动力学图和准确率竞争图
- **关键参数:**

```python
CA_LAYERS = 3  # 关键变量：修改这里 (1, 2, 3) 观察相变
INPUT_DIM = 30   # 输入维度 (15 bit front + 15 bit back)
CORE_DIM = 15    # 输出维度
HIDDEN_SIZE = 1024  # 模型容量
EPOCHS = 1000    # 训练轮数
```
