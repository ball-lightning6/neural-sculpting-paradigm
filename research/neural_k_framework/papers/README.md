- **English title:** *Compression Is Intelligence: Rethinking Neural Network Generalization*
- **Author:** Chao Zheng, Independent Researcher
- **Publication date:** 2026-09-02
- **DOI:** [10.5281/zenodo.22255552](https://doi.org/10.5281/zenodo.22255552)

这篇简短研究说明概括了 Neural K 工作的主要实验发现和最小理论框架。正文讨论训练集完全分类正确后的函数迁移、随loss变化的静态函数概率、Neural Kolmogorov复杂度曲线、固定训练集下的函数竞争，以及静态参数分布和真实优化器结果之间的区别。完整实验配置、复现脚本和结论边界见上一级目录的[实验索引](../experiments/README.md)与[证据总账](../evidence_ledger_zh.md)。
