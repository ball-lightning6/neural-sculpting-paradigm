# E13：实验动机与预注册判据

## 1. 竞争解释

E12 发现原始 AND、n=10的静态低-loss 区域偏向 F500/F550 shortcut。可能解释包括：

1. 静态质量会预测 SGD 进入同一 shortcut 家族；
2. optimizer 完全忽略该静态结构；
3. 初始 seed 预先决定终点，与数据缺口无关；
4. 继续训练最终总会恢复 AND，数据不足只影响速度。

## 2. 配置

- 网络：`4 -> 64 x 3 -> 1` GELU+LayerNorm；
- full-batch AdamW，学习率`1e-3`，weight decay 为0；
- 每条件2,048个 seed；
- 完整枚举16点 hard function；
- 原始缺口与最小平衡 n=10使用相同初始化 seed；
- 发布复现固定50,000步；原始归档另延长至127,458步验证平台。

最小干预只做：

```text
删除 1101 -> 1
加入 1000 -> 0
```

其余9个样本不变。

## 3. 判据

- 训练集首次100% hard-exact 时刻；
- AND、F100、F500、F510、F550 及单点邻居的质量轨迹；
- 平均未见例外数、函数熵和 agreement；
- 插值后迁移来源；
- 50k 以后分布平台稳定性；
- 相同 seed 在数据干预前后的函数和例外数变化。

## 4. 边界

- optimizer 分布不应与 E12 静态体积数值等同；
- 原始数据未唯一辨识 AND，因此长期混合平台不是“没有学会正确答案”的内部定义；
- 50k 复现预算用于核心配对，127k 只验证原始平台不会继续自动收束；
- 小型4-bit 空间放大单样本影响，跨规模普遍性需其他实验支持。
