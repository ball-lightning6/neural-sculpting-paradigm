# E23：实验动机与预注册

## 1. 可证伪问题

若完整规则在固定神经参考协议下的低-loss 质量确实刻画了机器相对难度，那么它应预测另一个独立量：从随机部分真值表中可靠恢复该规则需要多少样本。为避免事后按训练结果选择复杂度指标，实验分为完全分离的 A/B 两阶段。

## 2. 阶段 A：冻结体积预测

固定`8 -> 16 x 2 -> 1 tanh`网络和八条平衡规则：parity1--4、majority3/5、MUX3 和 random-balanced。对完整256状态运行 SMC，以

$$
K_f^N(\epsilon)=-\log V_f^{full}(\epsilon)
$$

在 raw BCE `0.690 -> 0.670`上的割线斜率作为冻结 volume score。分数越大，预言规则越难。任何随机子集训练开始前，预测顺序和 SHA256 均写入文件。

确认性主判决只使用嵌套 parity，因为其独立难度顺序最清楚；全部八规则是压力测试，允许暴露跨族单标量失败。

## 3. 阶段 B：独立测量样本相变

每个非完整样本量、每条规则生成64份随机训练集，每份使用24个配对初始化训练40,000步。一个数据集被判定“恢复”须同时满足训练拟合率、目标完整函数质量、目标为 modal function 和函数 collision 阈值。`n50/n90`定义为 isotonic 恢复率首次达到50%/90%的最小随机样本数；`n=256`只作完整数据可达性检查。

总计：

```text
19个非完整n x 8规则 x 64数据集 = 9,728
8个完整数据资格条件
每条件24个seed
```

## 4. 判决

- 主判决：parity 体积排序是否严格预测`n50/n90`排序；
- 次判决：八规则的秩相关及明确反转；
- 诊断：保存多阈值曲线，检查局部速度和绝对体积排名是否随 loss 变化。
