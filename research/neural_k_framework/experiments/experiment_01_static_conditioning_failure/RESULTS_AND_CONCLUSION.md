# E01a/E01b：完整结果与阶段裁决

## 1. E01a 完整性

- 协议版本：`static_prior_vs_sgd_function_posterior_v1`；
- 1,048,576个 prior 样本；
- 5个条件各8,192条训练轨迹；
- path test 三协议各4,096个初始化；
- 全部条件达到训练集 hard exact；
- 总运行时间约693.9秒；
- 原始函数分布、logits、bootstrap、路径统计和绘图均在 ZIP 中。

### 1.1 逐函数 TV 远超抽样噪声

| 条件 | 首次拟合TV | post-fit 100 TV | post-fit 1,000 TV | age 1,000 null p95 |
|---|---:|---:|---:|---:|
| `single_x0_y0` | 0.104 | 0.539 | 0.538 | 0.037 |
| `single_x0_y1` | 0.102 | 0.535 | 0.534 | 0.037 |
| `rule30_k2` | 0.309 | 0.638 | 0.640 | 0.028 |
| `rule30_k3` | 0.308 | 0.616 | 0.620 | 0.019 |
| `rule30_k4` | 0.309 | 0.602 | 0.607 | 0.017 |

所有 bootstrap 检验达到当前1,000次重复可分辨的最小`p≈0.001`。训练集不变时，分布在 post-fit 100步内继续远离固定静态后验。

### 1.2 具体函数排名反转

`rule30_k3`在 age 1,000：

| function ID | 静态条件先验 | Adam训练分布 |
|---:|---:|---:|
| 254 | 43.61% | 16.53% |
| 238 | 17.32% | 79.32% |

这不是公共温度下降对原排序的简单锐化，而是具体延拓函数换序。

### 1.3 训练历史没有被2,000步完全洗掉

到最终训练集后再训练2,000步，同初始化模型的 hard function 不同率为：

| 配对路径 | 函数不同率 | 两个经验分布TV |
|---|---:|---:|
| direct vs forward | 28.20% | 0.197 |
| direct vs reverse | 19.51% | 0.046 |
| forward vs reverse | 27.08% | 0.158 |

forward 与 reverse 的阶段大小和总步数匹配，因此二者是最干净的顺序效应；direct 从一开始就看见最终训练集，不能把它与增量路径的全部差异只归因于顺序。

## 2. E01b 完整性与结果

- 协议版本：`single_sample_prior_dynamics_1024_v1`；
- prior 覆盖186/256个观测 hard function；
- 四条件各128个模型，全部一步拟合；
- age 0/1/2全部保存，hard function 无任何短暂反转。

初始化 prior：

| 类型 | 质量 |
|---|---:|
| 常数0 | 14.01% |
| 常数1 | 13.72% |
| 非常数函数合计 | 72.27% |

单样本条件化后，目标常数静态质量为：

| 条件 | 静态目标常数质量 | 训练后目标常数质量 |
|---|---:|---:|
| `000 -> 0` | 27.49% | 100% |
| `000 -> 1` | 27.99% | 100% |
| `111 -> 0` | 27.76% | 100% |
| `111 -> 1` | 27.71% | 100% |

四组128/128均在第一次 Adam 更新后成为目标常数。初始化时已经满足训练点、但仍为非常数函数的 seed，也以45/45和47/47全部迁移到目标常数。若按静态条件先验独立采样，单组128次全部命中目标常数的概率约`10^-71`。

四条件最终 TV 约0.720--0.725，JS 约0.515--0.521 bit；静态 hard-function 熵约4.96--5.01 bit，训练后为0。age 2时平均训练 margin 约11.3--11.5，平均未见输入绝对 logit 约10.8--11.1，不是阈值附近偶然翻转。

## 3. 阶段裁决

两项实验共同拒绝：

> 全部简单性偏置在初始化时已经确定；训练只删除与标签不一致的 hard function，并按剩余先验比例抽样。

保留的结论是：

> 初始化函数先验是重要零阶项，但优化器能够系统运输已经满足训练集的函数质量，使具体函数赔率依赖训练年龄和历史。

## 4. 不能声称什么

1. 没有否定初始化先验的简单性偏置；
2. 没有否定连续 logit、soft likelihood 或显式动力学 Bayesian 模型；
3. E01a/E01b 均为 Adam，尚不能自动推广到任意 optimizer；
4. 没有证明迁移方向等于机器无关 Kolmogorov complexity 下降；
5. 没有证明路径在无限时间后仍不汇合；
6. hard function 稳定后 logits 仍变化，不能把两者混为同一对象。
