# E18：完整结果与阶段裁决

## 1. Pilot 发现 teacher-free 高共识可读规则

540个数据集中4个达到严格高共识：copy、NOT、majority3，以及一个随机平衡 n=12训练集。该随机集61/64 seeds 收束到同一完整256-bit 函数，collision 0.908；训练集在 step 200已全部拟合，modal 质量随后从0.281升至0.953，属于 post-interpolation 函数收缩。

主模态只依赖4个变量，可写成短2-CNF 或 signed threshold 式规则；穷举审计表明当前训练集不存在相容0--3变量 junta，故它达到最低 essential-variable count。

在全部512个随机训练集上，collision 与 essential variables、ANF、decision tree、ROBDD 和 influence 均显著负相关；控制样本数和输出平衡后仍保留，ROBDD partial Spearman 约-0.526。

## 2. 跨容量与样本干预

规范规则在六种容量/激活基线中均为第一模态，但 exact 质量从0.963降至0.596，说明符号骨架较稳、精确函数云高度协议相关。

加入原系综高分歧且一致的一个样本后，五个 tanh 设置规范质量达到0.998--1.000；大量原非规范 paired seeds 被因果运输到规范函数。GELU 是明确例外，显示信息价值仍依赖优化协议。

低分歧一致样本虽然被 base 终态所有函数 hard 预测正确，重新训练仍显著改变 exact 分布，证明“最终 hard posterior 再做零一条件化”不是训练过程。冲突标签排除规范函数后，六架构均未选择“规范函数只翻转该点”，而形成宽协议相关函数云。

## 3. 大规模结果

8,192个随机训练集中筛出120个宽松候选；fresh 4,096-seed 确认得到46个严格高共识。预注册 Tier 分布为4/31/11/0，没有 Tier-4 候选。事后 LP 审计发现：

- 46/46严格高共识函数都是线性阈值函数；
- 46/46具有等绝对值权重；
- 120/120宽松候选均线性可分，119/120属于等权 signed-threshold 族。

Tier-3 不是复杂反例，而是预注册语言漏掉了标准 signed-cardinality threshold。

## 4. 裁决

E18 没有证明所有神经高共识函数都人类可读，但给出强 teacher-free 正证据：在该8-bit MLP 协议中，高完整函数共识系统性对应训练集相容候选中的短符号规则；神经复杂度与人类符号复杂度至少在该自然规则族上显著对齐。

结果不支持逆命题，也不支持跨任意架构必然高共识。阈值族的统一识别属于事后发现，必须与预注册零 Tier-4 结果分开报告。
