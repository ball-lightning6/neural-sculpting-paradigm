# E08：实验动机与预注册判据

## 1. 唯象假说

若两个任务重复计算同一个昂贵中间状态，共享该状态应当节省有限网络容量；若被迫分别重算，两条任务各自可用的有效容量下降，达到同一低 loss 需要更多样本、更多优化步骤或更宽网络。

该假说试图为“低 loss 为何可能偏向可复用表示”提供因果正控，但不预设网络内部一定形成研究者命名的符号节点。

## 2. 四个原子任务

输入由两个独立30-bit 状态`u,v`组成。定义：

```text
F_k(u) = Rule30^k(u)
G_k(v) = Rule110^k(v)
A(z)   = z[:15] AND z[15:]
B(z)   = z[:15] OR  z[15:]
```

四个联合条件为：

```text
shared_f    = [A(F), B(F)]
shared_g    = [A(G), B(G)]
separate_fg = [A(F), B(G)]
separate_gf = [A(G), B(F)]
```

因此`A(F)、B(F)、A(G)、B(G)`在 Shared 与 Separate 两组中各出现一次。任何组间差异不能简单归因于使用了不同原子标签函数。

## 3. Joint 与 Split 干预

- Joint：两个输出共享三层隐藏网络，具备复用中间计算的通道；
- Split：两个输出使用完全独立分支，禁止隐藏计算共享；
- Split 每分支宽度自动设为178/359/721，使总参数量与 Joint 宽度256/512/1024的误差低于0.16%。

若 Shared 只是统计上更容易，它在 Split 中也应更容易。只有 Joint 出现额外 Shared 优势，才能归因于允许共享隐藏计算。

## 4. 正式配置与预注册剂量效应

- CA 前缀深度`k=0,1,2,3`；
- Joint 宽度256、512、1024；
- 每条件3 seeds，共288条轨迹；
- GELU+LayerNorm 三隐藏层，Adam `1e-3`，weight decay 与 dropout 均为0；
- 在线随机 CA 数据，batch 512；固定32,768 probe；最多5,000步。

主预测：

1. Split 中的 Shared/Separate 差异应接近0；
2. Joint 的共享优势应随前缀深度增加；
3. 网络越宽，重复计算越容易容纳，共享优势应减弱；
4. 优势可以表现为更低最佳 loss 或更快达到固定 loss 阈值。

## 5. 指标边界

固定学习率在线训练可能在达到极低 loss 后发生晚期坍缩。因此理论判决优先使用：

- 预算内最佳 probe loss；
- 首次达到`1e-2、1e-3、1e-4`的累计样本量；
- late-collapse 审计。

最终 checkpoint 均值只用于稳定性审计，不能作为主裁决。
