# E08：完整结果与阶段裁决

## 1. 设计审计

- 24/24个批量组、288条轨迹全部完成；
- Joint/Split 参数量匹配误差低于0.16%；
- Split 阴性对照在全部12个`depth x width`单元中的 Shared/Separate loss gap 约`1e-8`或更低；
- 同一 seed 的四个条件使用逐元素相同初始化与相同在线输入流。

Split 近零差异说明四格原子任务难度配平成功。Joint 中的差异才是共享通道存在后新增的交互效应。

## 2. 晚期坍缩与主指标修正

25/288条轨迹的最终 loss 比预算内最佳 loss 恶化超过5倍。极端轨迹曾先达到100%exact 和约`1e-5` loss，随后在最后区间突然升至`0.2--0.33`。因此最终 checkpoint 算术均值会被少数坍缩污染，结果以最佳可达 loss 和首次到阈值为准。

## 3. 最佳 loss 的深度与宽度剂量效应

下表给出：

```text
log(best separate / best shared)_joint
- log(best separate / best shared)_split
```

括号为 Separate/Shared 最佳 loss 几何比例。

| prefix depth | W=256 | W=512 | W=1024 |
|---:|---:|---:|---:|
| 0 | -1.731 (0.18x) | +0.022 (1.02x) | -0.061 (0.94x) |
| 1 | +1.366 (3.92x) | -0.147 (0.86x) | -0.216 (0.81x) |
| 2 | +2.087 (8.06x) | +1.524 (4.59x) | +1.275 (3.58x) |

`k=0`没有共享收益，`k=1`处于交叉区；`k=2/3`的全部18个 seed 配对中 Shared 最佳 loss 均低于 Separate。前缀越深，复用收益越大；网络越宽，收益系统性减弱。

## 4. 达到固定 loss 需要的样本量

`depth=2`达到 BCE `1e-3`：

| Joint width | Shared中位样本量 | Separate中位样本量 | 比例 |
|---:|---:|---:|---:|
| 256 | 768,000 | 1,984,000 | 2.58x |
| 512 | 512,000 | 768,000 | 1.50x |
| 1024 | 384,000 | 512,000 | 1.33x |

`depth=3`时，W=512达到`1e-2`快4.71倍，W=1024快3.80倍；W=1024达到`1e-3`为576,000对2,048,000，Shared 快3.56倍。更窄设置中 Separate 常在预算内完全达不到深阈值。

## 5. 阶段裁决

E08 允许声称：

> 当两个输出具有足够昂贵的共同 CA 前缀计算时，允许共享隐藏网络能用更少容量和更少在线样本达到同一极低 loss；优势随共享前缀深度增加，并随网络宽度增加而减弱。没有昂贵前缀时，任务耦合成本可抵消甚至反转共享收益。

这为“有限容量会形成计算复用压力，复用结构有利于更深 loss”提供了因果唯象证据。它不依赖用 hard function ID 猜内部程序，因此补充了完整映射体积测量无法直接分辨同一 hard function 内部实现的问题。

不能声称：

- 网络已经显式形成研究者预设的`F_k/G_k`中间变量；
- 所有层或神经元会平均承担计算压力；
- 任何共享任务都优于分离任务；
- 该实验已经证明 Kolmogorov complexity 定律；
- OOD 规则语义或人类概念形成已由本实验直接证明。

OOD 语义的合理连接仍是一个宏观假说：当许多任务能够通过同一解释器、符号绑定或中间状态复用时，该共享程序可能比多套焊死电路更经济，从而获得低-loss 优势。
