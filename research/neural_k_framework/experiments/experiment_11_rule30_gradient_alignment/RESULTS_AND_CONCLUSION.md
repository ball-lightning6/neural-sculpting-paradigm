# E11：完整结果与阶段裁决

## 1. 完整性

- 8个样本量、5 seeds，共40个模型；
- 全部运行20,000步，总耗时313.3秒；
- 相同 seed 跨样本量具有完全相同初始化；
- 训练集严格嵌套，validation 固定独立；
- matched-loss 使用逐 seed 对数 loss 插值，而非最近 checkpoint 代替。

## 2. 相同 raw BCE 下的数据量次序

在 raw BCE 0.3至0.003的每个截面，五个 seed 分别都呈现训练样本量增加、梯度余弦严格上升的完整次序。以 BCE 0.1为例：

| n | train/val梯度余弦 | validation BCE - train BCE |
|---:|---:|---:|
| 256 | -0.167 | 0.482 |
| 512 | -0.018 | 0.346 |
| 768 | 0.245 | 0.248 |
| 1024 | 0.446 | 0.173 |
| 1280 | 0.564 | 0.121 |
| 1536 | 0.671 | 0.091 |
| 2048 | 0.803 | 0.055 |
| 4096 | 0.927 | 0.019 |

在 BCE 0.01时：

- `n=256`：余弦`-0.237`，gap 约0.693；
- `n=4096`：余弦`0.950`，gap 约0.00137。

因此低数据条件继续降低训练 loss 时，局部方向已经主动提高 validation loss；高数据条件在同等深 loss 处仍几乎沿总体规则方向下降。

## 3. 从过拟合到同步泛化的连续谱

- `n=256/512`在31--50步完全拟合训练集，最终 validation bit accuracy 约74.84%/92.96%；
- `n=768`在67步拟合训练集，500--1000步后 validation 才超过99%，最终99.9958%，表现为平滑延迟泛化；
- `n=1024`五个 seed 最终全部零错误；
- `n=4096`训练和 validation exact accuracy 都约在84步达到100%，几乎同步。

在初始化附近，少量数据也能提供明显 Rule30 共有方向；数据量真正决定的是该方向可以延伸到多深的训练 loss。低数据的共享结构较早耗尽，剩余梯度转向训练集特有细节；高数据的剩余约束在低 loss 处仍保持规则相干。

## 4. 阶段裁决

E11 支持：

> 增加同一规则的训练样本，不只改变最终泛化结果，也沿 optimizer 实际轨迹系统性改善给定 raw BCE 截面的训练/validation 梯度对齐，使规则一致的下降通道延伸到更深 loss。

它为 train/validation 同步下降、平滑延迟泛化和普通过拟合提供同一局部几何解释，也支持“任何有限 D 通常只支持规则对齐到有限 loss 深度”的修正图景。

不能声称：

- 高 loss 参数空间已经由正确 hard function 充满；
- 梯度余弦直接等于函数体积；
- validation-half 余弦是严格上界；
- 单个 Rule30 数据排列足以建立跨任务定律；
- 数值接近零梯度时的最终余弦仍有意义。
