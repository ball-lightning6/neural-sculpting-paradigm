# E11：完整结果与阶段裁决

## 1. 完整性

- 8个样本量、5 seeds，共40个模型；
- 全部运行20,000步，总耗时313.3秒；
- 相同 seed 跨样本量具有完全相同初始化；
- 训练集严格嵌套，validation 固定独立；
- matched-loss 对每个样本量和 seed 按 log-loss 距离选择最近 checkpoint，仅保留`max(actual_loss / target_loss, target_loss / actual_loss) <= 1.35`的点；历史实现未做插值。

## 2. 近似匹配 raw BCE 下的数据量次序

归档`fixed_raw_bce_comparison.csv`显示：在目标 raw BCE 0.2、0.1、0.05、0.02、0.01和0.003的近邻匹配中，五个 seed 分别都呈现训练样本量增加、梯度余弦严格上升的完整次序。目标0.3只有4/5 seeds 严格保持该次序；seed 4在`n=256/512`的实际 BCE 为0.33647/0.26956，余弦为0.178/0.167。这是上述容差内的比较，不是精确同 loss 次序。以目标 BCE 0.1为例，余弦和 gap 为五个 seeds 的均值，实际 train BCE 列给出均值及范围：

| n | 实际 train BCE，均值 [最小, 最大] | train/val梯度余弦 | validation BCE - train BCE |
|---:|---:|---:|---:|
| 256 | 0.09056 [0.08318, 0.10133] | -0.167 | 0.482 |
| 512 | 0.09255 [0.08195, 0.10705] | -0.018 | 0.346 |
| 768 | 0.10144 [0.09380, 0.10908] | 0.245 | 0.248 |
| 1024 | 0.08977 [0.08397, 0.09649] | 0.446 | 0.173 |
| 1280 | 0.08959 [0.07922, 0.10595] | 0.564 | 0.121 |
| 1536 | 0.09139 [0.08361, 0.10105] | 0.671 | 0.091 |
| 2048 | 0.09092 [0.07892, 0.10456] | 0.803 | 0.055 |
| 4096 | 0.09132 [0.07900, 0.10984] | 0.927 | 0.019 |

在目标 BCE 0.01时：

- `n=256`：实际 train BCE 均值0.00977，范围 [0.00907, 0.01086]；余弦`-0.237`，gap 约0.693；
- `n=4096`：实际 train BCE 均值0.00949，范围 [0.00858, 0.01074]；余弦`0.950`，gap 约0.00137。

因此，低数据条件下观测到的负余弦表示：在对应诊断点沿负原始 full-train 梯度的小步更新会在一阶近似下提高 validation loss；不能由组均值为负推断每个 seed 均为负。高数据条件在近似匹配的深 loss 处，原始训练梯度仍与独立验证梯度高度对齐。这不是对实际 Adam 更新方向或实际 validation loss 增量的测量，后者需另测。

## 3. 从过拟合到同步泛化的连续谱

- `n=256/512`在31--50步完全拟合训练集，最终 validation bit accuracy 约74.84%/92.96%；
- `n=768`在67步拟合训练集，500--1000步后 validation 才超过99%，最终99.9958%，表现为平滑延迟泛化；
- `n=1024`五个 seed 最终全部零错误；
- `n=4096`训练和 validation exact accuracy 都约在84步达到100%，几乎同步。

在初始化附近，少量数据也能提供明显 Rule30 共有方向；数据量真正决定的是该方向可以延伸到多深的训练 loss。低数据的共享结构较早耗尽，剩余梯度转向训练集特有细节；高数据的剩余约束在低 loss 处仍保持规则相干。

## 4. 阶段裁决

E11 支持：

> 增加同一规则的训练样本，不只改变最终泛化结果，也在 optimizer 实际轨迹上近似匹配 raw BCE 的诊断点系统性改善原始训练/validation 梯度对齐，支持沿负原始梯度的规则一致下降方向延伸到更深 loss。

它为 train/validation 同步下降、平滑延迟泛化和普通过拟合提供同一局部几何解释，也支持“任何有限 D 通常只支持规则对齐到有限 loss 深度”的修正图景。

不能声称：

- 高 loss 参数空间已经由正确 hard function 充满；
- 梯度余弦直接等于函数体积；
- 原始梯度余弦直接给出实际 Adam 更新的 validation loss 变化；
- validation-half 余弦是严格上界；
- 单个 Rule30 数据排列足以建立跨任务定律；
- 数值接近零梯度时的最终余弦仍有意义。
