# E05：完整结果与阶段裁决

## 1. 测量审计与固定 kernel 前提

经验 NTK 快速公式与逐参数 autograd Jacobian Gram 的最大绝对误差为`3.55e-15`，最大相对误差为`2.72e-16`。

匹配三隐藏层 ReLU 网络的解析无限宽 NTK 在20,000个未见状态上得到：

- 600,000个输出 bit 零错误；
- 20,000个完整30-bit 输出零 exact error；
- bit accuracy 与 exact accuracy 均为100%。

宽度1,024的初始化经验 NTK 只测输出位0、15、29。三个 seed 合计180,000个预测 bit 错误220个，平均 bit accuracy 为99.8778%；三位联合 exact accuracy 分别为99.5800%、99.7500%和99.5750%。因此有限宽经验核已接近解析极限，但没有被偷写成严格零错误。

## 2. 初始化到最终的结构变化

六条端到端轨迹最终都达到训练集与20,000测试集完整30-bit 零错误。三 seed 平均：

| loss | 隐藏表示`1-CKA` | block NTK `1-CKA` | ReLU门控翻转 | 隐藏表示目标对齐 |
|---|---:|---:|---:|---:|
| BCE | 0.2400 | 0.01556 | 37.85% | 0.1305 -> 0.2472 |
| MSE | 0.0920 | 0.00728 | 25.76% | 0.1305 -> 0.1666 |

MSE 下仍有约四分之一门控改变、明显的隐藏表示 CKA 变化和稳定的任务对齐提升，所以结果不能只归因于 BCE 无限增大 margin。BCE 的 kernel 范数确实增长数百倍；MSE 下范数也增长约3.7--5.1倍，但主判据使用的是归一化结构指标。

## 3. 完整函数已经正确以后

六条轨迹中五条通过脚本预设的“CKA 变化与门控翻转同时超过`0.001`”判据。`mse_seed2`未通过自动布尔判决，但从登记的首次全对快照到30,000步仍有：

- 1.145%的门控继续翻转；
- block NTK `1-CKA=0.000169`；
- 隐藏 CK `1-CKA=0.000464`。

该 seed 在3,000步只剩一个 exact error，下一快照直接跳到10,000步全对，因此真实首次全对后的主要变化可能落在未记录区间。结果应如实写成“五条跨过预注册双阈值；第六条仍有门控变化但归一化 kernel 变化低于阈值”，不能写成六条全部通过。

## 4. 阶段裁决

可以声称：

> 匹配架构的固定无限宽 NTK 已经能够零错误学习 Rule 110，但真实有限宽网络在端到端训练中仍发生跨 seed、跨 BCE/MSE 的任务相关特征学习。kernel 充分性并不迫使网络停留在初始化 kernel 或 lazy-training 机制中。

该结果还支持一个概念分离：固定 NTK 本身已经泛化，而真实网络仍改变特征，故“发生特征学习”与“特征学习为泛化所必需”不是同一命题。

在本文框架中，特征学习是优化器沿训练目标运输参数与表示的一种机制；泛化则取决于训练集与协议定义的低-loss 质量是否在未见输入上集中到共同延拓。因此：

- 结构化且可辨识的数据上，特征学习可以与泛化同时出现；
- 欠约束或随机标签数据上，也可以发生表示变化而不产生规则泛化；
- 一个合适的固定 kernel 可以在没有 kernel 变化时泛化。

不能声称：

- 固定 NTK 本身发生了特征学习；
- 宽度1,024的每个初始化经验 NTK 已经完整零错误；
- 特征学习必然提高泛化；
- CKA 或门控变化已经证明程序复杂度下降；
- 六条轨迹都通过了 post-fit 预注册双阈值。
