# 幅度对齐的独立静态验证

日期：2026-09-14。状态：完成一轮幅度约束的独立SMC验证，不运行SGD训练、跨训练集成本模型或深尾外推。

**任务范围纠偏：**用户随后明确，原要求是利用新调研的数学基础对现有框架作可靠量化预测。本轮实际是幅度正则的独立静态复核，虽保留结果，但不算完成该原始要求；数学转移与旧数据回测另见[纠偏后的记录](E:/code/clean_github/neural-sculpting-paradigm/research/notes/20260914_theory_to_quantitative_predictions_zh.md)。

## 结论先行

**在这一个固定训练集、网络和Gaussian参数测度下，幅度方差约束确实产生了平均BCE之外的额外静态选择效应。** 较强一档lambda=0.1在匹配BCE分布后，使完整parity2规则占比由86.65%升至88.82%，同时降低候选规则的平均固定K和K分布宽度。较弱一档lambda=0.01的目标占比收益还不能与本轮Monte Carlo波动清楚区分。

这不是直接证明原版grokking或SGD采样规律，也不是证明任何幅度正则都会增强简单性偏置。它回答的是更窄而明确的问题：**在相同平均loss附近，约束各样本的正确方向margin更接近，能否额外改变静态函数分布，并偏向本实验中参考成本较低的规则？本次结果支持。**

## 1. 测了什么

- 网络：4→16→1 tanh，97维独立标准Gaussian神经坐标；隐藏权重和bias除以2，读出权重和bias除以4。与旧实验相同，不修改参数化。
- 输入：4bit的16种0/1输入。训练输入固定为0、3、4、7、8、11、12、15；其它8点只作观测。
- 标签：来自parity2，即0x0FF0。parity4（0x6996）也符合这8条训练标签，但没有只保留这两个函数；全部完整映射都参与统计。
- 正则对象：正确方向margin `m_i=(2y_i-1)z_i` 的总体方差。不是让相反标签的原始logits相等，也不是只取无符号幅度。
- 采样事件：`J_lambda = mean_BCE_D + lambda * Var_D(m_i) <= 0.3`，lambda取0、0.01、0.1。
- 每个条件8个独立Gaussian起点副本，每副本4096个SMC粒子。到达终点后追加96轮固定步长pCN更新。

**固定K的含义：**沿用旧全16点BCE<=0.01曲线得到的完整规则成本表，作为给不同hard function贴的独立参考标签。它不是本次8样本约束的参数体积成本，也不是逐权重的精确Kolmogorov复杂度或新估计的收缩斜率。

**Agreement的含义：**从条件函数分布独立抽两个完整映射，计算它们在固定8个未见输入上的逐点相同概率，再取平均；不是目标正确率，也不是整个映射完全一致的概率。

新科学采样前，已于2026-09-14 07:08:21冻结旧4个SMC副本的条件筛选预报、快照hash和本轮协议。新SMC没有载入旧权重，也没有用函数ID引导proposal。

| 条件 | 旧预报parity2占比 | 新独立SMC占比 | 新平均固定K | 新未见agreement | 额外体积成本：新测/旧预报 |
|---|---:|---:|---:|---:|---:|
| 无正则 | 85.0830% | 85.8521% | 559.862 | 95.3201% | 0 / 0 bit |
| lambda=0.01 | 85.8128% | 86.4014% | 558.896 | 95.3927% | 0.296 / 0.427 bit |

## 3. 排除“只是BCE更低”的解释

`J_lambda<=0.3`给正则留出了预算，因此处理组本来就可以偏向更低的BCE。仅比较上表不够。

本轮预先规定用宽0.0005的BCE细分箱，比较同箱内的函数分布，再把无正则对照重加权为处理组的BCE分箱分布。共同支持由每箱总计数与独立副本覆盖决定，不看目标占比或K收益。

主采样中lambda=0.1的支持覆盖率为85.19%，触发预定的一次补采：额外8个独立副本采样无正则的 `0.27<=BCE<=0.29` 带。它们只补足完整落在带内的细分箱对照，不混入无正则组的总体分布。补采后主匹配覆盖98.62%。

这些是本轮副本Monte Carlo波动的区间，不包含固定K标签误差或未知共同混合偏差。

### 预定的半箱宽敏感性分析

将BCE分箱宽减半到0.00025，共同支持覆盖95.82%，结果仍为：

- 目标占比差 **+2.0991个百分点**，95%区间[+1.6035,+2.5982]。
- 平均固定K差 **-3.7304**。
- 未见agreement差 **+0.3964个百分点**。
- 双方匹配后的平均BCE仅差约0.00000109。

所以主要效果没有因更细的BCE匹配而消失。有限分箱仍不等于严格连续等loss条件化，但这里的残余BCE差已很小。

### 弱剂量：lambda=0.01

主分箱中目标占比差为+0.3662个百分点，95%区间[-0.2194,+1.0534]；未见agreement差也包含零。平均固定K下降有弱信号，但半箱宽后其区间也包含零。**本轮不把这一档写成可靠的目标占比或agreement提升。**

## 4. 与理论的对应，及没有证明什么

如果E0表示 `BCE<=0.3`，E_lambda表示加入方差项后的事件，则E_lambda包含于E0。对完整函数f，有

`q_lambda(f) = q_0(f) * P(E_lambda | E0, f) / P(E_lambda | E0)`。

这个条件概率关系本身按定义成立，不是新发现。真正需要实验的部分是：**不同完整映射内部的margin分布怎样，使额外约束实际偏向哪些映射，以及独立采样能否复现这种偏好。** 本次观察到的具体偏好是更高的parity2质量、更低且更窄的参考K分布。

这与“联合输出分布是上游对象，平均BCE只是一个选择坐标”的修正相符。无需假设简单函数的绝对质量增加；lambda=0.1的总事件质量实际上更小，但目标的相对份额增加。

还应保留四点：

1. 这里只测一个训练集、一个架构和一个参考测度，不推出跨任务普遍有效。
2. 这是硬目标阈值的条件分布，不是 `exp(-eta R)` 软重权；不能拿它直接验证软响应公式的导数值。
3. 没有运行SGD，也没有据此声称已经测到原版grokking的静态体积。
4. 固定K变窄不证明微观复杂度谱唯一，更不证明每个hard function内部也同样变窄。

## 5. 计算、复核与残余风险

- 正式主作业24个，预定补采8个，共32个独立SMC作业、32个不同seed；全部完成。
- 总计131072个最终权重向量，逐个用NumPy float64独立重算16点输出；最大logit差8.02e-7以内，无符号翻转，无重算后目标越界。
- 采样在本地RTX3080的CUDA1运行；粒子和前向float32，log质量float64，无TF32或AMP。采样作业累计约618秒，即10.3分钟，不含开发、工程检查和后处理时间。
- 7项采样器工程自检、3项分箱匹配工程测试通过；128粒子的冒烟数据与科学数据分目录保存，不进入正式统计。
- 另一份逐粒子重权实现独立核对主分析的分箱矩阵算法，四组条件/箱宽的最大统计量差小于2.9e-12，全部通过。
- 终点96轮内，各条件目标占比均值有约0.35至0.63个百分点的净变化。此短程诊断不能证明充分混合；多个独立副本也不能排除共有偏差。本轮到此结束，不无限加采来追求无法保证的精度。
