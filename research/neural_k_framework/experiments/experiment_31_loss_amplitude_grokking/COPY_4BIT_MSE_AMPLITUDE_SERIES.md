# 4-bit copy 的 MSE 幅度系列与 BCE 幅度对齐正则

> 所属：E31 Loss、目标幅度与 grokking。本页补齐 2026-09-10 的 4-bit copy 系列，它是幅度对齐正则的诞生地，也是"MSE 并非一律劣于 BCE"方向的证据。

## 问题

固定 `4→16→1 tanh`（97 参数）、0/1 输入、Gaussian 初始化、充分拟合的前提下：把 loss 从 BCE 换成不同目标幅度的原始 MSE，或在 BCE 上加入幅度对齐正则，会怎样改变 copy 规则的完整恢复率？

## 结果

### 小目标幅度系列（12 训练样本，512 独立初始化/组）

| 目标 | 完整恢复 copy | 未见准确率 |
|---|---:|---:|
| BCE / MSE ±1 | 512/512 | 100% |
| MSE ±0.1 | 446/512（87.11%） | 96.00% |
| MSE ±0.01 | 67/512（13.09%） | 58.79% |
| MSE ±0.001 | 30/512（5.86%） | 49.32% |

全部组都充分拟合了训练集。**充分拟合 ≠ 泛化**：±0.001 目标下，12 个训练点全部拟合，4 个未见点平均准确率为49.32%，接近随机猜测。

### n=8 对照：0/1 MSE 反超 BCE

| 目标 | 完整恢复 copy |
|---|---:|
| BCE | 374/512（73.05%） |
| 0/1 MSE | 507/512（99.02%） |
| ±0.5 MSE | 505/512 |
| ±0.3 MSE | 480/512 |

133 个 seed 只有 MSE 成功、无反向。**不能把"小幅度 MSE 失败"推广成"MSE 不如 BCE"**；是否有效取决于目标中心、间隔与任务饱和程度，不是 loss 名称。

### BCE + 幅度对齐正则（诞生地）

BCE + λ×（各样本有符号 logit 的方差），λ∈{0.01, 0.1, 1}：**三档全部 512/512 恢复**（基线 BCE 仅 374/512）。弱正则组原始 BCE 中位数与基线几乎相同（7.73e-6 vs 7.55e-6），排除"只是 loss 降得更低"的解释。该正则随后被迁移到 Rule30 与 mod97（见 E31 其他报告页）。

## 裁决

1. loss 的选择方向（目标位置、形状、对齐方式）是独立于"loss 深度"的控制轴；小幅度目标可以摧毁有限样本的规则恢复；
2. "BCE 才能 grokking"不成立：0/1 MSE 在本组反超 BCE；
3. 幅度对齐（各样本输出尽量接近）能实质增强有利于规则恢复的选择压力——幅度对齐正则的诞生地。

## 边界

- 单一 `4→16→1 tanh` 小网络、copy 单规则、0/1 编码、512 seed；幅度效应的中心/间隔/任务饱和度未分离；
- 结果不能外推为"MSE 普遍优于/劣于 BCE"或"对齐正则普遍有效"；
- 与 E31 中 Rule30（BCE 更优方向）和 mod97（对齐有效方向）一起构成完整图景，不应只引用其中一侧。
