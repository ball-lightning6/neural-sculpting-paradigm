# E03：完整结果与阶段裁决

## 1. E03a：一次更新即重写完整函数

实验仍是3-bit 而非4-bit；65,536表示 prior 网络数量，不是训练了65,536个目标函数。三个训练集分别留下128、64、16个兼容函数，总训练模型为`3 × (128 ordinary + 512 prior-consistent) = 1,920`。

prior-consistent cohort 训练前已经满足全部 hard 标签，并且函数分布与条件先验相容。仅一次 Adam 更新：

| 条件 | 改变完整函数的模型 | 最大函数质量变化 | 训练后相对hard prior TV |
|---|---:|---:|---:|
| 1样本 | 72.7% | 27.3% -> 100% | 0.717 |
| 2样本 | 99.0% | 7.2% -> 77.3% | 0.826 |
| 4样本 | 97.9% | 17.4% -> 39.3% | 0.553 |

对应有限样本 null p95 约0.156、0.132和0.058，迁移远超抽样波动。

## 2. 迁移方向不是随机，也不等于人类最短公式

二样本训练点为立方体对角点，训练后约81%的模型集中到对称最大间隔阈值函数：

```text
majority(not x0, not x1, x2)
```

四样本条件主要集中到：

```text
x2 AND (not x1)
x2 OR  (not x1)
```

初始化条件先验中大量存在更短的一变量解`x2`和`not x1`，却被训练主动挤走。因此“人类 Boolean 公式更短”不是当前网络选择的充分解释；对称、margin、范数与优化几何都可能参与。

## 3. 首次拟合后仍有大量配对迁移

ordinary cohort 从首次拟合继续到 age 5,000：

- 单样本：32.8%的 seed 改变完整函数；
- 二样本：50.8%；
- 四样本：47.7%。

四样本总体分布 TV 仅0.125，但47.7%的 seed 已换函数，说明相反方向迁移会在边缘直方图中抵消。仅看总体分布“看似稳定”会严重低估动力学。

prior-consistent cohort 到 age 5,000仍有：

- 二样本10.5%的模型改变函数；
- 四样本27.0%。

## 4. E03b：迁移稳健，具体后验依赖网络族

### tanh 宽度族

- width 16/32/64/128的初始化 hard prior 非常接近；相对128的 TV 约0.025/0.023/0.022；
- width 64与128的最终主模式6/6一致，差异处于 bootstrap 噪声内；
- width 16保留同一迁移方向，但改变集中速度和近并列函数排名；
- width 16没有比64更快，六个训练块约122秒 vs119 秒。

所有宽度均保留大规模 post-fit 迁移。width 16的 prior-consistent cohort 在 age 5,000相对各自 hard prior 的 TV，single/k2/k4 约为0.828/0.850/0.565。

### 与1024×3 GELU+LayerNorm 比较

- 两个网络族初始化 prior 的 TV 已经约0.29；
- 具体主导函数和概率显著不同，全部关键比较超过抽样噪声；
- 1024网络相应 TV 约0.717/0.840/0.471。

所以小网络没有复现大网络的具体后验，但“训练集拟合后函数质量仍被大规模运输”跨网络族保留。架构既影响 prior，也影响动力学吸引子。

## 5. 阶段裁决

E03 在完全不使用 K 复杂度标签的情况下建立：

1. hard-conditioned initialization prior 不是训练后函数分布；
2. 已经 hard-fit 的初始化函数会被一次更新大规模重写；
3. post-fit 长期仍有配对函数迁移；
4. 迁移方向结构化但依赖网络参考协议；
5. aggregate agreement/TV 不能替代逐 seed 函数轨迹。

该实验没有证明迁移就是 Kolmogorov 压缩，也没有裁决“[Solomonoff（1964）算法概率](https://mlanthology.org/misc/1964/solomonoff1964misc-formal/)的宽层级 vs 最低复杂度薄壳”。它为后续复杂度理论提供了必须解释的无循环经验事实。
