# E06：实验动机与预注册判据

## 1. 理论转折

训练集 hard accuracy 达到100%不表示训练 loss 为0。BCE 仍可继续降低，logit margin 仍可继续增长，完整函数也已经被 E01--E04 证明会继续改变。因此当时提出：

> 在同一批满足 hard 约束的简单和复杂函数之间，更深的连续低-loss 区域是否给架构相对经济的函数分配更大参数质量？

重要反驳随即出现：简单函数和复杂函数都可能把有限训练集 loss 压到任意低，故“某类函数存在低-loss 实现”本身不能区分它们。需要比较的是，在明确参数测度下，各函数低-loss 实现的**相对质量**怎样随 loss 阈值变化，而不是只问解是否存在。

## 2. 竞争预测

### H1：hard 条件化已经足够

满足相同 hard labels 以后，进一步降低连续 loss 只改变 margin 或公共 logit scale；所有兼容 hard function 近似按同一因子收缩，相对函数质量不发生稳定重排。

### H2：loss-resolved 静态几何

不同完整函数的参数质量会随训练 loss 以不同速度变化。静态低-loss 截面可以预示真实 SGD 的部分吸引方向，但不必给出相同强度。

### H3：SGD 等于静态退火

更强的候选解释认为，真实 SGD 在某个时刻的函数分布近似等于初始化测度按相同 loss 阈值截取或按`exp(-beta L)`重加权后的分布。若四样本等条件中静态与 SGD 函数排序、质量和迁移方向明显分离，该等同关系即失败。

## 3. 测量对象

实验固定`3 -> 1024 x 3 -> 1` GELU+LayerNorm 网络及其初始化分布，完整枚举8个输入上的256种 hard function。对每个条件先保留训练点 hard prediction 全部正确的参数，再采用两种互补测量：

1. **微正则子水平集**：在 hard-exact 样本中保留 raw BCE 最低的`50% ... 0.1%`；
2. **正则退火**：按`exp(-beta L_D)`连续重加权，并报告有效样本量 ESS。

为排除整体 logit 尺度混杂，还报告 RMS-normalized BCE 与固定 logit-scale 子群。所有 loss 只在有限训练集`D`上计算；function ID 则由全部8个输入上的 hard 输出定义。

## 4. 三组训练约束

| 条件 | 训练样本 | hard-exact后兼容函数数 | E03中的SGD主要吸引子 |
|---|---|---:|---|
| 单样本 | `000 -> 0` | 128 | 常量0，ID 0 |
| 双样本 | `110 -> 0, 001 -> 1` | 64 | 对称阈值函数ID 113 |
| 四样本 | 四个平衡点，标签`0011` | 16 | ID 48与243 |

full 运行采样4,194,304个未训练网络。四样本 hard-exact 仍有365,248个，最低0.1%尾部有366个样本，达到预设可靠性要求。

## 5. 预先声明的边界

- raw BCE 同时包含 hard function、margin 布局和整体 logit scale；
- Boolean 公式长度、ANF、Walsh 或 influence 都不是架构相对复杂度真值；
- 参数“体积”始终指给定初始化分布下的概率质量，不是坐标无关裸体积；
- 本实验完全不训练，不能测 SGD 流入率、逃逸率、混合或动态稳定性；
- 三组训练集只能裁决强等同关系，不能建立所有数据集上的普适单调定律。
