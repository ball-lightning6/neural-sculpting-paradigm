# 最小统计语言的逐项审计与勘误

日期：2026-09-20。对应[修订后的最小定义](20260920_minimal_strict_statistical_language_zh.md)。

## 1. 这次查到的实质问题

前稿仍存在对象替换问题，不能仅以“补了下标、区分了定义与经验”声称已经严格。最严重的一处是：已经条件于旧平均loss事件 \(E\) 的联合分布，只能得到 \(E\cap A_y^+\) 内的结果，却被命名为加入样本后的新分布。新平均loss事件 \(A_y^+\) 可能从 \(E\) 外吸收参数，前稿遗漏了这一部分。

另一个缺口是信息量所处的层级：参数分布的KL与hard函数分布的KL通常不同。连续loss限制可能只筛选同一函数内部的实现，函数分布完全不变。仅写“surprise等于KL”无法说明究竟是哪一个KL。

本轮重新读了“算法概率解释”中有关average-loss非嵌套、hard/soft预测、surprise、KL、shell及full-target的对话，并对照旧教程和相关推导，修改了最小主文。以下按实质问题记录。

## 2. 逐项改了什么

| 问题 | 旧写法的风险 | 当前修正位置与内容 |
|---|---|---|
| 一个hard函数的loss | 默认函数宏观态有一个确定能量 | 主文1至2节：函数cell内部保留连续输出；loss是参数函数 \(L_D(\theta)\)，用分支loss测度 \(\xi_f\) 描述 |
| 新平均loss更新 | 只算旧集合里通过的新样本参数 | 4.3节：明确加入 \(\mathrm{in}_y(f)\) 和 \(\mathrm{out}_y(f)\)，重建整个新事件质量 |
| 保留旧要求和重新采样 | 两者共用 \(Q^{\rm soft}_{D^+}\) 名字 | 4.2至4.3节：分别命名 \(Q^\cap_{E,y}\) 与 \(Q^{\rm new}_y\)，保留各自条件事件 |
| 标签预测 | 用“附加候选标签后的低loss质量”代替原分布hard投票 | 4.1至4.3节：互斥hard分支概率、soft接受率、独立候选事件质量各有定义 |
| 候选事件归一化 | 默认各候选标签事件能拼回父集合 | 4.3节：这些事件可重叠或遗漏区域；新/旧质量比可大于1，归一化评分也不自动等于hard预测 |
| 查询输入不在旧函数表里 | 仅凭旧函数边缘推算未见标签 | 1、4.1节：先扩展为 \(U'\)，保留旧cell的细分或等价联合信息 |
| 参数KL与函数KL | 混用同一个“分布更新量” | 5节：给出KL链式分解，补上cell内部条件分布的KL项；教学版明确要求函数分区可数且条件分布存在 |
| 期望surprise | 省略标签期望取自何种分布 | 5.1节：模型预测分布下等于模型Shannon熵；外部分布下为交叉熵 |
| 信息链式法则 | 每加数据都重新定义平均loss，却继续套嵌套乘法 | 5.1节：限定为真正的事件交集序列；最终交集固定才有顺序不变 |
| 最小KL | 把测度信息代价说成真实数据或算力需求 | 5.2节：保留精确投影分解，说明它度量的是分布相对参考测度的偏离 |
| Full-target与fixed-D | 把完整目标低loss质量当成候选hard函数质量 | 6.1至6.2节：补上目标内部的连续精度通过率 \(b_g\) |
| 平均loss与总loss | 同一阈值符号跨样本数使用 | 2、6.2节：总预算 \(\tau\) 对应平均阈值 \(\tau/n\)；完整表和部分表阈值分别换算 |
| 累计区域与shell | 只说“不同”，没有准确连接 | 2节：先定义loss测度；存在密度时，用局部收缩指数给出两种函数概率的精确重权 |
| 精确loss密度 | 默认每种loss分布都有普通密度 | 2节：允许原子和奇异分布；仅在绝对连续条件下使用 \(\rho_f\) 和导数 |
| Neural K与剩余成本 | \(-\log\Omega_f\) 与 \(-\log Q(f)\) 混用 | 3节：二者相差父事件负对数质量 \(J(D,\epsilon)\) |
| Neural K命名 | 论文full-target profile与fixed-D cell profile共用一个无后缀符号 | 论文对象写作 (K^{N,\mathrm{full}})，fixed-D对象写作 (K^{N,\mathrm{FD}})；只有在明确声明后才使用总称 |
| 复杂度分布 | 函数数目直方图、概率加权分布、当前K混用 | 3节：先固定成本标尺 \(c(f)\)，再定义其在当前函数分布下的推前分布 |
| 淘汰与复杂收缩 | 集合收缩被当成平均复杂度必降 | 3.1、7节：平均成本变化由协方差决定；最低可行成本沿相反方向单调，整体分布变化仍需测量 |
| 可行与正质量 | 用infimum直接判定边界存在；零质量当无解 | 7节：区分下确界取到、非空解集及正质量解集 |
| Agreement与凝聚 | 成本分布很窄就认为唯一函数占优 | 8节：区分完整碰撞、逐点一致、多数标签比例和成本方差 |
| 数据集随机性 | 不同数据集重复和固定数据重复混在一起 | 8节：平均条件碰撞率与混合分布碰撞率是不同量 |
| 函数簇与概率预算 | 重叠的函数性质事件直接相加 | 1、8节：聚合必须是固定分区；概率预算不适用于重叠的full-target高loss事件 |
| SGD与参考测度 | 为所有训练分布强行写参数密度比 | 9节：一般测度定义始终保留；密度比只在绝对连续前提下使用 |
| 几何体积与高斯质量 | 平移网络输出就声称固定高斯质量不变 | 10节：明确同测度平移不变和同步推前测度是两种条件 |
| 移动目标的体积比 | 将非嵌套的MSE邻域质量比称为存活率 | 10节：改成几何质量变化；只有嵌套协议有条件存活率解释 |
| 线性收缩 | 平移对称直接推出指数式 | 10节：仍需独立的混合差分界；给出有限窗口误差，收缩符号还要求正斜率 |
| AIT与MDL | 编码定理的常数被当成loss控制的混合修正 | 11节：固定最优前缀机和对象编码；神经混合修正是另定义的最小熵量 |
| 旧统计术语 | “相对熵”“自由能”无指定对象 | 用下表映射到精确定义，停止由名称推出物理机制 |

原称谓与当前对象的对照：

| 原称谓 | 精确对象 |
|---|---|
| 微观态 | 参数 \(\theta\)；规定推前测度时也可选连续联合输出 |
| 函数宏观态 | 固定输入域和读取规则下的cell \(C_f\) 或预定函数簇 |
| 能量 | 指定数据上的 \(L_D(\theta)\) 或 \(T_D(\theta)\)，二者须写明归一化；一般不是 \(L_D(f)\) |
| 态密度 | 先有分支loss测度 \(\xi_f\)，密度存在时才写 \(\rho_f\) |
| hard free energy | 若保留该名，明确仅指 \(J(E)=-\log\mu(E)\) |
| 分支“熵” \(\log\Omega_f\) | 一个事件的对数质量；不等于Shannon熵，也不等于KL相对熵 |
| 预测熵 | 指定标签随机变量在指定分布下的Shannon熵 |
| 函数Rényi熵 | 指定完整函数分布的 \(-\log_2\sum_f Q(f)^2\) |

## 3. 三个能直接查错的有限例子

### 3.1 新旧事件的比值大于1

有三个参数点，参考质量为 \(0.4,0.2,0.4\)。旧训练集只有一个样本，旧loss分别为 \(0.10,0.19,0.30\)，阈值为 \(0.20\)。

加入候选标签后的单样本loss分别为 \(0.10,2.00,0.01\)。新平均loss分别为 \(0.10,1.095,0.155\)。因此：

- 旧事件保留前两个参数点，质量 \(0.6\)；
- 新事件保留第一个和第三个参数点，质量 \(0.8\)；
- 只在旧事件内筛选只留下第一个，质量 \(0.4\)。

新/旧质量比为 \(4/3\)，不能叫预测概率。给三个点不同的完整函数ID，“旧条件内筛选”与“新事件重新采样”的函数分布也不同。

### 3.2 同一个hard函数的内部筛选

两个等质量参数点具有同一个hard函数。它们旧loss都为 \(0.19\)，查询点对同一正确标签的BCE分别为 \(0.10,0.30\)，都预测正确。加入查询样本后平均loss分别为 \(0.145,0.245\)。

按 \(0.20\) 阈值筛选只留第一个。于是hard预测概率为1，连续loss接受率为 \(1/2\)，参数KL为1 bit，函数KL为0。这个例子同时否定两个错误替换：hard预测率等于连续通过率、参数KL等于函数KL。

### 3.3 Full-target漏掉的内部因子

在某个固定训练总预算事件内，目标hard函数质量为 \(1/2\)。进一步要求held-out连续loss也满足完整预算时，只剩其中 \(2/5\)。

完整目标质量就是 \(1/5=(1/2)(2/5)\)，不能拿 \(1/5\) 直接当成原父事件中的目标hard质量。

## 4. 核验做了什么

脚本：[有限概率核验](checks/check_minimal_statistical_language.py)。

执行方式：

~~~powershell
& .venv-gpu/Scripts/python.exe -X utf8 -E -s research/notes/checks/check_minimal_statistical_language.py
~~~

本轮在CPU上执行，不涉及训练和采样。结果：[核验JSON](checks/20260920_minimal_statistical_language_results.json)。

10组检查全部通过；其中200个随机有限概率模型检查了条件KL、粗粒化KL链、最小KL分解、保留率更新、固定成本协方差、碰撞率界和概率预算。集合质量与大部分代数使用有理数精确核验，涉及对数的最大浮点残差约 \(8.88\times10^{-16}\)。

还核验了：同一平均阈值的进入/退出、hard函数内部loss差异、候选事件重叠、总预算嵌套、目标概率上升但collision下降、零成本方差但低collision、shell与累计赔率不同，以及full-target精度因子和离散曲率误差界。

这些是对公式和反例的检查。一般命题的依据仍是正文的定义、条件和推导；有限核验不等于证明神经网络满足指数收缩等经验前提。

## 5. 两份相关推导的追加修正

[联合输出速率推导](20260919_joint_output_rate_derivation_zh.md)：

- 平移公式明确写出推前后的测度，撤去未获条件支持的固定中心无关结论。
- Gaussian点密度式与小盒体积极限分别定义，指明小盒极限固定幅度，不能直接外推固定容差深尾。
- 大偏差部分分别定义输出尺度和速率尺度，要求方向邻域内一致余项。固定比例盒的主导率可能是盒内下确界，不能默认取中心值。
- 可微性和积分下求导条件显式写明。

[有限窗口收缩推导](20260919_volume_contraction_conditional_theorem_zh.md)：

- 近似平移的四角误差分别定义为 \(e_{ij}\)，若每个 \(|e_{ij}|\le\tau\)，一般界应为 \(\eta_{\rm int}+4\tau\)；原 \(2\tau\) 没有对应的充分前提。
- 加入时间状态说明，旧“节点缺少”描述保留为当时记录，后续已测结果另链到实测文档。

这些推导仍是条件模型，未证明复杂规则必有更大收缩系数。
