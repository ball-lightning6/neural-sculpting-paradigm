## Experiment overview {#overview}

## Purpose

E19 uses the full 16-point training set to directly specify each 4-bit rule, avoiding the ambiguity of which function a partial training set actually induces, and uses constrained SMC to compare the parameter mass with which different full targets reach the same loss.

Run:

```bash
python experiment_full_truth_rule_volume_smc.py
```

## Why this experiment was run, and how it was judged {#motivation}

## 1. Question

Under a partial training set, the winner may not be the researcher's generator; using the full truth table as the training target uniquely specifies the rule. If the low-loss mass of complex rules contracts faster, the volume ratio between rules should systematically grow with loss under the same reference machine and the same loss threshold.

## 2. Setup

- Network: `4 -> 16 x 2 -> 1 tanh`, 369 parameters;
- Measure: the PyTorch default uniform initialization parameter cube;
- Targets: parity1--4, majority3, and a pre-registered random balanced function;
- Each target is a full 16-point truth table with output strictly 8/8 balanced;
- 8 SMC replicas, 4,096 particles per replica;
- 4,194,304 direct prior draws calibrate the high-loss overlap region;
- No loss gradients are used.

## 3. Limits

The full-target volume `V_full(f,epsilon)` and the candidate cell mass under a fixed partial training set are not the same quantity; E19 measures only the former. The complex parity deep-tail lineages degenerate, so the formal conclusion is restricted to the common loss range where the replica intervals are stable, and we do not pretend to have completed the pre-registered slope below 0.04.

## Results, interpretation, and limits {#results}

## 1. SMC calibration

Across the 7 overlap points where both SMC and brute-force prior have nonzero counts, the maximum absolute log-volume error is 0.119 and the maximum ratio error is about 12.6%; the overlap-region calibration for simple targets passes.

## 2. Strict ordering of the parity family

At 0.68, 0.65, 0.60, and 0.55, which all four parities complete together, the following holds:

$$
V_{p1}>V_{p2}>V_{p3}>V_{p4},
$$

and the most unfavorable intervals across the 8 replicas do not overlap either. For each additional parity-participating bit, the `-log V` cost at fixed loss is approximately linear, with the four-point fit giving `R^2=0.981--0.994`; this relation is treated only as an exploratory within-family formula.

## 3. Majority and random targets separate from approximate to exponential

The two have approximately equal volumes over BCE 0.68--0.55, with the random one even slightly larger; starting from 0.50 majority overtakes it, with the ratio about 34.6x at 0.45, about `5.6e3` at 0.40, and about `1.5e18` at 0.30. In the 0.50--0.30 range where 12--51 lineages still remain, the direction and the enormous effect do not depend on the deepest-tail degeneration.

This directly proves that the volumes of different full targets are not `a function constant x a common loss factor`: lower loss systematically amplifies structural differences.

## 4. Human-formula complexity is not a uniform cross-family ordering

Parity2 is far shorter than a random truth table in human logical language, yet in this tanh reference machine its prior mass and target-loss volumes are instead smaller. The misalignment of the parity spectrum and gradients makes the machine-relative difficulty run in reverse order to the gate-circuit length. Therefore "simple" must be a protocol-relative object, and one cannot directly claim to have measured a machine-independent Kolmogorov complexity.

## 5. Verdict

E19 strongly supports: the low-loss parameter mass of full targets has rule-specific, scale-dependent contraction curves; within a family, structural difficulty yields a stable ordering, while across families a full profile and protocol features are needed. It does not yet prove that these full-rule volumes can, without bridging, directly predict candidate-function odds for arbitrary partial training sets.
