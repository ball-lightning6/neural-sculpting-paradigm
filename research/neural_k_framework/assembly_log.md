## 1. 短论文范围冻结

### 结构冻结

正文采用时间顺序，不再按主题重排实验。每个阶段固定使用：

```text
当时问题 -> 竞争解释 -> 实验 -> 结果 -> 理论修正 -> 边界
```

第2节只提供读懂实验所需的最小定义，最终统一理论放在完整时间线之后。后续审阅只追加下一时间段，已经完成的段落除事实勘误外不再返工。

### 每个实验单元的上传标准

每确认一个明确实验，必须同步完成：

1. 稳定实验 ID 与正文链接；
2. `MOTIVATION_AND_PREREGISTRATION.md`：原因、竞争预测、判据；
3. 冻结的自包含脚本与源码 SHA256；
4. `RESULTS_AND_CONCLUSION.md`：配置、关键数字、结论与边界；
5. `README.md`：运行顺序和文件导航；
6. 发布 manifest 登记。

原始结果 ZIP 只在本地用于数字复核；对于可在消费级 GPU 上快速复现的实验，不进最终上传包。只有昂贵或难以再生成的结果才另行决定是否归档。

### 两条全文认识论原则

1. **训练 loss 优先。** 网络的显式数据目标是降低训练目标；泛化、外部语义和 validation 表现是待解释的结果，不是隐藏目标。
2. **生成器不享有训练内特权。** 研究者知道样本来自`g*`，只使`g*`成为外部 generator-aligned 基准。有限 D 内的其他兼容延拓必须作为真实竞争函数分析。

此后写作统一避免未经限定的“真实规则”“伪规则”“网络发现正确答案”。样本少、模式不平衡或函数空间太小时，必须先列出 D 允许的竞争函数，再讨论体积与训练选择。

### 中心命题

> 固定神经协议后，训练数据和连续 loss 定义函数分辨的低-loss 参数质量；该质量随 loss 发生函数特异、尺度依赖的重排，并能预测样本辨识相变和未见样本行为。真实优化器受这一静态几何影响，但不是其无偏采样器。

### 主文保留

1. 条件初始化先验与真实训练函数分布的直接冲突；
2. post-fit 完整函数迁移；
3. loss-resolved 函数体积与 Neural K-profile；
4. full-rule、固定 D 与 hard-margin 测度闭环；
5. 体积 profile 对`n50/n90`的前瞻预测；
6. hard-cell 内部深尾交叉；
7. MNIST 逐样本预测与 U 形；
8. optimizer gap、parity 入口、噪声作为必要边界。

### 主文排除或只作一句背景

- 百余任务逐项展示、Neural CPU、完整符号主义/连接主义论述；
- 人类意识、LLM 意识、耗散结构和宏观哲学外推；
- 隐藏层计算压力、持续学习、主动学习工具化；
- 大量论文阅读过程和研究者评价；
- 所有尚未预注册复现的高 agreement→人类可读强猜想。

这些内容进入长论文、附录或未来独立工作，不挤进短论文主链。

用户对结果前动机的复述已经确认：极端欠约束下仍跨 seed 稳定泛化，迫使强静态图景承担“所有替代函数的总条件先验质量都指数小”的预言。单个替代函数概率很低并不够，因为候选数量可能指数多；该预言反直觉但逻辑上并非不可能，因此不能靠直觉否定，必须直接测量。

E02 已经形成短论文§3.2完整正文与上传五件套。该阶段还冻结了全文方法论原则：网络训练直接优化训练目标，外部生成规则、validation 和语义不变性不是隐藏目标；泛化必须由训练 loss 几何与归纳偏置的对齐来解释。

E03 已经形成短论文§3.3和上传五件套。该阶段主动删除了 DSL/K 主判据，避免用后验定义复杂度再解释同一后验；实验只建立无循环事实：prior-consistent 函数被一次更新大规模重写、post-fit 继续迁移、定性现象跨宽度保留而具体后验依架构。

压缩即智能、MDL 和 weight decay 不作为 E03 测量定义，而统一放在最终理论关系§4.5--4.6：lower loss 通过协议相对体积产生隐式 MDL 偏好，不是显式双目标；weight decay 可修改路径但不是 grokking 定义条件。

E04 已经形成短论文§3.4和上传五件套。该阶段首次明确提出训练集与网络协议共同决定“低-loss 极限目标”：它后来被严格化为随 loss 阈值变化的函数质量分布，而非唯一权重或唯一 hard function。同期还提出 MDL 辨识样本量与规则难度的联系，并预言 grokking 数据相变可以成为协议相对复杂度的操作量；这时只是前瞻假设，不能把后来的 Neural K 与`n50/n90`结果倒灌为 E04 的实验结论。

E05 已经形成短论文§3.5和上传五件套。它由 Göring 等人“feature learning 不等于 generalization”的概念清理直接触发，并反向检验固定 NTK 已经足够时真实网络是否仍会重组表示。结果把两个对象拆开：匹配架构的无限宽 NTK 完整零错误，而有限宽网络仍表现出跨 BCE/MSE 的 kernel、隐藏表示和门控变化。该实验不测 Neural K，也不把 feature learning 本身写成泛化或压缩的充分证据。

19:20以后的随机标签/五层 Rule 30 agreement 扫描已经审阅，但不单独建立实验编号，也不进短论文主链。它否定了当时“随机标签会恢复初始化先验中横跨多种复杂度的宽分布”这一设想，并暴露 agreement、函数分散度和复杂度代理宽度不能混同；然而其单个随机映射、Walsh/ANF/zlib 等代理及窄复杂度带解释都没有进入最终 loss-resolved 理论。后续函数分辨 SMC、测度闭环和共识实验使用了更直接的对象，已实质取代这条支线。四个结果包只保留在总账和原仓库中，不为短论文重复冻结上传副本。

E06 已经形成短论文§3.6和上传五件套。清晨的 agreement 讨论作为后来 teacher-free 共识猜想的理论前身写入正文，但没有伪装成当时已经完成的实验。上午的静态采样第一次把连续训练 loss 变成函数分辨坐标：双样本在 raw/normalized/fixed-scale 三种口径下都强烈放大 SGD 吸引子，四样本又直接排除“SGD 等于静态退火”。因此本阶段确认的是函数特异的 loss 质量重排，而非普适的“预定简单函数全程单调增加”。

E07 已经形成短论文§3.7.1和上传五件套。width-16 函数游走提供高时间分辨率轨迹，matched-loss 对照则给出本阶段最耐久的裁决：静态几何会识别 SGD 后来利用的候选函数，但相同 normalized loss 下的函数赔率仍可相差约34倍，故 optimizer 分布不是静态 posterior。晚期再扩张、无效绘图子图和自动 normalized 匹配 bug 均已明确标注，不让 pilot 承担跨架构定律。

E08 已经形成短论文§3.7.3和上传五件套。四格 Joint/Split 干预把“特征复用有助于降低 loss”从直觉变成有限容量下的因果唯象事实；主裁决采用最佳可达 loss 与首次到阈值，排除了最后 checkpoint 坍缩的污染。该实验不直接证明内部符号变量、层间均摊或人类概念化，相关内容只作为 OOD 语义的候选宏观连接。

E09 已经形成短论文§3.8.1和上传五件套。它没有完成80%噪声的99.99%插值，因而不声称测得强插值终态；但最佳点几乎复现约91%现象，并显示噪声拟合从约20%推进到33%--63%时，clean test 已稳定崩至23%--32%。它负责冻结“loss 是唯一显式目标，压缩和泛化均为条件性结果”这条全文认识论原则。

E10 已经形成短论文§3.8.3和上传五件套。广泛4-bit 复杂度面板先否定无条件简化，严格 simple/complex 函数对随后在 raw BCE 下给出12/12显著 simple-odds enrichment。旧 ZIP 摘要的可靠性标准已被废弃；正文使用`baseline_count*fraction>=20`对两函数分别成立的重审计。normalized/fixed-scale 降为机制诊断，不再参与 raw 命题裁决。

E11 已经形成短论文§3.8.5和上传五件套。它在相同 raw BCE 下直接测量数据量如何改变 train/validation 梯度对齐：BCE 0.3至0.003的所有截面、五个 seed 分别都保留样本量严格次序。它是“有限 D 只支持规则下降到有限 loss 深度”的局部动力学证据，不被写成整个参数空间的静态体积定理。
