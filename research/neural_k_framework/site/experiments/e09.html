E09：MNIST 80%隐藏标签噪声长训

该实验区分两个经常被混写的命题：

复现脚本
experiment_mnist_hidden_noise_long_training.py

实验概览

目的

该实验区分两个经常被混写的命题：

  1. 含80%错误标签的 MNIST 训练集仍能在早期学到真实数字规则；
  2. 网络已经充分记忆80%错误标签后，是否仍保持约91%的干净测试准确率。

实验固定一次标签污染，不向网络提供噪声身份，并把最佳验证点、首次近完全插值和长训终点严格分开。

为什么做、怎样判决

1. 争议命题

相关公开说法常被转述成：MNIST 训练标签即使80%错误，学生网络仍可达到约91%测试准确率。真正需要区分的是：该数字出现在模型只学习20%相干信号的早期，还是已经充分记忆错误标签后的插值终态。

若是前者，现象只是“强共享信号先于噪声记忆”；若是后者，则要求 optimizer 形成一种训练点局部记忆而未见输入默认使用规则的特殊分解。

2. 实验设计

  • MNIST：50,000训练、10,000干净 validation、10,000干净 test；
  • 固定污染40,000个训练标签，不向输入添加任何噪声标记；
  • clean/noise80 采用逐元素相同初始化和相同数据顺序；
  • 每种架构3 seeds；
  • overparam_cnn：约1,260,810参数；
  • hinton_small：约23,603参数；
  • Adam，weight decay 为0，最多300 epochs。

3. 三个冻结判决点

  1. best_validation：干净 validation 选择的早停点；
  2. first_interpolation：noisy train accuracy 首次达到99.99%；
  3. final：插值后继续40 epochs，或300 epochs 预算终点。

同时记录：

  • noisy 训练标签准确率；
  • 同一训练图片相对隐藏真值的准确率；
  • 污染子集上对错误标签和真实标签的分别准确率；
  • 干净 validation/test 准确率；
  • noise 模型与配对 clean 模型在 test 上的 agreement。

4. 预先声明的边界

  • 如果300 epochs 内未达到99.99% noisy interpolation，实验不能裁决完整插值终态；
  • 干净 validation 用于人类模型选择，不属于网络训练目标；
  • 固定随机标签噪声是不可复用残差的受控放大，不等同于所有现实数据噪声；
  • 测试准确率下降只说明外部真值被破坏，不表示训练目标恶化。

结果、解读与边界

1. 最佳验证点几乎精确复现91%现象

架构 最佳epoch 最佳test 当时noisy train 污染子集拟合错误标签 污染子集遵循真值
overparam CNN 4 91.890% 19.441% 约1.26% 约90.63%
Hinton small 5 93.893% 19.621% 约1.03% 约92.5%

最佳点的 noisy train accuracy 约19.5%，基本就是20%未污染标签与随机碰巧正确的贡献；污染子集几乎仍在遵循真实数字标签。约91%的现象因此位于规则已学会、噪声尚未实质记忆的早期阶段。

2. 继续降低 noisy 训练 loss 会破坏规则

架构 最终noisy train 最终test clean对照最终test
overparam CNN 62.512% 22.793% 约99.29%
Hinton small 33.456% 32.423% 约99.25%

overparam 模型到 epoch 300时，污染子集对错误标签准确率约59.42%，对真实标签只剩约11.47%。其 test 准确率22.79%，与配对 clean 模型的 test agreement 22.80%几乎重合。从 epoch 5以后，noisy train accuracy 与 clean test accuracy 的相关系数为-0.941，小模型为-0.980。

clean 对照同样长训仍维持约99.3%，排除了“训练时间本身必然损害测试性能”。损害来自继续满足固定错误训练标签。

3. 严谨边界

两个架构在300 epochs 内都没有达到99.99% noisy interpolation。因此不能声称本实验已经测得“完整记忆80%噪声后的最终测试准确率”。可以稳健声称的是：

噪声拟合远未完成时，外部规则性能已经从约92%--94%降至约23%--32%，且整条300-epoch 轨迹没有后期恢复迹象。

4. 理论作用

E09 将普通过拟合放大为两个清晰阶段：

通过共享结构同时降低许多样本loss
-> 共享信号基本耗尽
-> 通过样本级残差继续降低训练loss
-> 整体函数被持续改写

它直接支持“loss 是显式目标，压缩是条件性路径，泛化是外部结果”。网络没有获得“哪些标签是真值、哪些是噪声”的 oracle；干净 validation 之所以有用，是研究者把真正关心的外部语义重新注入模型选择。

该实验同时否定任何普适的loss 下降 => 外部规则或程序复杂度持续改善命题。
