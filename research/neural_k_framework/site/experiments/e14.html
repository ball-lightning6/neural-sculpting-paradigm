E14：加权 Rule-bit 的 loss 阶段函数换序

E14 人为构造多数 Rule110 与少数 Rule30 的层级约束，使高 loss 时忽略少数分支最经济，而极低 loss 时必须满足完整复合映射。它直接检验固定 hard function 的概率是否必须随 loss 单调。

复现脚本
experiment_weighted_rulebit_sgd.py

实验概览

目的

E14 人为构造多数 Rule110 与少数 Rule30 的层级约束，使高 loss 时忽略少数分支最经济，而极低 loss 时必须满足完整复合映射。它直接检验固定 hard function 的概率是否必须随 loss 单调。

为什么做、怎样判决

1. 构造

输入含一个 rule bit。rule bit 0对应 Rule110，rule bit 1对应 Rule30。训练目标按：

Rule110 : Rule30 = 1, 10, 100, 1000, 10000

加权。少数 Rule30 样本绝对数量仍足以表达规则，但对高 weighted loss 的贡献可被多数分支暂时忽略。

2. 竞争预测

  • 若固定 hard 函数概率对 loss 全程单调，则Rule110-both不应先增后减；
  • 若不同 loss 深度激活不同约束，训练应先优化多数分支，随后逐位修正三个冲突 neighborhood，最终形成完整复合映射；
  • 权重比若只平移有效 loss 尺度，则用少数权重epsilon归一化后，各比例迁移应塌缩。

3. 配置

  • 4 -> 64 x 3 -> 1 GELU+LayerNorm；
  • plain full-batch SGD，学习率0.05，无 momentum 和 weight decay；
  • 每个比例512个 paired seeds，共2,560个模型；
  • matched weighted raw-BCE first crossing；
  • 最长运行125,204步。

4. 边界

该实验有意通过样本权重制造约束接管，证明“可以非单调”，不主张所有自然数据集都出现同一路线。完整复合函数在足够低 loss 处还受到 hard 约束强制，不能单独解释成 MDL 终点证据。

结果、解读与边界

1. 固定 hard function 明确先升后降

Rule110-both=0x6E6E的概率轨迹：

Rule110:Rule30 峰值 峰值loss 完整复合函数接管
10:1 25.78% 0.2 100% at 0.01
100:1 52.93% 0.05 100% at 0.001
1000:1 54.69% 0.005 100% at 0.0001
10000:1 51.76% 0.0005 100% of 501 at 0.00001

同 seed 转移排除了不同 seed 群体替换：例如1000:1峰值时的280个 Rule110-both 模型，257个在更深 loss 成为完整复合函数；10000:1对应260/260。

2. 迁移由三个冲突约束逐步接管

多数分支先固定为 Rule110 低字节0x6E，少数分支依次沿：

0x6E -> {0x4E,0x2E} -> 0x0E -> 0x1E

逐位修正 Rule110 与 Rule30 在100、101、110上的冲突。转换不是一次发现完整规则，而是不同权重尺度的训练约束随 loss 深入逐步接管。

3. 权重比例主要平移 loss 尺度

令epsilon=1/(ratio+1)，100:1、1000:1、10000:1的迁移在loss/epsilon坐标近似塌缩。Rule110-both 的 hard-function loss floor 满足：

$$ L_{floor}/\epsilon=(3/8)\ln2. $$

最终换序正好发生在该下界附近。

4. 训练会主动恶化少数分支

10000:1条件 step 500时，总 weighted BCE 已降至0.000979，Rule30 分支 BCE 却从初始0.728升至1.297；最终总 loss 继续降低，Rule30 分支才降至0.0145并形成完整映射。网络没有外部“完整复合函数”目标，只优化给定加权训练 loss。

5. 阶段裁决

E14 直接否定：

固定 hard function 在不同 loss 区域中的相对概率必然单调。

它支持：数据权重和 loss 深度共同决定当前有效约束；中间函数质量可以多阶段换序，训练甚至可先系统远离外部完整规则再返回。该结果是动力学构造，不等于静态体积具有相同轨迹。
