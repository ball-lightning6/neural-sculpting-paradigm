E24：深尾 Neural K-profile 与排序交叉

E24 先在4-bit、54条完整规则上把 Gaussian 参考体积推进到 hard-exact 区域，再选择唯一仍在追赶 parity4 的单点例外规则。随后从共享父系综并行推进两条分支，直接测量体积比是否在更深 loss 发生反转。

实验概览

目的

E24 先在4-bit、54条完整规则上把 Gaussian 参考体积推进到 hard-exact 区域，再选择唯一仍在追赶 parity4 的单点例外规则。随后从共享父系综并行推进两条分支，直接测量体积比是否在更深 loss 发生反转。

python experiment_4bit_deep_volume_flow.py

为什么做、怎样判决

1. 问题

E23 显示局部收缩速度和绝对体积排名均会随 loss 变化。接下来的可证伪问题是：

  1. 排名变化是否只是浅 loss 噪声；
  2. 进入 hard-exact 区域后，曲线是否仍能交叉；
  3. 单个 hard function ID 是否足以定义复杂度状态。

2. 54规则深尾面板

固定4 -> 16 -> 1 tanh、97参数、标准 Gaussian 神经坐标和 prior-preserving pCN。目标包含6条结构规则、16条 parity4 单例外、16条平衡双例外及16条随机平衡规则。8副本 x8,192粒子推进25个阈值，从 BCE 0.700到0.01913；hard-exact 充分边界为ln(2)/16=0.04332。

按预先规则选择在最深共同阈值上绝对体积最接近 parity4、且局部收缩率可靠更快的候选，再做共享父系综验证，避免独立 SMC 归一化偏移制造虚假交叉。

3. 共享父分布判决

候选为：

parity4          = 0x6996
parity4_flip0000 = 0x6997

共同父分布后用8副本 x32,768粒子同步推进。定义

$$ R(\epsilon)=\log\frac{V_{parity4}(\epsilon)}{V_{flip}(\epsilon)}. $$

R>0表示单点例外体积更小。严格停止标准要求连续五个窗口8/8副本同时满足R>0且相对局部收缩率为正；中位交叉与该严格标准必须分开报告。

结果、解读与边界

1. 4-bit 面板筛出唯一追赶者

54/54目标完成。最深五个阈值上，六条结构规则的绝对体积和速度排序均稳定；parity4 在全部25个阈值上都是面板中体积最小者。16条随机、16条双例外和15/16单例外均未追上 parity4。

唯一候选flip0000在epsilon=0.01913仍比 parity4 大约exp(13.65)，但最后窗口收缩率为159.49，对比 parity4 的152.75，八副本区间完全不重叠。独立曲线外推的交叉位置约epsilon=0.0025。

2. 共享桥确认绝对体积反转

共享父系综下，中位体积比在

$$ \epsilon_{cross}\approx0.002308 $$

处穿过零点，与独立外推高度一致。最深阈值epsilon=0.000952时，中位R=16.82，即 flip 体积约比 parity4 小2.0e7倍。7/8副本已绝对反超，8/8副本的局部相对收缩率均为正，交叉后差距仍在扩大。

预注册严格停止标准要求8/8副本连续五窗绝对反超，当前未满足；因此只能写“中位及7/8副本已反超，全部副本继续向同一方向”，不能写成“全副本稳健标准通过”。

交叉后的排序与此前 leave-one-out 训练偏好同向：从 parity4 真值表留出0000时，缺失标签的多数预测偏向 parity4，而不是flip0000，尽管没有达到100%。这构成 full-rule 深尾体积与 fixed-$D$ 局部预测之间的一致性旁证。

它不是4-bit grokking 相变的直接测量。Leave-one-out 只对应 $n=15$ 的一个固定训练集分支；随机训练集恢复率和n50/n90必须像 E23 那样另行扫描。E24 的作用是证明 profile 自身会换序，并检验 E20 条件测度链的前半段。

3. 交叉不是 hard function 切换

二者从很早开始就各自100%固定为不同 hard function，交叉发生在 hard-exact 深尾。表示和 margin 指标在交叉点附近平滑变化，没有同步的离散跳跃。这说明相对复杂度换序可以由长期连续收缩率差累积产生，而不要求 hard ID 或某个表示指标突然相变。

4. 理论裁决

  1. K^N_f(epsilon)不是由 prior 概率或单个斜率决定的固定排序；
  2. hard function ID 内部的连续 logit、margin 和表示实现是必要状态变量；
  3. 单点不可复用例外的深尾成本可以晚于 parity 的架构错配成本显现；
  4. 复杂度应以 profile 为主，局部斜率和曲率为导出量；
  5. 该静态结果不证明 SGD 在交叉点发生 feature learning，只刻画它面对的几何压力。
