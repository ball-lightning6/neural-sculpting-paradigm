E07：函数 ID 迁移与 matched-loss 静态对照

E07 把 E06 的静态 loss 几何与真实 optimizer 运输放进完全相同的微型协议中比较：

复现脚本
experiment_function_id_wandering.pyexperiment_wandering_matched_loss_prior.py

实验概览

目的

E07 把 E06 的静态 loss 几何与真实 optimizer 运输放进完全相同的微型协议中比较：

  1. 直接记录训练集完全拟合以后，每条轨迹的完整 function ID 怎样变化；
  2. 对同一网络、同一训练集大量采样未训练权重；
  3. 在几乎相同的 normalized loss 下比较静态函数质量与 SGD 函数分布。

它回答的不是“函数是否会动”，而是“相同 loss 是否足以决定相同函数分布”。

为什么做、怎样判决

1. 问题

E06 已经证明静态低-loss 质量会重排完整函数，但四样本条件也证明静态退火不能替代 SGD。E07 因此把函数分布粗粒化为可精确追踪的 function ID，直接测量：

  • 单个模型在 hard fit 后是否继续跨函数 cell；
  • 迁移是随机跳跃还是集中到少数通道；
  • 多 seed 分布是否趋于稳定；
  • 静态先验在同等 loss 下是否给出相同分布。

2. 函数迁移实验

  • 任务：4-bit -> 1-bit，完整16点可穷举；
  • 训练集：6个固定平衡样本，留下10个未见输入和1,024个 hard-compatible 函数；
  • 网络：4 -> 16 x 3 -> 1 tanh；
  • 模型：1,024个独立 seed；
  • 优化：full-batch Adam，学习率0.003，weight decay 为0；
  • 对齐：按每条轨迹首次达到训练集100% hard accuracy 对齐；
  • 观察：post-fit 20,000步，密集保存 function ID 与部分 logits。

训练标签事后发现恰好满足y=x1。这不是预注册目标，因此相关规则解释只作为结果审计，不能伪装成实验设计时已知。

3. Matched-loss 静态对照

第二个脚本在完全相同的网络和训练集下采样4,194,304个未训练网络，先筛选 hard-exact 权重，再用两种方式与 SGD 年龄对照：

  1. raw BCE 子水平集或exp(-beta L)重加权；
  2. RMS-normalized BCE 退火，在静态和 SGD 平均 normalized loss 近似相同时比较 function ID 分布。

4. 判据

  • function-ID 转换次数、Hamming 距离、转移边与停留时间；
  • 多 seed 函数熵、top-state 质量与 agreement；
  • 静态/SGD 分布的 JS divergence；
  • ID 666与 ID 722的静态和动态赔率；
  • 相同 normalized loss 是否产生相同函数分布。

5. 边界

  • 宽度16是高密度轨迹 pilot，不承担跨宽度普遍性；
  • 极低 loss 接近 Adam eps=1e-8和 float32 数值尺度，晚期再扩张谨慎解释；
  • wandering_overview.png右下累计转换子图错误使用最终总数，禁止引用；
  • 原结果包自动生成的normalized_loss_match_*误拿 raw SGD loss 作匹配目标；正文 normalized 对照必须使用保存 logits 后的独立复算；
  • hard function ID 相同不表示连续 logits、margin 或内部实现相同。

结果、解读与边界

1. Function-ID 迁移不是随机漫游

1,024条轨迹全部拟合训练集，其中1,019条在首次拟合后至少改变一次完整函数：

  • 总转换4,379次；
  • 平均4.28次，中位数4次；
  • 90.9%的转换只翻转一个未见输入 bit。

函数分布从首次拟合时的熵5.217 bit、top 质量12.1%、agreement 0.683，收缩到 age 10,000时的熵1.291 bit、top ID 722质量79.8%、agreement 0.945。这是沿相邻 function cells 发生的定向弛豫，不是对1,024个兼容函数的无结构随机游走。

2. 人类最短规则与网络吸引函数不同

六个训练标签事后恰好符合y=x1，对应 ID 666。ID 666在首次拟合时最常见，但长期主导函数变成 ID 722：

1[2*x0 + 4*x1 - 2*x2 + 2*x3 - 3 >= 0]

ID 722只在两个未见输入上偏离x1，也是线性阈值函数。1,024个兼容函数中只有81个线性可分，而 age 10以后100%的模型都位于该家族。结果证明网络强烈偏向一个窄函数族，但“简单”不能由人类表面公式长度单独指定。

3. 极低 loss 下的晚期再扩张

age mean loss top质量 函数熵 agreement
14,000 5.83e-8 81.2% 1.234 0.948
17,000 2.01e-8 85.8% 1.073 0.953
20,000 9.39e-9 77.1% 1.450 0.936

因此 loss 下降不保证 function entropy 单调下降。不过该阶段已接近 Adam epsilon 与 float32 敏感区，且网络宽度只有16；本文只把它作为“全程单调强命题不安全”的警告，不据此提出普适第二相变。

4. 同 normalized loss，静态和 SGD 分布仍不同

419万未训练网络中只有25,935个 hard-exact，最低 raw BCE 为0.6061。SGD 在 age 2已经降到0.6006，随后迅速进入初始化直接采样完全覆盖不到的区域。因此 raw loss 无法完成深层 matched comparison。

独立复算 normalized BCE 后，静态beta=128与 SGD age 20,000可比较：

指标 静态退火 SGD age 20,000
mean normalized BCE 0.2885 0.2903
函数熵 3.139 bit 1.450 bit
ID 666质量 30.6% 2.9%
ID 722质量 23.9% 77.1%

两分布JS 0.378 bit -

静态几何并非无信息：ID 722从 hard prior 的0.94%升到23.9%，已经被识别为优势候选；但 SGD 进一步把它推至77.1%，并压掉静态更偏爱的 ID 666。甚至 SGD age 20与20,000的 normalized loss 近似，函数分布仍完全不同，显示明显历史依赖。

5. 阶段裁决

E07 支持：

静态 loss 几何为 optimizer 提供强候选结构，但相同训练集和相同标量 loss 不足以决定函数分布；真实训练还包含定向、历史依赖的概率运输。

它将“不同 seed 是 Bayesian posterior samples”降为不成立的强等同关系，同时又解释了静态 posterior 为何常有一阶预测力：静态和动态分布共享同一 loss 地形，optimizer 却按流入通道、路径和停留性质重新加权其函数质量。

不能声称：

  • width 16的精细吸引子排序跨架构不变；
  • 晚期再扩张是普适物理相变；
  • ID 722比x1具有更低的机器无关 Kolmogorov complexity；
  • 相同 hard function ID 代表内部程序已经停止变化；
  • 静态体积与动态集水区之间已有已知换算公式。
