E13：AND shortcut 的 SGD 运输与单样本干预

E13 检验 E12 的静态函数换序是否会在真实训练中出现，并用相同初始化、只替换一个训练样本的配对干预判断数据几何能否因果改写长期函数分布。

复现脚本
experiment_and_shortcut_sgd_dynamics.py

实验概览

目的

E13 检验 E12 的静态函数换序是否会在真实训练中出现，并用相同初始化、只替换一个训练样本的配对干预判断数据几何能否因果改写长期函数分布。

为什么做、怎样判决

1. 竞争解释

E12 发现原始 AND、n=10的静态低-loss 区域偏向 F500/F550 shortcut。可能解释包括：

  1. 静态质量会预测 SGD 进入同一 shortcut 家族；
  2. optimizer 完全忽略该静态结构；
  3. 初始 seed 预先决定终点，与数据缺口无关；
  4. 继续训练最终总会恢复 AND，数据不足只影响速度。

2. 配置

  • 网络：4 -> 64 x 3 -> 1 GELU+LayerNorm；
  • full-batch AdamW，学习率1e-3，weight decay 为0；
  • 每条件2,048个 seed；
  • 完整枚举16点 hard function；
  • 原始缺口与最小平衡 n=10使用相同初始化 seed；
  • 发布复现固定50,000步；原始归档另延长至127,458步验证平台。

最小干预只做：

删除 1101 -> 1
加入 1000 -> 0

其余9个样本不变。

3. 判据

  • 训练集首次100% hard-exact 时刻；
  • AND、F100、F500、F510、F550 及单点邻居的质量轨迹；
  • 平均未见例外数、函数熵和 agreement；
  • 插值后迁移来源；
  • 50k 以后分布平台稳定性；
  • 相同 seed 在数据干预前后的函数和例外数变化。

4. 边界

  • optimizer 分布不应与 E12 静态体积数值等同；
  • 原始数据未唯一辨识 AND，因此长期混合平台不是“没有学会正确答案”的内部定义；
  • 50k 复现预算用于核心配对，127k 只验证原始平台不会继续自动收束；
  • 小型4-bit 空间放大单样本影响，跨规模普遍性需其他实验支持。

结果、解读与边界

1. 原始缺口快速进入 shortcut 家族

首轮四条件共8,192个模型在 step 20前后全部拟合训练集。原始 n=10中：

step AND F100 F500 F510 F550 平均例外数
20 0.83% 10.94% 6.84% 26.71% 19.43% 2.870
100 0.63% 12.16% 8.45% 34.81% 22.71% 2.783
5,000 8.35% 22.41% 11.87% 21.24% 20.41% 2.300
20,000 21.19% 26.12% 11.33% 13.92% 12.55% 1.767

SGD 复现了静态预测的 shortcut 家族，但具体权重不同：F510 是早期主要赢家，F100 在深训练后成为第一名。静态几何识别候选方向，optimizer 决定族内运输。

2. 长训不会自动恢复唯一 AND

原始条件延长至127,458步：

  • AND 22.51%；
  • F100 25.29%；
  • F550 14.21%；
  • 平均例外1.771；
  • 函数熵约2.83 bit；
  • 未见准确率约70.5%。

50k 以后各指标进入窄平台；100k 到终点98.3%的模型 hard function 不变。loss 仍降至2.06e-9，但函数分布不再向唯一 AND 收束。因此无限延长训练不能替代缺失数据。

3. 一个样本替换系统性改变长期分布

平衡条件 step 50,288：

AND             64.94%
D000            16.02%
F040             8.35%
F050             5.62%
平均例外          0.450
函数熵            1.711 bit
未见准确率        92.50%

网络在 step 20已完全拟合，此时 F050 为42.58%、AND 为21.58%；随后 F050 降至5.62%，AND 升至64.94%。最终1,330个 AND 模型中72.1%是在插值后由 shortcut 迁移而来。

与原始条件同 seed 比较到50k：69.97%的 seed 例外减少，21.73%不变，8.30%增加，平均减少1.337个错误点。原始 F100/F500/F510/F550 终点中，平衡后成为 AND 的比例分别约75.1%/66.4%/56.3%/52.8%。初始化没有预先固定终点。

4. 静态与动态的共同结构及差异

平衡静态几何已经显示中等 loss 先提高 F050 相对优势、深 loss 再提高 AND；SGD 沿同一阶段方向产生更强烈换序。静态最低0.2%中 AND 为28.10%，SGD 最终为64.94%，且真实训练进入的 BCE 远低于直接 prior 采样覆盖范围。

5. 阶段裁决

E13 建立：

  1. lower loss 的优势函数会随训练阶段换序；
  2. 插值后继续训练可将概率质量从多例外 shortcut 运向较少例外规则；
  3. 数据欠定时，该压缩会停在稳定混合平台而非唯一生成器；
  4. 只替换一个有判别力样本即可因果改变早期 shortcut 和长期分布；
  5. 静态 loss 几何与 SGD 方向相关，但 optimizer 不是静态采样器。

这直接否定“同一预定简单函数在整个 loss 轴上始终占优”，并促使最终理论采用 loss-resolved Neural K-profile，而非单一复杂度排序。
