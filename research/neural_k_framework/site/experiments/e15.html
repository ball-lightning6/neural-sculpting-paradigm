E15：Mod97 grokking 的完整函数与边缘凝聚

E15 在原版风格 Mod97 除法任务中同时跟踪完整9,312点 hard function、逐输入边缘众数、agreement、target-function 质量和 matched train CE，区分“完整函数样本仍全部不同”与“逐点预测已经围绕同一规则凝聚”。

复现脚本
experiment_mod97_matched_loss_function_distribution.py

实验概览

目的

为什么做、怎样判决

1. 问题

Grokking 前的多 seed 分布究竟是共同 shortcut，还是共享规则骨架加 seed 特异残差？只看 validation accuracy 或 agreement 无法区分。完整函数 exact 又可能过严：每个 seed 只错不同少数点时，完整 hash 仍全部不同。

2. 设置

  • 任务：x / y mod 97，完整输入空间9,312；
  • 嵌套训练比例60%、70%、80%、90%；
  • 每比例32个 paired seeds，共128个模型；
  • MLP：194 -> 512 x 3 -> 97 GELU+LayerNorm；
  • Adam 1e-3，无 weight decay；
  • 运行121,101步；
  • 在相同 train CE first crossing 处比较函数分布。

3. 同时报告的对象

  • 完整目标函数质量；
  • 完整函数 hash entropy 和 top 重复质量；
  • coordinate-wise modal function；
  • seed agreement；
  • 所有条件共用的最后10% holdout；
  • train CE 与未见准确率的关系。

4. 边界

32 seeds 只能解析不低于3.125%的单函数质量；modal function 是逐坐标边缘组合，不一定是任一单 seed 真实实现的完整函数；本实验测量 Adam 轨迹，不是静态体积。

结果、解读与边界

1. 完整函数质量需要足够数据和足够深 loss

训练比例 第一个目标seed 最终目标质量 最终函数熵
60% 未出现 0/32 5.000 bit
70% 未出现 0/32 5.000 bit
80% step 78,000 1/32 5.000 bit
90% step 12,500 18/32=56.25% 2.654 bit

90%条件中，target 质量随 matched train CE 从3e-7的3.125%逐步升到3e-11的56.25%。60%--80%的非目标完整函数几乎每个 seed 都不同，没有可重复共同 shortcut。

2. Modal function 远早于单 seed 完整恢复

训练比例 modal function成为完整目标 第一个目标seed
60% 未发生 未发生
70% 最终modal accuracy 95.41% 未发生
80% step 18,000 step 78,000
90% step 2,000 step 12,500

90%在 step 500时 modal full accuracy 已97.47%。不同 seed 错误围绕目标规则分布并在逐坐标边缘相互抵消，即使完整函数 hash 仍全部不同。

3. 公共 holdout 排除新增训练点平凡收益

最终公共10% holdout 准确率随训练比例为2.29%、16.19%、51.83%、91.65%。31/32 paired seeds 在四档严格不降；相邻数据量比较也几乎全部改善。

4. 阶段裁决

E15 建立：

  1. 数据量、loss 深度与优化时间是三个不同变量；
  2. 完整函数分布宽不表示逐输入边缘没有围绕目标凝聚；
  3. grokking 前更准确的状态是共享目标骨架加 seed 特异残差，而非共同完整 shortcut；
  4. exact function probability、hash entropy、agreement 和 modal function 必须并列报告。

它不证明静态体积因果，也不保证90%条件的其余14个 seed 最终必然到达目标。
