E11：Rule30 数据量与训练/验证梯度对齐

E11 检验：增加同一规则的训练样本，是否只改变最终泛化终点，还是会在相同 raw BCE 水平下系统性改变训练梯度与独立验证梯度的方向关系。

复现脚本
experiment_rule30_train_val_gradient_alignment.py

实验概览

目的

E11 检验：增加同一规则的训练样本，是否只改变最终泛化终点，还是会在相同 raw BCE 水平下系统性改变训练梯度与独立验证梯度的方向关系。

它为“有限训练集只支持规则对齐下降到有限 loss 深度；数据越多，该通道延伸得越深”提供局部动力学证据。

为什么做、怎样判决

1. 问题

在数据充分的合成任务中，train 与 validation loss 常从训练初期同步下降。一个过强解释是“高 loss 区域已几乎全是正确函数”；更局部、可测的解释是：数据越多，训练梯度越接近总体规则梯度，训练集特有方向在样本平均中越充分抵消。

一步小学习率更新满足：

$$ \Delta L_{val} \approx -\eta\nabla L_{val}\cdot\nabla L_{train}. $$

因此 train/validation 梯度余弦直接判断降低训练 loss 的局部方向是否也降低 validation loss。

2. 正式配置

  • 任务：30-bit 循环边界 Rule30 单步更新，输出30 bit；
  • 网络：30 -> 1024 x 3 -> 30 GELU+LayerNorm；
  • 训练样本：256、512、768、1024、1280、1536、2048、4096，严格嵌套；
  • 独立 validation：4,096；
  • 5个 paired model seeds，共40个模型；
  • Adam，学习率1e-3，batch 512；
  • dropout 与 weight decay 均为0；
  • 最大20,000步。

3. 三个梯度指标

  • train_validation_gradient_cosine：训练与独立 validation 完整梯度余弦；
  • train_half_gradient_cosine：训练集两半的梯度相干性；
  • validation_half_gradient_cosine：validation 两半的一致性参考线。

第三项只是有限 validation 采样噪声的参考，不是严格数学上限。

4. 关键控制：matched raw BCE

不同样本量到达同一 step 时 loss 不同，不能直接比较。实验在每个 seed 的log(raw BCE)轨迹上插值，在：

0.68, 0.6, 0.5, 0.4, 0.3, 0.2,
0.1, 0.05, 0.02, 0.01, 0.003

逐层比较梯度余弦和 validation-train BCE gap。

5. 预注册预测与边界

若数据量重塑的不只是终点，则在相同 raw BCE 下，训练样本越多：

  1. train/validation 梯度余弦越高；
  2. 泛化 gap 越小；
  3. 该顺序应跨 seed 保留；
  4. 低数据条件可在深 loss 转为负余弦，高数据仍保持正向。

该实验只使用一个嵌套数据排列和一个任务，不建立跨任务普适定律；梯度范数接近数值零时余弦失去意义，主分析限制在 BCE 不低于0.003的区域。

结果、解读与边界

1. 完整性

  • 8个样本量、5 seeds，共40个模型；
  • 全部运行20,000步，总耗时313.3秒；
  • 相同 seed 跨样本量具有完全相同初始化；
  • 训练集严格嵌套，validation 固定独立；
  • matched-loss 使用逐 seed 对数 loss 插值，而非最近 checkpoint 代替。

2. 相同 raw BCE 下的数据量次序

在 raw BCE 0.3至0.003的每个截面，五个 seed 分别都呈现训练样本量增加、梯度余弦严格上升的完整次序。以 BCE 0.1为例：

n train/val梯度余弦 validation BCE - train BCE
256 -0.167 0.482
512 -0.018 0.346
768 0.245 0.248
1024 0.446 0.173
1280 0.564 0.121
1536 0.671 0.091
2048 0.803 0.055
4096 0.927 0.019

在 BCE 0.01时：

  • n=256：余弦-0.237，gap 约0.693；
  • n=4096：余弦0.950，gap 约0.00137。

因此低数据条件继续降低训练 loss 时，局部方向已经主动提高 validation loss；高数据条件在同等深 loss 处仍几乎沿总体规则方向下降。

3. 从过拟合到同步泛化的连续谱

  • n=256/512在31--50步完全拟合训练集，最终 validation bit accuracy 约74.84%/92.96%；
  • n=768在67步拟合训练集，500--1000步后 validation 才超过99%，最终99.9958%，表现为平滑延迟泛化；
  • n=1024五个 seed 最终全部零错误；
  • n=4096训练和 validation exact accuracy 都约在84步达到100%，几乎同步。

在初始化附近，少量数据也能提供明显 Rule30 共有方向；数据量真正决定的是该方向可以延伸到多深的训练 loss。低数据的共享结构较早耗尽，剩余梯度转向训练集特有细节；高数据的剩余约束在低 loss 处仍保持规则相干。

4. 阶段裁决

E11 支持：

增加同一规则的训练样本，不只改变最终泛化结果，也沿 optimizer 实际轨迹系统性改善给定 raw BCE 截面的训练/validation 梯度对齐，使规则一致的下降通道延伸到更深 loss。

它为 train/validation 同步下降、平滑延迟泛化和普通过拟合提供同一局部几何解释，也支持“任何有限 D 通常只支持规则对齐到有限 loss 深度”的修正图景。

不能声称：

  • 高 loss 参数空间已经由正确 hard function 充满；
  • 梯度余弦直接等于函数体积；
  • validation-half 余弦是严格上界；
  • 单个 Rule30 数据排列足以建立跨任务定律；
  • 数值接近零梯度时的最终余弦仍有意义。
