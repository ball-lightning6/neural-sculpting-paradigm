E19：完整真值表规则的 loss-resolved 体积

E19 用完整16点训练集直接指定每条4-bit 规则，避免部分训练集究竟诱导哪个函数的歧义，并用 constrained SMC 比较不同完整目标达到相同 loss 的参数质量。

复现脚本
experiment_full_truth_rule_volume_smc.py

实验概览

目的

E19 用完整16点训练集直接指定每条4-bit 规则，避免部分训练集究竟诱导哪个函数的歧义，并用 constrained SMC 比较不同完整目标达到相同 loss 的参数质量。

运行：

为什么做、怎样判决

1. 问题

部分训练集下的赢家可能不是研究者 generator；用完整真值表作为训练目标则唯一指定规则。若复杂规则低-loss 质量收缩更快，应在同一参考机和相同 loss 阈值看到规则间体积比随 loss 系统放大。

2. 设置

  • 网络：4 -> 16 x 2 -> 1 tanh，369参数；
  • 测度：PyTorch 默认均匀初始化参数立方体；
  • 目标：parity1--4、majority3、预注册随机平衡函数；
  • 每条完整16点、输出严格8/8平衡；
  • 8个 SMC 副本，每副本4,096粒子；
  • 4,194,304次直接 prior 校准高 loss 重叠区；
  • 不使用 loss 梯度。

3. 边界

完整目标体积V_full(f,epsilon)与固定部分训练集下候选 cell 质量不是同一个量；E19 只测前者。复杂 parity 深尾 lineage 退化，正式结论限制在副本区间稳定的共同 loss 范围，不假装完成0.04以下预注册斜率。

结果、解读与边界

1. SMC 校准

与暴力 prior 均有非零计数的7个重叠点，最大绝对 log-volume 误差0.119，最大比例误差约12.6%；简单目标的重叠区校准通过。

2. Parity 族严格排序

四条 parity 共同完成的0.68、0.65、0.60、0.55均满足：

$$ V_{p1}>V_{p2}>V_{p3}>V_{p4}, $$

且8副本最不利区间也不重叠。每增加一个 parity 参与 bit，-log V成本在固定 loss 上近似线性，四点拟合R^2=0.981--0.994；该关系只视为族内探索性公式。

3. Majority 与随机目标从近似到指数分离

两者在 BCE 0.68--0.55体积近似，随机甚至略大；从0.50起 majority 反超，比例在0.45约34.6倍、0.40约5.6e3、0.30约1.5e18。在仍有12--51条 lineage 的0.50--0.30区间，方向和巨大效应不依赖最深尾退化。

这直接证明不同完整目标的体积不是函数常数 x 公共 loss 因子：lower loss 会系统放大结构差异。

4. 人类公式复杂度不是统一跨族排序

Parity2 在人类逻辑语言中远短于随机真值表，但该 tanh 参考机中其 prior 与目标 loss 体积反而更小。Parity 的频谱和梯度不对齐使机器相对难度与门电路长度反序。因此“简单”必须是协议相对对象，不能直接宣称测得机器无关 Kolmogorov complexity。

5. 裁决

E19 强力支持：完整目标的低-loss 参数质量具有规则特异、尺度依赖的收缩曲线；同族结构难度可给稳定排序，跨族则需要完整 profile 和协议特征。它尚未证明这些 full-rule 体积可未经桥接直接预测任意部分训练集的候选函数赔率。
