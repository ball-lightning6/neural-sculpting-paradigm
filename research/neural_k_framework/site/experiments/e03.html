为什么做、怎样判决

1. 循环论证问题

原计划曾试图给256个 Boolean 函数构造手写 DSL 最短长度，再检验训练是否向最低复杂度函数迁移。该方案被主动放弃，因为：

  1. DSL 最短长度只代表人为参考语言，不等于神经网络实际程序复杂度；
  2. 用训练后函数惊讶度定义“神经复杂度”，再用它解释同一后验，会形成循环；
  3. ANF、BDD、DNF 等指标可以作独立结构坐标，但没有单项足以冒充真实 K。

因此 E03 不测 K，也不把迁移方向预先命名为“压缩”。它只回答更基础的事实问题：固定训练约束后，优化是否继续系统改变完整函数？

2. E03a 设计

  • 3-bit -> 1-bit，完整256个 hard function；
  • 网络：3 -> 1024 x 3 -> 1，GELU+LayerNorm，Adam，weight_decay=0；
  • prior：65,536个初始化网络；
  • 三个部分训练集：1、2、4样本，分别留下128、64、16个 hard 兼容函数；
  • ordinary cohort：每条件128个普通初始化；
  • prior-consistent cohort：每条件512个初始化时已满足全部训练标签的网络；
  • post-fit 年龄：0到5,000步，共13个截面；
  • 同时保存 hard function ID 与完整 logits；
  • soft likelihood 温度族仅作基线，不作为事后自由调参的解释器。

主判据：prior-consistent 模型在没有新增 hard 约束时是否改变完整函数，以及 ordinary 模型在首次拟合后是否继续迁移。

3. E03b 设计

  • 与 Oxford 同族：3 -> width x 2 -> 1 tanh，无归一化；
  • sigma_w=1、sigma_b=0.2、Adam、weight_decay=0；
  • width 16/32/64/128；
  • 复用 E03a 完全相同的三组训练约束、prior/ordinary/consistent 样本量和年龄；
  • width 128作为同族锚点，1024×3仅作跨架构行为参照，不伪装成纯宽度消融。

4. 竞争预测

  • 若 hard-conditioned prior 足够，prior-consistent cohort 应保持初始函数分布；
  • 若优化主动运输函数质量，一次更新即可产生超过抽样噪声的函数迁移；
  • 若迁移只是大网络/LayerNorm 特例，tanh 小网络中应显著减弱或消失；
  • 若网络协议定义有效参考语言，具体吸引函数和概率应随架构改变，即使“post-fit 仍迁移”的定性现象保留。

5. 结果前边界

  • 不测量 Kolmogorov complexity；
  • 不用后验本身给函数贴复杂度标签；
  • 不预言人类看来最短公式一定胜出；
  • 所有主体优化仍是 Adam，不能自动推广到任意优化器；
  • aggregate 分布近似稳定不代表配对 seed 没有大量相反方向迁移。

结果、解读与边界

1. E03a：一次更新即重写完整函数

实验仍是3-bit 而非4-bit；65,536表示 prior 网络数量，不是训练了65,536个目标函数。三个训练集分别留下128、64、16个兼容函数，总训练模型为3 × (128 ordinary + 512 prior-consistent) = 1,920。

prior-consistent cohort 训练前已经满足全部 hard 标签，并且函数分布与条件先验相容。仅一次 Adam 更新：

条件 改变完整函数的模型 最大函数质量变化 训练后相对hard prior TV
1样本 72.7% 27.3% -> 100% 0.717
2样本 99.0% 7.2% -> 77.3% 0.826
4样本 97.9% 17.4% -> 39.3% 0.553

对应有限样本 null p95 约0.156、0.132和0.058，迁移远超抽样波动。

2. 迁移方向不是随机，也不等于人类最短公式

二样本训练点为立方体对角点，训练后约81%的模型集中到对称最大间隔阈值函数：

majority(not x0, not x1, x2)

四样本条件主要集中到：

x2 AND (not x1)
x2 OR  (not x1)

初始化条件先验中大量存在更短的一变量解x2和not x1，却被训练主动挤走。因此“人类 Boolean 公式更短”不是当前网络选择的充分解释；对称、margin、范数与优化几何都可能参与。

3. 首次拟合后仍有大量配对迁移

ordinary cohort 从首次拟合继续到 age 5,000：

  • 单样本：32.8%的 seed 改变完整函数；
  • 二样本：50.8%；
  • 四样本：47.7%。

四样本总体分布 TV 仅0.125，但47.7%的 seed 已换函数，说明相反方向迁移会在边缘直方图中抵消。仅看总体分布“看似稳定”会严重低估动力学。

prior-consistent cohort 到 age 5,000仍有：

  • 二样本10.5%的模型改变函数；
  • 四样本27.0%。

4. E03b：迁移稳健，具体后验依赖网络族

tanh 宽度族

  • width 16/32/64/128的初始化 hard prior 非常接近；相对128的 TV 约0.025/0.023/0.022；
  • width 64与128的最终主模式6/6一致，差异处于 bootstrap 噪声内；
  • width 16保留同一迁移方向，但改变集中速度和近并列函数排名；
  • width 16没有比64更快，六个训练块约122秒 vs119 秒。

所有宽度均保留大规模 post-fit 迁移。width 16的 prior-consistent cohort 在 age 5,000相对各自 hard prior 的 TV，single/k2/k4 约为0.828/0.850/0.565。

与1024×3 GELU+LayerNorm 比较

  • 两个网络族初始化 prior 的 TV 已经约0.29；
  • 具体主导函数和概率显著不同，全部关键比较超过抽样噪声；
  • 1024网络相应 TV 约0.717/0.840/0.471。

所以小网络没有复现大网络的具体后验，但“训练集拟合后函数质量仍被大规模运输”跨网络族保留。架构既影响 prior，也影响动力学吸引子。

5. 阶段裁决

E03 在完全不使用 K 复杂度标签的情况下建立：

  1. hard-conditioned initialization prior 不是训练后函数分布；
  2. 已经 hard-fit 的初始化函数会被一次更新大规模重写；
  3. post-fit 长期仍有配对函数迁移；
  4. 迁移方向结构化但依赖网络参考协议；
  5. aggregate agreement/TV 不能替代逐 seed 函数轨迹。

该实验没有证明迁移就是 Kolmogorov 压缩，也没有裁决“Solomonoff（1964）算法概率的宽层级 vs 最低复杂度薄壳”。它为后续复杂度理论提供了必须解释的无循环经验事实。
