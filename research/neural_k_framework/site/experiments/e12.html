E12：AND shortcut 的静态 loss 几何

为什么做、怎样判决

1. 两种避免循环论证的策略

此前实验暴露了“简单函数是谁”可能依赖训练集与网络语言。8月20日冻结了两种可证伪策略：

  1. 选择 copy、NOT、AND、OR 等极明显简单规则，并提供10--14个训练样本；
  2. 构造 simple 及其加入明确例外后的 complex 函数对，使二者在训练集上一致，complex 在表示层级上严格更难。

第一种用于全 loss 扫描，第二种已由 E10 检验。E12 追踪第一种策略中出现的 AND 反例。

2. 全 loss 扫描

  • 网络：4 -> 64 x 3 -> 1 GELU+LayerNorm；
  • prior：33,554,432个独立网络；
  • 规则：copy、NOT、AND、OR、XOR；
  • 训练样本：n=10,12,14；
  • 保存完整 prior、hard-exact cohort、累计 tail 和非重叠 loss bins 中的目标函数质量。

XOR 先验只命中17次，低于预注册50次门槛，不参与正式裁决。

3. AND 缺口干预

原始 AND、n=10包含全部4个正例和6个负例，但遗漏若干 off-diagonal 负例，允许依赖x4的 F500/F550 等 shortcut。定向静态分析固定架构、样本数和标签比例，只改变负例位置：

  • 原始逻辑缺口；
  • 分别封闭两条 shortcut 分支；
  • 同时封闭两边；
  • x4=1镜像缺口；
  • 最小平衡干预：只把1101 -> 1替换成1000 -> 0。

主要判据为 hard-exact cohort 内随 raw BCE 降低的函数概率、赔率、平均未见例外数、函数熵和每个函数在训练样本上的 signed margin。

4. 解释边界

  • 生成器 AND 不在训练内享有特权；它只是外部评估基准；
  • hard function ID 仍粗粒化连续 margin 与内部表示；
  • 静态质量不是 SGD 访问概率；
  • 若固定函数赔率发生交叉，则“同一简单函数在所有 loss 区间单调占优”直接失败，不能事后把每个赢家重新命名为更简单来回避反例。

结果、解读与边界

1. 一般倾向与一个真实反例同时出现

从完整 prior 到最低0.01% raw-loss tail，copy、NOT、AND、OR 的12个可裁决条件中，目标函数质量全部严格单调增加。最低0.01%相对 prior 富集约为：

  • copy：151--261倍；
  • NOT：193--272倍；
  • AND：87--269倍；
  • OR：189--242倍。

但先固定 hard-exact cohort 再降低 raw BCE，AND、n=10成为显著反例：AND 从8.75%降至最低10%的6.81%，富集仅0.778倍，单侧超几何p=8.60e-20。其排名从第1降到最低0.1%的第9。

2. 固定函数赔率真实交叉

原始训练集下：

lowest-loss fraction AND F550 AND/F550
100% 8.75% 6.02% 1.45
50% 7.99% 7.97% 1.00
25% 7.39% 9.04% 0.82
10% 6.81% 10.17% 0.67
0.5% 6.73% 10.58% 0.64

F550 和 F500 在外部逻辑代理上都比 AND 复杂，却能利用训练集未覆盖的x4模式，在已见样本上形成更大 margin。平均 signed margin 为 AND 0.378、F500 0.404、F550 0.444。lower raw BCE 因而系统偏向样本特异 shortcut。

3. 补洞因果改变静态赢家

只补某一边会排除旧 shortcut，却可能暴露新的copy x2解释；同时覆盖四个关键 off-diagonal 负例后，AND 从 hard-exact 40.2%升至最低10%的49.3%、最低1%的54.9%。六组随机负例子集中，AND 五组富集、一组下降，证明决定因素是具体约束覆盖而非样本数或标签比例。

4. 最小平衡干预显示两阶段静态换序

只替换一个样本后，四种(x1,x2)模式覆盖由3/2/1/4变为3/2/2/3。在76,477个 hard-exact prior 样本中：

  • AND：16.65% -> 最低0.2%的28.10%；
  • 平均未见例外：1.733 -> 1.242；
  • 函数熵：4.331 -> 3.303 bit。

但 AND/F050 赔率先从1.508降到最低10%的1.388，随后在最低0.2%升至2.231。静态截面自身已经显示“中等 loss 先强化 shortcut，更深 loss 再强化 AND”的阶段换序。

5. 阶段裁决

E12 同时建立：

  1. lower raw BCE 通常强烈富集可复用简单规则；
  2. 在固定 hard-compatible 集合内，该倾向不是无条件定律；
  3. 训练集的具体逻辑缺口可以让结构更复杂但 margin 更优的 shortcut 在某段 loss 区间占优；
  4. 只改变一个有判别力样本即可重塑完整静态函数分布；
  5. 优势函数和复杂度排序应被视为 loss-resolved profile，而非固定标量。

这不是核心理论失败，而是将“简单函数”从全程固定标签修正为必须观察完整 loss 尺度。后来的 Neural K-profile 和深尾交叉正是对此的正式化。
