E08：共享中间表示与有限容量压力

E08 检验一个唯象机制：当两个输出任务具有昂贵的共同 CA 前缀计算时，允许网络共享隐藏表示，是否比强制两条独立分支更容易达到同一极低 loss。

复现脚本
experiment_ca_shared_intermediate_pressure.py

实验概览

目的

E08 检验一个唯象机制：当两个输出任务具有昂贵的共同 CA 前缀计算时，允许网络共享隐藏表示，是否比强制两条独立分支更容易达到同一极低 loss。

实验采用四格交叉设计，使完全相同的四个原子子任务各自在 Shared 与 Separate 组出现一次；另设参数量匹配的 forced-split 架构作为阴性对照，排除标签边际或原子任务固有难度。

为什么做、怎样判决

1. 唯象假说

若两个任务重复计算同一个昂贵中间状态，共享该状态应当节省有限网络容量；若被迫分别重算，两条任务各自可用的有效容量下降，达到同一低 loss 需要更多样本、更多优化步骤或更宽网络。

该假说试图为“低 loss 为何可能偏向可复用表示”提供因果正控，但不预设网络内部一定形成研究者命名的符号节点。

2. 四个原子任务

输入由两个独立30-bit 状态u,v组成。定义：

F_k(u) = Rule30^k(u)
G_k(v) = Rule110^k(v)
A(z)   = z[:15] AND z[15:]
B(z)   = z[:15] OR  z[15:]

四个联合条件为：

shared_f    = [A(F), B(F)]
shared_g    = [A(G), B(G)]
separate_fg = [A(F), B(G)]
separate_gf = [A(G), B(F)]

因此A(F)、B(F)、A(G)、B(G)在 Shared 与 Separate 两组中各出现一次。任何组间差异不能简单归因于使用了不同原子标签函数。

3. Joint 与 Split 干预

  • Joint：两个输出共享三层隐藏网络，具备复用中间计算的通道；
  • Split：两个输出使用完全独立分支，禁止隐藏计算共享；
  • Split 每分支宽度自动设为178/359/721，使总参数量与 Joint 宽度256/512/1024的误差低于0.16%。

若 Shared 只是统计上更容易，它在 Split 中也应更容易。只有 Joint 出现额外 Shared 优势，才能归因于允许共享隐藏计算。

4. 正式配置与预注册剂量效应

  • CA 前缀深度k=0,1,2,3；
  • Joint 宽度256、512、1024；
  • 每条件3 seeds，共288条轨迹；
  • GELU+LayerNorm 三隐藏层，Adam 1e-3，weight decay 与 dropout 均为0；
  • 在线随机 CA 数据，batch 512；固定32,768 probe；最多5,000步。

主预测：

  1. Split 中的 Shared/Separate 差异应接近0；
  2. Joint 的共享优势应随前缀深度增加；
  3. 网络越宽，重复计算越容易容纳，共享优势应减弱；
  4. 优势可以表现为更低最佳 loss 或更快达到固定 loss 阈值。

5. 指标边界

固定学习率在线训练可能在达到极低 loss 后发生晚期坍缩。因此理论判决优先使用：

  • 预算内最佳 probe loss；
  • 首次达到1e-2、1e-3、1e-4的累计样本量；
  • late-collapse 审计。

最终 checkpoint 均值只用于稳定性审计，不能作为主裁决。

结果、解读与边界

1. 设计审计

  • 24/24个批量组、288条轨迹全部完成；
  • Joint/Split 参数量匹配误差低于0.16%；
  • Split 阴性对照在全部12个depth x width单元中的 Shared/Separate loss gap 约1e-8或更低；
  • 同一 seed 的四个条件使用逐元素相同初始化与相同在线输入流。

Split 近零差异说明四格原子任务难度配平成功。Joint 中的差异才是共享通道存在后新增的交互效应。

2. 晚期坍缩与主指标修正

25/288条轨迹的最终 loss 比预算内最佳 loss 恶化超过5倍。极端轨迹曾先达到100%exact 和约1e-5 loss，随后在最后区间突然升至0.2--0.33。因此最终 checkpoint 算术均值会被少数坍缩污染，结果以最佳可达 loss 和首次到阈值为准。

5. 阶段裁决

E08 允许声称：

当两个输出具有足够昂贵的共同 CA 前缀计算时，允许共享隐藏网络能用更少容量和更少在线样本达到同一极低 loss；优势随共享前缀深度增加，并随网络宽度增加而减弱。没有昂贵前缀时，任务耦合成本可抵消甚至反转共享收益。

这为“有限容量会形成计算复用压力，复用结构有利于更深 loss”提供了因果唯象证据。它不依赖用 hard function ID 猜内部程序，因此补充了完整映射体积测量无法直接分辨同一 hard function 内部实现的问题。

不能声称：

  • 网络已经显式形成研究者预设的F_k/G_k中间变量；
  • 所有层或神经元会平均承担计算压力；
  • 任何共享任务都优于分离任务；
  • 该实验已经证明 Kolmogorov complexity 定律；
  • OOD 规则语义或人类概念形成已由本实验直接证明。

OOD 语义的合理连接仍是一个宏观假说：当许多任务能够通过同一解释器、符号绑定或中间状态复用时，该共享程序可能比多套焊死电路更经济，从而获得低-loss 优势。
