E02：Rule-bit 反事实不变性与训练 loss 中心原则

检验固定控制位是否会被网络自动识别为语义无关变量，以及加入多少反事实样本才能让两条控制分支严格执行同一 ECA 规则。该实验同时区分：

复现脚本
experiment_rule_bit_invariance_completion.py

实验概览

目的

检验固定控制位是否会被网络自动识别为语义无关变量，以及加入多少反事实样本才能让两条控制分支严格执行同一 ECA 规则。该实验同时区分：

  • 训练中恒0与恒1；
  • binary 0/1与 centered -1/+1编码；
  • 已学规则后追加反事实样本（warm）；
  • 从头训练最终数据（cold）；
  • 继续训练但不加反事实样本（k=0）。

为什么做、怎样判决

1. 背景问题

E01 证明优化器不是静态 hard prior 的被动筛选器，但这不自动推出网络会恢复人类语义上最短、最纯净的程序。旧31-bit 实验中，训练只出现一个固定 rule bit，翻转该 bit 后输出仍大体执行已学规则，却没有严格不变。

这形成两个竞争解释：

  1. 语义压缩强版本：既然目标规则与 rule bit 无关，训练会自动删除该变量；
  2. 训练 loss/参数化版本：训练集没有提供反事实不变性，常数 bit 可以参与 bias、门控和表示；网络只需降低可见训练 loss。

这里外部 ECA 生成器规定的“rule bit 应当无关”只用于反事实评分。对 Stage 1训练集而言，所有在固定 bit 分支上正确的延拓都同样符合数据；不能因为研究者知道生成脚本，就预先把严格不变函数视为网络已经获得的唯一真实规则。

2. 实验前判据

不变性补全

若极少反事实样本使翻转分支在全 probe 严格等于原规则，而k=0不产生同样改善，则数据能够用很小代价补全不变性。

表示复用

若 warm 达到同样严格成功率所需样本或步数显著少于 cold，则已学主体表示对不变性补全提供正迁移。若无一致优势，不主张表示复用。

编码/参数化

若恒0、恒1或 binary、centered 结果明显不同，则语义无关性不是充分解释，网络结构与编码必须进入理论。

3. 冻结协议

  • Rule30、Rule110，各一步 ECA；
  • 输入：1个 rule bit + 30个状态 bit；输出30 bit；
  • 31 -> 1024 x 3 -> 30，GELU+LayerNorm；
  • 2,048训练状态，65,536 probe；
  • 8个 seed；Adam，学习率1e-3，batch 512；
  • dropout=0、weight_decay=0；
  • Stage 1固定 rule bit 训练8,000步；
  • warm 追加嵌套k=0,1,2,...,512反事实样本，训练5,000步；
  • cold 从相同初始化训练最终数据13,000步；
  • binary 与 centered 编码，固定 bit 0/1双向扫描。

4. 主要测量

  • 原分支/翻转分支 bit accuracy 与30-bit exact accuracy；
  • 两分支输出 agreement；
  • hard strict success 和8/8 seed 严格成功率；
  • logit 差与 rule-bit 输入列 L2 范数；
  • warm/cold 达到严格不变性的最小k。

5. 预先保留的边界

  • 训练目标没有包含“真实语义无关”这一信息；
  • 恒1可与 bias 不可辨识，恒0输入列可能完全无梯度；
  • centered 翻转比 binary 删除通路更强；
  • 成功只说明当前协议存在不变性补全偏置，不证明任意网络都会自动找出无关变量。

结果、解读与边界

1. Stage 1：原规则完全学会，反事实分支仍取决于编码

8,000步后，所有原始 rule-bit 分支在65,536 probe 上均达到 exact accuracy 1。翻转 rule bit 后的 median 结果：

编码 规则 训练固定bit flip bit accuracy flip exact accuracy 严格成功seed
binary 30 0 1.0000 1.0000 8/8
binary 30 1 0.99952 0.98561 0/8
binary 110 0 1.0000 1.0000 8/8
binary 110 1 0.79358 0.00151 0/8
centered 30 0 0.86071 0.01517 0/8
centered 30 1 0.85416 0.01137 0/8
centered 110 0 0.50286 0 0/8
centered 110 1 0.49822 0 0/8

相同语义任务仅改变常数编码，反事实行为便从完美不变到接近随机，直接否定“语义无关变量必然被自动删除”的强版本。

2. 为什么全0与全1不同

第一层写成

$$ h=W_xx+w_zz+b. $$
  • binary 固定z=0：w_z列在 Stage 1不接收梯度；
  • binary 固定z=1：数据只约束w_z+b，rule-bit 列成为额外 bias 通路；
  • centered 翻转：贡献不仅被删除，还反向施加。

优化器没有“该变量在外部生成器中无关”的语义信息。只要利用常数输入有助于降低训练 loss，它就可以承担阈值、门控和中间计算。

3. 反事实剂量响应

Warm 严格成功的最小 k（要求8/8 seed）

编码 规则 固定bit 最小k
binary 30 0 1
binary 110 0 1
binary 30 1 未在512内达到
binary 110 1 未在512内达到
centered 30 0/1 未在512内达到
centered 110 0 未在512内达到
centered 110 1 512

binary 固定0时，仅1个反事实样本（占原训练集约0.049%）即可使两条规则8/8 seed 严格不变。但困难方向并不呈现同样的一例补全；许多条件到512个样本仍仅6/8或7/8严格成功。

Cold 对照

cold 在 binary 固定0时k=0已经严格成功；binary 固定1通常需k=64；centered 多数条件需k=64，个别需512。warm 没有一致地以更少样本达到相同成功率，所以本实验不支持“预训练主体表示普遍带来强样本效率优势”这一强结论。

4. 阶段裁决

可以声称：

  1. 训练集未约束的反事实分支会形成结构化延拓，而非自动保持随机；
  2. 语义无关不等于训练中不参与计算；
  3. 常数编码和网络 bias 结构会系统改变 off-support 函数；
  4. 少量反事实证据在部分协议中能迅速补全严格不变性；
  5. 神经网络直接优化训练目标，泛化与语义不变性只有在数据和归纳偏置对齐时才作为副作用出现。

不能声称：

  • SGD/Adam 会自动删除所有无关变量；
  • 一个反事实样本普遍足够；
  • warm 总比 cold 样本效率高；
  • 结果证明人类语义上的最低 Kolmogorov complexity 程序被找到；
  • 任何 off-support 失败都能笼统归入“动力学”而不再接受证伪。

5. 对总体框架的修正

本实验把理论从

训练会恢复语义上最短的真实程序

修正为

架构、编码、数据与优化器共同定义训练loss几何；
网络在该协议中选择低loss实现，外部语义不是额外目标。

这也是后续 loss-resolved 体积框架以L_D而非 validation 或 teacher rule 为原始对象的直接来源。
