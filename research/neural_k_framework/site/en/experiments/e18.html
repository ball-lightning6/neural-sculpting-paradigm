E18 · Experiment details

E18: Teacher-Free Consensus and Symbolic Readability

Test whether training sets that induce near-deterministic complete-function agreement also induce short human-readable symbolic rules.

Scripts
experiment_8bit_consensus_large_scale.pyexperiment_8bit_consensus_symbolicity.pyexperiment_8bit_consensus_width_intervention.py

Experiment overview

Purpose

E18 searches, on teacher-free random partial truth tables whose data-generating rule is unknown, for full functions that contract to high consensus across initializations, and audits whether these functions belong to a human-readable low-complexity symbolic family; it then runs a cross-capacity check, sample interventions, and a large-scale recheck over 8,192 datasets.

Why this experiment was run, and how it was judged

1. Conjecture

Agreement does not depend on a researcher-specified teacher. If a partial training set makes many independent initializations contract to almost the same full function, does that usually mean that the version space contains a short rule that the network prefers and that is human-readable? A counterexample would be high consensus + cannot be compressed by the pre-registered symbolic language.

2. Pilot

  • Full 8-bit input space of 256 points;
  • 540 datasets: 512 random balanced partial truth tables and 28 hidden symbolic teachers;
  • 64 seeds per dataset, 8 -> 16 x 2 -> 1 tanh, 20,000 steps;
  • High consensus requires a fit rate no lower than 0.95, a modal full-function mass no lower than 0.95, and a full-function collision no lower than 0.90.

The symbolic audit pre-registers essential variables, ANF, decision tree, ROBDD, and influence; it does not judge by natural language alone after seeing the candidates.

3. Intervention and large-scale confirmation

  • To teacher-free high-consensus sets, add a high-disagreement input labeled consistently with the canonical function, a conflicting label at the same input, and a low-disagreement input labeled consistently with the canonical function; "consistent" here refers to the label agreeing with the canonical function, not unanimous ensemble predictions;
  • Sweep widths 16--1024, depths, and tanh/GELU;
  • A large-scale scan of 8,192 new random n=12 training sets, screened with 64 seeds and confirmed with 4,096 fresh seeds;
  • The pre-registered Tier audit and the post-hoc linear-threshold LP audit are strictly kept in separate columns.

4. Limits

High consensus only defines function condensation and does not guarantee external correctness; symbolic complexity must be compared among the candidates compatible with the training set. The experiment tests the one-way proposition high consensus -> low readable complexity and does not test its converse.

Results, interpretation, and limits

1. Pilot finds teacher-free high-consensus readable rules

Of the 540 datasets, 4 reach strict high consensus: copy, NOT, majority3, and one random balanced n=12 training set. In that random set, 61/64 seeds contract to the same full 256-bit function, with collision 0.908; the training set is already fully fit by step 200, and the modal mass then rises from 0.281 to 0.953, which is post-interpolation function contraction.

The main mode depends on only 4 variables and can be written as a short 2-CNF or a signed-threshold-style rule; the exhaustive audit shows that no 0--3-variable junta compatible with the current training set exists, so it attains the minimum essential-variable count.

Across all 512 random training sets, collision is significantly negatively correlated with essential variables, ANF, decision tree, ROBDD, and influence; the correlations persist after controlling for sample count and output balance, with ROBDD partial Spearman of about -0.526.

2. Cross-capacity and sample interventions

The canonical rule is the first mode in all six capacity/activation baselines, but the exact mass drops from 0.963 to 0.596, showing that the symbolic skeleton is relatively stable while the precise function cloud is highly protocol-dependent.

After adding one input with high prediction disagreement in the original ensemble and a label consistent with the canonical function, the canonical mass reaches 0.998--1.000 in five tanh settings; a large number of originally non-canonical paired seeds are causally transported to the canonical function. "Consistent" here means that the new label agrees with the canonical function, not that all model predictions agree. GELU is a clear exception, showing that information value still depends on the optimization protocol.

Although a low-disagreement sample labeled consistently with the canonical function is already hard-predicted correctly by every function in the base final state, retraining still significantly changes the exact distribution, proving that "applying zero-one conditioning on top of the final hard posterior" is not the training process. After a conflicting label excludes the canonical function, none of the six architectures chooses "the canonical function flipped only at that point"; instead they form broad protocol-dependent function clouds.

3. Large-scale results

From 8,192 random training sets, 120 loose candidates are screened out; confirmation with fresh 4,096 seeds yields 46 strict high consensus. The pre-registered Tier distribution is 4/31/11/0, with no Tier-4 candidate. The post-hoc LP audit finds:

  • 46/46 strict high-consensus functions are linear threshold functions;
  • 46/46 have equal-absolute-value weights;
  • 120/120 loose candidates are all linearly separable, and 119/120 belong to the equal-weight signed-threshold family.

Tier-3 is not a complex counterexample; rather, the pre-registered language missed the standard signed-cardinality threshold.

4. Verdict

E18 does not prove that all neural high-consensus functions are human-readable, but it provides strong teacher-free positive evidence: in this 8-bit MLP protocol, high full-function consensus systematically corresponds to short symbolic rules among the candidates compatible with the training set; neural complexity and human symbolic complexity are significantly aligned at least on this natural rule family.

The results do not support the converse, nor do they support the claim that high consensus necessarily holds across arbitrary architectures. The unified identification of the threshold family is a post-hoc finding and must be reported separately from the pre-registered zero-Tier-4 result.
