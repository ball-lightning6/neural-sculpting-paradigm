E16: Parity Reachability, Half-Space Generalization, and Scaffold Recovery

Separate intrinsic low-loss parity preference from global optimization barriers and holdout-symmetry artifacts.

Scripts
experiment_parity12_half_space_generalization.pyexperiment_parity16_scaffold_perturb_recovery.pyexperiment_parity_leave_one_out_dimension_scan.py

Experiment overview

Objective

E16 distinguishes the following through four layers of intervention — leave-one-out, random half-space, error-point reveal, and prefix scaffold:

  1. whether parity exists and is supported by the endpoint loss;
  2. whether random initialization can enter its low-loss region;
  3. whether an exact solution that has been reached remains stable after the auxiliary information is removed;
  4. whether, after a strong perturbation destroys the hard function, it can be recovered using only the endpoint loss.

Why this experiment was run, and how it was judged

1. Initial ambiguity

High-dimensional parity, when trained from random initialization, often stalls on the ln2 plateau. This could mean:

  • the network cannot represent exact parity;
  • the low-loss region does not prefer parity;
  • the data gap makes another continuation more preferred;
  • the target exists and is locally stable, but ordinary gradients cannot see the global entrance.

Leave-one-out also deliberately breaks the symmetry of the input space, so a wrong prediction on the final held-out point cannot be directly interpreted as insufficient target volume.

2. Four-layer adjudication

  1. Dimension scan: n=4...16, training on the full truth table minus one stratified holdout;
  2. Random half-space: a 14-bit random, label-balanced 50% train / 50% test mask;
  3. Error reveal: five branches copied from the same parent weights — continue, random correct points, current error points, error replay, and full reveal;
  4. Scaffold recovery: a 16-bit network first predicts all prefix parities; after transferring the final head, all intermediate supervision is removed; then relative L2 perturbations of 0--0.2 are applied from the exact anchor, and recovery uses only endpoint BCE.

3. Common reference machine

GELU + LayerNorm with three hidden layers, AdamW at 1e-3, weight decay 0. The main networks for leave-one-out and half-space are width 64; the final scaffold adjudication uses width 256. The full input space is exhaustively enumerable in all cases.

4. Boundaries

  • Parity being short in human logical language does not mean it is easy to reach in the gradient language of this network;
  • the holdout position and the mask spectrum change optimization visibility;
  • high test accuracy does not equal the exact full function;
  • auxiliary supervision changes the path; after success it must be removed, and endpoint-only stability/recovery serves as the final criterion.

Results, interpretation, and limits

1. Leave-one-out: preference turnover happens first, accessibility collapse only later

bits leave-one-out models hard-exact of which complete parity interpretation
4 64/64 0/64 single-point flip dominant
6 64/64 26/64 mixed completions
8 64/64 57/64 parity dominant
10 64/64 45/64 parity dominant, with position effects
12 64/64 43/64 parity dominant, long-tail arrivals
14 22/64 10/22 accessibility dominates
16 1/64 1/1 single unstable escape; probability cannot be estimated

Looking only at internal holdouts, 8--12 bit gives 89/96, about 92.7%, completed to parity; the overall-table decline comes mainly from low Hamming-weight boundary points being oversampled. This withdraws the conjecture that "leave-one-out can never complete parity."

2. The 14-bit random half-space removes the main entrance barrier

All 64/64 half-space models fit the 8,192 training points; the final test accuracy has mean 99.935% and median 99.963%, but 0/64 recover the complete 16,384-point parity. With the full truth table as control, only 3/8 escape the plateau.

From step 500 to 2,000, train BCE falls from 0.678 to 0.00644, and test accuracy rises from 43.9% to 99.46%; after extremely low loss, the remaining 1--21 errors no longer disappear monotonically. The main difficulty is the global entrance; exact program recovery is a still finer layer.

3. Current error points carry extremely high information gain

Five branches copied from the 20,000-step parent model, with an average of 6.22 original errors:

intervention final mean total errors complete parity
continue training 6.50 0/64
same number of random correct points 6.55 0/64
precisely revealing the error points 3.38 23/64
error points with 25% replay 6.47 7/64
revealing the full test set 0.61 29/64

Precise samples almost clear the old errors, yet produce an average of 3.19 new errors; overly strong replay clears old errors while creating 6.47 new ones. The missing constraints determine which defects can survive; the optimizer determines whether the repair is a global reorganization or an error migration.

4. The 16-bit scaffold proves the endpoint exists and is locally recoverable

Width-256 reference machine:

  • direct endpoint-only: 0/8 exact, BCE about 0.693;
  • prefix scaffold with final head: 5/8 exact;
  • all auxiliary supervision removed, endpoint-only settle: 7/8 exact;
  • continued training without perturbation: 7/7 remain exact.

Four perturbations were made from each of the 7 anchors: at relative L2 radii 0.1 and 0.2, all 28/28 hard functions were destroyed; recovering for 5,000 steps using only endpoint BCE, the final counts that returned to exact were 23/28 and 21/28 respectively. A radius of 0.2 pushes the median BCE to 0.631, yet most models can still be recovered.

5. Causal verdict

Under this protocol, the main obstacle for 16-bit parity is global accessibility — entering the target region from random initialization — rather than insufficient representational capacity, the exact endpoint not being supported by the pure endpoint loss, or the absence of a basin of attraction near the target.

This requires the main theory to be explicitly conditioned on "the optimizer being able to enter the corresponding low-loss region." Low description length and a favorable local endpoint do not guarantee a global gradient entrance; decoupling/scaffolds can change the path without changing the final architecture and the endpoint function.
