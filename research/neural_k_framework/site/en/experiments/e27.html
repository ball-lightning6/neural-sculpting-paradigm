E27: Agreement Before and During Grokking

Determine whether seeds already share one stable wrong function after hard fit but before rule generalization.

Scripts
analyze_agreement_around_grokking.pyexperiment_mod97_matched_loss_function_distribution.py

Experiment overview

Purpose

To test whether, when the model has already fully fit the training set but has not yet grokked, different seeds share the same wrong function, or are still scattered on unseen inputs; and to measure how agreement changes with rule generalization.

Entry points

  • experiment_mod97_matched_loss_function_distribution.py
  • analyze_agreement_around_grokking.py

  • RESULTS_AND_CONCLUSION.md

The analysis script reads the original E15 trajectory.csv; no retraining is needed. The primary protocol computes pairwise seed agreement only on unseen Mod97 inputs at the current training fraction.

Why this experiment was run, and how it was judged

1. Competing explanations

The low validation accuracy before grokking could correspond to two completely different function populations:

  1. Different seeds have already stably formed the same wrong shortcut;
  2. Different seeds share only the same training-set memorization, while the residual errors on unseen inputs are still different from one another.

Ordinary average validation accuracy cannot distinguish between the two.

2. Frozen protocol

  • Hard fit: the first time all seeds' training accuracy is no lower than 0.999;
  • Primary agreement: pairwise seed agreement computed only on unseen inputs;
  • Grokking milestone: the first time average unseen accuracy reaches 0.90;
  • Also report the agreement baseline produced only by each seed independently answering the target correctly.

The full-domain agreement that includes training inputs serves only as a bias demonstration and cannot carry the primary judgment.

3. Judgment

If unseen agreement at hard fit is already close to 1, that supports a shared wrong function; if it is close to random and subsequently rises only together with unseen accuracy, that supports seed-specific residual errors being gradually replaced by the shared target.

Results, interpretation, and limits

1. Question

To test the following intuition: when the model has already memorized the training set but has not yet grokked, are the predictions of different seeds on unseen inputs still scattered; and only after grokking, does agreement approach 1 as the target rule is recovered?

This analysis does not retrain any model; it only reads the existing E15 trajectory.csv. E15 uses the Mod97 division task, multiple nested training fractions, and 32 paired seeds, and saves per-seed predictions and cross-seed agreement during training.

2. Pre-fixed protocol

  • Primary agreement: pairwise seed agreement computed only on unseen validation inputs at the current training fraction.
  • Hard fit: the first time all seeds' training accuracy is no lower than 0.999.
  • Grokking position: the first time average unseen accuracy reaches 0.90, used only as a descriptive milestone.
  • Accuracy baseline: if each seed gives the same correct label with probability $a$, and when wrong chooses independently and uniformly among the remaining 96 classes, then
$$ A_{\mathrm{base}}(a)=a^2+\frac{(1-a)^2}{96}. $$

This baseline is used to judge whether the growth of agreement exceeds what "each seed gradually answers the same target correctly" itself produces.

Full-domain agreement that includes training inputs cannot be used for the primary judgment. After hard fit, all seeds already agree on training inputs; if the training set covers 90% of the inputs, full-domain agreement is mechanically lifted to near 0.9 even if it is nearly random on unseen inputs.

3. Results

Training fraction Unseen agreement at hard fit Full-domain agreement at hard fit Final unseen accuracy Final unseen agreement
60% 0.033 0.613 0.028 0.027
70% 0.029 0.709 0.164 0.046
80% 0.027 0.805 0.520 0.273
90% 0.027 0.903 0.916 0.839

Random pairwise agreement for 97-class classification is about 0.010. At hard fit, the unseen agreement of all four training fractions is far from 1, only slightly above the random baseline; the high values of full-domain agreement mainly come from the already-memorized training inputs.

The 90% training condition actually crossed the preset 0.90 unseen-accuracy threshold. At the adjacent checkpoints just before and after the crossing:

  • unseen accuracy changed from about 0.900 to 0.901;
  • unseen agreement changed from about 0.809 to 0.811;
  • final unseen accuracy was about 0.916, with agreement about 0.839.

Agreement did not suddenly jump to 1 at some independent moment; it grew together with unseen accuracy. After entering the mid-to-late phase, the observed agreement almost perfectly tracks $A_{\mathrm{base}}(a)$; in other words, different seeds mainly share the correct target predictions, while the remaining errors are mostly seed-specific.

There is a brief agreement peak early in training, but at that point accuracy is still close to random, reflecting that multiple seeds share some simple but wrong output bias. This peak subsequently fades and cannot be interpreted as rule convergence.

4. Verdict

The existing E15 results support the core intuition raised by the user:

When the training set has been fully fit but rule generalization has not yet occurred, unseen-input agreement is not close to 1; as grokking recovers the shared target rule, agreement rises toward 1.

Two qualifications need to be added:

  1. The rise of agreement is not a second phase transition independent of generalization accuracy; in the current experiment, it is mainly explained by different seeds simultaneously recovering the correct labels.
  2. "Approaching 1 after grokking" requires each seed's unseen accuracy itself to approach 1. The 90% condition of E15 did not fully generalize in the end, so agreement also stops at a position below 1.

Another important result is that the ensemble modal function can become the target function before single-seed high accuracy and high agreement: different seeds already share the target skeleton, but each still carries different residual errors. Therefore full function mass, modal function, unseen accuracy, and agreement still need to be reported separately.

5. Scope

E15 reproduces the classic Mod97 division task, but uses an MLP, no weight decay, and higher training fractions; it is not an item-by-item replica of the original two-layer Transformer protocol of Power et al. It already directly answers the agreement intuition in a function ensemble; an original Transformer replication can serve as a confirmatory external control, rather than a necessary prerequisite for establishing the phenomenon.
