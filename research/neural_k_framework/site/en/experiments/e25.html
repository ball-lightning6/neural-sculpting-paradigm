E25: MNIST Sample Complexity and Static Branch Prediction

Move the static-volume framework from enumerable Boolean maps to real images and test whether it predicts labels and validation-NLL turning points.

Scripts
experiment_mnist_loss_calibration.pyexperiment_mnist_static_branch_prediction.py

Experiment overview

Purpose

E25 ports the Boolean truth table method to real images. Stage 0 first calibrates the minimal training set and the overfitting loss range on two binary classification tasks; after freezing the conditions, Stage 1 compares the static mass of the two label branches for each unseen image within the same training-loss parent, and examines its prediction accuracy, the NLL U-shape, and the position of the SGD turning point.

Why this experiment was run, and how it was judged

1. From rule tables to real inputs

For an unseen sample x, the framework's direct prediction does not first train an additional classifier, but instead compares, within the same L_D<=epsilon static parent:

$$ P_{hard}(y\mid x,D,\epsilon) =\frac{\mu\{L_D\le\epsilon,h_\theta(x)=y\}} {\mu\{L_D\le\epsilon\}}. $$

The soft version adds a Bernoulli likelihood inside the parent; -log P_soft(y) is the single-sample free-energy increment. Both choose the label with the larger remaining parameter mass.

2. Stage 0 calibration

  • Tasks: MNIST 0 vs 1 and 3 vs 8;
  • Input: 28x28 average-pooled to 7x7 and mapped to [-1,1];
  • Network: 49 -> 32 -> 1 tanh, 1,633 parameters;
  • n=4 to 512, four datasets x eight seeds, 15,000 steps;
  • Measured train/validation BCE, hard accuracy, agreement, and the U-shape turning point.

Stage 0 is allowed to use validation to select the two contrast tasks, the minimal n, and the loss grid to cover; what follows is therefore a "calibrate-then-freeze" confirmation, not a fully blind prediction on a new task.

3. Stage 1 freezing

Froze 0/1,n=4,dataset0 and 3/8,n=4,dataset0, together with nine train raw-BCE sections 0.6...4e-5. Each condition used Gaussian-pCN SMC with 6 replicas x 4,096 particles. For each section, the validation/test predictions were first written to an unscored file and their SHA256 computed, and only then were the labels read for scoring.

Main verdicts:

  1. Whether the static branch predicts real MNIST significantly above chance;
  2. Whether the static soft NLL forms a U-shape on its own;
  3. Whether its lowest interval aligns with the matched-loss SGD validation turning point;
  4. Whether the low-loss volume difference between the two tasks points in the same direction as the minimal sufficient sample size.

Results, interpretation, and limits

1. Task difference at four samples

In Stage 0, checkpoints were selected by the lowest validation BCE along each trajectory: for 0/1,n=4, the median validation accuracy was 96.74% and test 98.31%; for 3/8,n=4, only 70.44%/69.66%. Under the operational threshold of median best-validation of at least 95%, 0/1 already crossed it at n=4, while 3/8 crossed it only at n=512.

Identical input dimension, network, sample count, and training budget therefore correspond to a roughly 128-fold difference in sample-identification scale.

2. Static volume predicts real images

All nine Stage 1 loss sections completed. Test static hard accuracy from shallow to deep is roughly:

0 vs 1: 92.97% -> peak 96.35% -> 96.09%
3 vs 8: 76.69% -> peak 78.13% -> 78.13%

With only four training samples, both tasks are already clearly above chance at epsilon=0.6; going deeper in loss overall improves the hard prediction, but not monotonically throughout. The static distribution also differs markedly from matched-loss AdamW, especially on 3/8 at shallow sections, where the static accuracy is about 76.7% versus about 60% for SGD.

3. Static geometry reconstructs the NLL U-shape

For 0/1, the test and validation soft NLL are lowest near epsilon=0.0006; the SGD validation minimum on the same fixed training set corresponds to a train BCE of about 1.46e-4, one preregistered grid interval away. For 3/8, the test minimum is at 0.01 and the validation minimum at 0.03; the SGD minimum corresponds to a train BCE of about 0.0455, landing directly in the adjacent interval.

The classical validation-loss U-shape therefore has at least one static geometric source that precedes the optimizer. Because Stage 0 participated in selecting the tasks and the loss coverage, this is not yet a fully blind prediction of the turning-point position for a brand-new digit pair.

4. Agreement, accuracy, and calibration decouple

Hard point collision increases as loss deepens: 0/1 rises from 0.595 to 0.979, and 3/8 from 0.542 to 0.922. But on 3/8 the contraction continues after accuracy stalls around 78%. On persistently mispredicted samples, the soft branch mass of the true label keeps decreasing past the NLL optimum, which explains why hard accuracy stays nearly unchanged while NLL rises: a small amount of boundary correction and inflated confidence on errors can happen at the same time.

5. The volume gap aligns with sample complexity

The median parameter-mass deficit of 3/8 relative to 0/1 grows from 0.56 decimal orders of magnitude at epsilon=0.6 to 55.43 orders of magnitude at epsilon=4e-5; this points in the same direction as the 95% identification threshold n=512 vs n=4. It constitutes a triangulation among the Neural K-profile, real-image prediction, and the sample data transition.

6. Boundaries

  • Only two binary classification tasks, a tiny MLP, and one fixed n=4 dataset per task are covered;
  • The static soft branch is not a full Bayesian posterior predictive;
  • The deep-tail lineage shows degeneracy; high-precision single-sample odds still require more particles and repetitions;
  • The results show that static volume has first-order predictive power, while once again refuting the claim that "SGD unbiasedly samples the static posterior";
  • This experiment does not explain why this network language assigns 3/8 a smaller low-loss volume.
