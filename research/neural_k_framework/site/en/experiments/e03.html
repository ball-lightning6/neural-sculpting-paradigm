E03 · Experiment details

E03: Prior-Consistent Function Dynamics and Width Intervention

Measure complete-function motion without defining complexity from the same outcomes that the theory is meant to explain.

Scripts
experiment_boolean_function_posterior_dynamics.pyexperiment_boolean_posterior_width_scan.py

Experiment overview

Experiment composition

  • E03a: Starting from ordinary and prior-consistent initializations, track the full Boolean function distribution under 1/2/4-sample constraints up to 5,000 post-fit steps;
  • E03b: Using tanh networks of the same family as Oxford, scan width 16/32/64/128 to test whether the qualitative phenomena of E03a depend on the 1024×3 GELU+LayerNorm large network.

Why this experiment was run, and how it was judged

1. The circular-argument problem

The original plan attempted to construct hand-written DSL shortest lengths for the 256 Boolean functions and then test whether training migrates toward the lowest-complexity functions. That plan was deliberately abandoned because:

  1. DSL shortest length only represents an artificial reference language; it is not equal to the neural network's actual program complexity;
  2. Defining "neural complexity" by post-training function surprise and then using it to explain the same posterior would be circular;
  3. Metrics such as ANF, BDD, and DNF can serve as independent structural coordinates, but no single one suffices to impersonate the true K.

Therefore E03 neither measures K nor pre-labels the migration direction as "compression". It only answers a more basic factual question: once the training constraints are fixed, does optimization continue to systematically change the full function?

2. E03a design

  • 3-bit -> 1-bit, all 256 hard functions;
  • Network: 3 -> 1024 x 3 -> 1, GELU+LayerNorm, Adam, weight_decay=0;
  • prior: 65,536 initialized networks;
  • Three partial training sets: 1, 2, and 4 samples, leaving 128, 64, and 16 hard-compatible functions respectively;
  • ordinary cohort: 128 ordinary initializations per condition;
  • prior-consistent cohort: 512 networks per condition that already satisfy all training labels at initialization;
  • post-fit ages: 0 to 5,000 steps, 13 cross-sections in total;
  • Save both hard function IDs and full logits;
  • The soft-likelihood temperature family serves only as a baseline, not as a post-hoc freely tunable interpreter.

Primary criteria: whether prior-consistent models change the full function when no new hard constraints are added, and whether ordinary models continue to migrate after the first fit.

3. E03b design

  • Same family as Oxford: 3 -> width x 2 -> 1 tanh, no normalization;
  • sigma_w=1, sigma_b=0.2, Adam, weight_decay=0;
  • width 16/32/64/128;
  • Reuse exactly the same three training constraints, prior/ordinary/consistent sample sizes, and ages as E03a;
  • width 128 serves as the same-family anchor; 1024×3 serves only as a cross-architecture behavioral reference and is not disguised as a pure width ablation.

4. Competing predictions

  • If the hard-conditioned prior is sufficient, the prior-consistent cohort should preserve its initial function distribution;
  • If optimization actively transports function mass, a single update can already produce function migration exceeding sampling noise;
  • If migration is only a special case of large networks/LayerNorm, it should significantly weaken or vanish in small tanh networks;
  • If the network protocol defines an effective reference language, the specific attracting functions and probabilities should change with architecture, even if the qualitative phenomenon of "still migrating post-fit" is preserved.

5. Pre-result boundaries

  • Kolmogorov complexity is not measured;
  • The posterior itself is not used to attach complexity labels to functions;
  • It is not predicted that the formula shortest to human eyes must win;
  • All main optimization remains Adam and cannot be automatically generalized to arbitrary optimizers;
  • An approximately stable aggregate distribution does not mean paired seeds lack substantial migration in opposite directions.

Results, interpretation, and limits

1. E03a: a single update rewrites the full function

The experiment is still 3-bit, not 4-bit; 65,536 is the number of prior networks, not the number of target functions trained. The three training sets leave 128, 64, and 16 compatible functions respectively, for a total of 3 × (128 ordinary + 512 prior-consistent) = 1,920 trained models.

The prior-consistent cohort already satisfies all hard labels before training, and its function distribution is consistent with the conditional prior. After only a single Adam update:

Condition Models that changed the full function Maximum function-mass change Post-training TV relative to hard prior
1-sample 72.7% 27.3% -> 100% 0.717
2-sample 99.0% 7.2% -> 77.3% 0.826
4-sample 97.9% 17.4% -> 39.3% 0.553

The corresponding finite-sample null p95 values are about 0.156, 0.132, and 0.058; the migration far exceeds sampling fluctuations.

2. The migration direction is not random, nor equal to the human-shortest formula

The two-sample training points are diagonal corners of the cube; after training, about 81% of the models concentrate on the symmetric maximum-margin threshold function:

majority(not x0, not x1, x2)

The four-sample condition mainly concentrates on:

x2 AND (not x1)
x2 OR  (not x1)

Shorter one-variable solutions x2 and not x1 exist abundantly in the initialization conditional prior, yet they are actively squeezed out by training. Therefore "shorter human Boolean formula" is not a sufficient explanation for the current network's choice; symmetry, margin, norm, and optimization geometry may all participate.

3. Substantial paired migration persists after the first fit

The ordinary cohort continues from the first fit to age 5,000:

  • Single-sample: 32.8% of seeds changed the full function;
  • Two-sample: 50.8%;
  • Four-sample: 47.7%.

The four-sample aggregate-distribution TV is only 0.125, yet 47.7% of seeds have switched functions, showing that migrations in opposite directions cancel out in the marginal histogram. Looking only at the "apparently stable" aggregate distribution would severely underestimate the dynamics.

The prior-consistent cohort still shows, at age 5,000:

  • Two-sample: 10.5% of models changed functions;
  • Four-sample: 27.0%.

4. E03b: migration is robust, but the specific posterior depends on the network family

The tanh width family

  • The initialization hard priors of width 16/32/64/128 are very close; the TV relative to 128 is about 0.025/0.023/0.022;
  • The final main modes of width 64 and 128 agree 6/6, with differences within bootstrap noise;
  • width 16 preserves the same migration direction but changes the concentration speed and the ranking of near-tied functions;
  • width 16 is not faster than 64: the six training blocks took about 122 s vs 119 s.

All widths preserve large-scale post-fit migration. For the width-16 prior-consistent cohort at age 5,000, the TV relative to its own hard prior is about 0.828/0.850/0.565 for single/k2/k4.

Comparison with the 1024×3 GELU+LayerNorm network

  • The initialization priors of the two network families already have a TV of about 0.29;
  • The specific dominant functions and probabilities differ significantly; all key comparisons exceed sampling noise;
  • The corresponding TVs of the 1024 network are about 0.717/0.840/0.471.

So the small network does not reproduce the large network's specific posterior, but "function mass is still transported at large scale after the training set is fit" is preserved across network families. Architecture affects both the prior and the dynamical attractors.

5. Stage verdict

Without using any K-complexity labels, E03 establishes:

  1. The hard-conditioned initialization prior is not the post-training function distribution;
  2. Initialization functions that are already hard-fit are massively rewritten by a single update;
  3. Paired function migration persists long after the fit;
  4. The migration direction is structured but depends on the network reference protocol;
  5. aggregate agreement/TV cannot substitute for per-seed function trajectories.

This experiment does not prove that migration is Kolmogorov compression, nor does it adjudicate "the broad hierarchy vs the lowest-complexity thin shell of Solomonoff's (1964) algorithmic probability". It provides circularity-free empirical facts that any subsequent complexity theory must explain.
