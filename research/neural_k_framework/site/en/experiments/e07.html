E07 · Experiment details

E07: Function-ID Wandering and Matched-Loss Static Controls

Observe post-fit movement between neighboring complete functions and test whether matching a scalar loss makes static and optimizer-induced distributions equal.

Scripts
experiment_function_id_wandering.pyexperiment_wandering_matched_loss_prior.py

Experiment overview

Purpose

E07 compares E06's static loss geometry against real optimizer transport inside exactly the same miniature protocol:

  1. directly record how the full function ID of each trajectory changes after the training set has been completely fitted;
  2. densely sample untrained weights for the same network and the same training set;
  3. compare the static function mass with the SGD function distribution when the mean normalized losses are approximately matched.

What it answers is not "whether the function moves", but "whether the tested static annealing baseline and the training endpoint give the same function distribution when their mean losses are approximately matched".

Why this experiment was run, and how it was judged

1. Question

E06 has already shown that static low-loss mass rearranges the full functions, but the four-sample condition also showed that static annealing cannot replace SGD. E07 therefore coarse-grains the function distribution into exactly trackable function IDs and directly measures:

  • whether a single model continues to cross function cells after the hard fit;
  • whether the migration is random jumping or concentrates into a few channels;
  • whether the multi-seed distribution tends to stabilize;
  • whether the tested static annealing baseline gives the same distribution when the mean losses are approximately matched.

2. Function-migration experiment

  • Task: 4-bit -> 1-bit, fully enumerable over the complete 16 points;
  • Training set: 6 fixed balanced samples, leaving 10 unseen inputs and 1,024 hard-compatible functions;
  • Network: 4 -> 16 x 3 -> 1 tanh;
  • Models: 1,024 independent seeds;
  • Optimization: full-batch Adam, learning rate 0.003, weight decay 0;
  • Alignment: aligned by the first step at which each trajectory reaches 100% hard accuracy on the training set;
  • Observation: 20,000 post-fit steps, with function IDs and partial logits saved densely.

The training labels were discovered afterwards to satisfy exactly y=x1. This was not a preregistered target, so the related rule interpretation serves only as a result audit and must not be disguised as something known at experiment-design time.

3. Matched-loss static control

The second script samples 4,194,304 untrained networks under exactly the same network and training set, first filters for hard-exact weights, and then compares them against SGD ages in two ways:

  1. raw BCE sublevel sets or exp(-beta L) reweighting;
  2. RMS-normalized BCE annealing, comparing the function-ID distributions when the static and SGD average normalized losses are approximately the same.

4. Criteria

  • number of function-ID transitions, Hamming distances, transition edges, and dwell times;
  • multi-seed function entropy, top-state mass, and agreement;
  • JS divergence between the static and SGD distributions;
  • static and dynamic odds of ID 666 and ID 722;
  • whether the tested static annealing baseline and the training endpoint give the same function distribution when their mean normalized losses are approximately matched.

5. Boundaries

  • width 16 is a high-density-trajectory pilot and does not carry cross-width generality;
  • the extremely low loss approaches the numerical scale of Adam eps=1e-8 and float32, so the late-stage re-expansion should be interpreted with caution;
  • the lower-right cumulative-transition subplot of wandering_overview.png erroneously uses the final total; citing it is forbidden;
  • the automatically generated normalized_loss_match_* in the original result bundle mistakenly used the raw SGD loss as the matching target; the normalized comparison in the main text must use the independent recomputation performed after the logits were saved;
  • approximately matching the mean normalized loss does not match per-model losses or the full loss distribution, and cannot rule out all Bayesian conditional distributions;
  • identical hard function IDs do not imply identical continuous logits, margins, or internal implementations.

Results, interpretation, and limits

1. Function-ID migration is not a random walk

All 1,024 trajectories fitted the training set, and 1,019 of them changed their full function at least once after the first fit:

  • 4,379 total transitions;
  • mean 4.28 transitions, median 4;
  • 90.9% of the transitions flipped only one unseen-input bit.

The function distribution contracts from an entropy of 5.217 bits, top mass of 12.1%, and agreement of 0.683 at first fit to an entropy of 1.291 bits, top ID 722 mass of 79.8%, and agreement of 0.945 at age 10,000. This is directed relaxation along neighboring function cells, not an unstructured random walk over the 1,024 compatible functions.

2. The shortest human rule differs from the network's attractor function

The six training labels happen, after the fact, to match y=x1, corresponding to ID 666. ID 666 is the most common at first fit, but the long-run dominant function becomes ID 722:

1[2*x0 + 4*x1 - 2*x2 + 2*x3 - 3 >= 0]

ID 722 deviates from x1 on only two unseen inputs and is also a linear threshold function. Only 81 of the 1,024 compatible functions are linearly separable, yet after age 10, 100% of the models lie in this family. The result shows that the network is strongly biased toward a narrow function family, but "simple" cannot be specified by human surface-formula length alone.

3. Late-stage re-expansion at extremely low loss

age mean loss top mass function entropy agreement
14,000 5.83e-8 81.2% 1.234 0.948
17,000 2.01e-8 85.8% 1.073 0.953
20,000 9.39e-9 77.1% 1.450 0.936

Therefore a decreasing loss does not guarantee a monotonically decreasing function entropy. However, this stage already approaches the Adam epsilon and float32 sensitivity region, and the network width is only 16; this document treats it only as a warning that "the strong claim of monotonicity throughout is unsafe", and does not propose a universal second phase transition on its basis.

4. With approximately matched mean normalized loss, the static and SGD distributions still differ

Of the 4.19 million untrained networks, only 25,935 are hard-exact, with a minimum raw BCE of 0.6061. SGD has already dropped to 0.6006 by age 2 and then rapidly enters a region that direct sampling of the initialization cannot cover at all. Therefore the raw loss cannot support a deep matched comparison.

After independently recomputing the normalized BCE, the static beta=128 case is comparable to SGD at age 20,000:

mean normalized BCE 0.2885 0.2903
function entropy 3.139 bits 1.450 bits
ID 666 mass 30.6% 2.9%
ID 722 mass 23.9% 77.1%
agreement 0.853 0.936

The static geometry is not uninformative: ID 722 rises from 0.94% under the hard prior to 23.9%, and is already identified as an advantaged candidate; but SGD further pushes it to 77.1% and suppresses the statically more favored ID 666. Even SGD at age 20 versus age 20,000, whose mean normalized losses are close, still have clearly different function distributions, consistent with history dependence.

5. Stage verdict

E07 supports:

The static loss geometry provides strong candidate structure for the optimizer, but on the same training set with approximately matched mean normalized loss, the tested static annealing baseline and the training endpoint still give markedly different function distributions; this is consistent with directed, history-dependent probability transport in real training.

What it rejects is the strong claim that "the tested static beta=128 annealing baseline equals the SGD function distribution at age 20,000". Only the mean normalized BCE is approximately matched here (0.2885/0.2903), not per-model losses or the full loss distribution, so this cannot rule out all Bayesian conditional distributions. The static baseline still identifies advantaged candidates, but sharing the same loss landscape does not guarantee equality with the optimizer's path-dependent distribution.

It cannot claim:

  • that the fine-grained attractor ordering at width 16 is invariant across architectures;
  • that the late-stage re-expansion is a universal physical phase transition;
  • that ID 722 has a lower machine-independent Kolmogorov complexity than x1;
  • that identical hard function IDs mean the internal program has stopped changing;
  • that a known conversion formula already exists between the static volume and the dynamic basin of attraction.
