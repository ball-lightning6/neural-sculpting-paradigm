E22 · Experiment details

E22: Per-Example Free Energy and an Information Invariant

Determine whether order-dependent per-example surprise sums to an order-independent complete-rule endpoint cost under one static measure.

Scripts
experiment_static_free_energy_information_invariant.py

Experiment overview

Purpose

E22 reframes the question "can the surprise of adding samples one at a time accumulate into rule difficulty" as a partition-function problem under a single static parameter measure. It exhaustively enumerates all partially labeled states of 3-bit inputs, all 256 complete rules, and all sample-addition orders, testing whether the step-by-step free-energy increments form a path-independent endpoint potential difference.

Run

python experiment_static_free_energy_information_invariant.py

Why this experiment was run, and how it was judged

1. Problem

Earlier per-sample experiments used committee disagreement on new labels to estimate information gain, but the single-step increment depends strongly on the sample order. Two objects must be distinguished: the surprise of each step may depend on the path, whereas the question is whether the cumulative cost of a complete rule admits an order invariant.

2. Static definition

Fix the network protocol and the reference measure mu. For a partially labeled state S, define the mass or partition function Z(S), and let

$$ F(S)=-\log_2 Z(S). $$

The generalized surprise of adding sample i is

$$ \Delta I(i\mid S)=F(S\cup\{i\})-F(S) =-\log_2\frac{Z(S\cup\{i\})}{Z(S)}. $$

If all states are defined by the same Z, then any addition order pi must satisfy

$$ \sum_t\Delta I(\pi_t\mid S_{t-1})=F(D_f)-F(\varnothing). $$

The single-step surprise and the stage averages may differ; the endpoint total must be identical. The Shapley average in turn gives a symmetric allocation of the endpoint cost to each sample.

3. Exhaustive protocol

  • Input space: 3 bit, 8 states in total;
  • Partially labeled states: each point can be unlabeled/0/1, 3^8=6,561 in total;
  • Complete rules: 256;
  • Sample orders per rule: 8!=40,320;
  • prior samples: 2,097,152 networks;
  • Compute both hard-conditioned and multiple Gibbs beta variants;
  • Also store the complete-rule microcanonical volume, for later alignment with subsequent SMC volume curves.

4. Decision boundaries

The path invariant itself is a telescoping identity on the same partition function and should not be packaged as a new law. What the experiment actually checks is numerical closure, the rule-level differences in endpoint cost under the network reference measure, and whether the earlier per-sample information intuition can be placed into a self-consistent static state function. It does not predict the step-by-step path of real SGD.

Results, interpretation, and limits

1. Numerical closure

All 2,097,152 prior samples, 6,561 partial states, 256 rules, and 40,320 orders per rule were completed.

max path-invariance error       = 2.84e-14 bit
max stage-decomposition error   = 1.42e-14 bit
max Shapley-efficiency error    = 5.68e-14 bit
hard predictive normalization  = 1.89e-15
beta=1 normalization error      = 6.10e-08

Therefore, the per-sample generalized surprise is indeed a difference of the same static potential function; different orders redistribute the cost of each step, but the total cost is strictly equal to the complete-rule endpoint free energy.

2. Rule150 remains the hard endpoint

Rule150 is 3-bit parity. Under the hard-conditioned variant, its complete-rule cost is about 29.0000007 bit, ranking hardest among the 256 rules; under the beta=1 Gibbs variant the cost is about 8.0625 bit, ranking second. This reproduces the direction of parity difficulty seen in the earlier per-sample heuristic, but the total no longer depends on the addition order.

3. Theoretical significance

E22 establishes a strict relationship among three objects:

  1. the predictive branch mass on the current training set;
  2. the generalized surprise of a new sample;
  3. the endpoint free energy or code length of a complete rule.

It provides a common language for the prequential coding of Blier and Ollivier (2018), Bayesian evidence, and the statistical-mechanics partition function of Levin, Tishby, and Solla (1989), and it also shows that agreement and surprise can be understood as two facets of function-ensemble condensation and free-energy increments.

4. Boundaries

  • The invariant belongs to a static reference measure; it does not imply that SGD is a Gibbs sampler;
  • The information content of each step still depends on the addition order; only the endpoint total and the Shapley average possess the corresponding invariance;
  • Endpoint difficulty depends on the network, parameterization, input encoding, loss, and reference measure; it is not a machine-independent K complexity;
  • The 3-bit exhaustion confirms the mathematical closure, but cannot by itself prove quantitative extrapolation to large networks.
