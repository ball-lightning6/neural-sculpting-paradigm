E06 · Experiment details

E06: Loss-Conditioned Prior Annealing

Measure whether continuous raw training loss reweights complete functions beyond hard label consistency.

Scripts
experiment_loss_conditioned_prior_annealing.py

Experiment overview

Purpose

This experiment directly measures, for the first time, whether — with the network, the initialization distribution, and the finite training set all fixed, and with all parameters already satisfying the same hard labels — further tightening the training-set raw BCE changes the relative parameter mass of complete functions.

It is the first static experiment in this paper's transition from a "hard-conditioned function prior" to "loss-resolved function volume". It simultaneously tests how much of the direction of real SGD can be explained by static low-loss mass, and whether the two can be equated.

Why this experiment was run, and how it was judged

1. The theoretical turn

Reaching 100% training-set hard accuracy does not mean the training loss is 0. The BCE can still decrease further, the logit margin can still keep growing, and E01--E04 had already shown that the complete function continues to change. The question was therefore raised at the time:

Among the same batch of simple and complex functions satisfying the hard constraints, do deeper continuous low-loss regions assign larger parameter mass to functions that are relatively economical for the architecture?

An important counterargument appeared immediately: both simple and complex functions can push the finite training-set loss arbitrarily low, so "a low-loss implementation of some class of functions exists" cannot by itself distinguish them. What needs to be compared is how the relative mass of the low-loss implementations of each function changes with the loss threshold under an explicit parameter measure — not merely whether a solution exists.

2. Competing predictions

H1: hard conditioning is already sufficient

After the same hard labels are satisfied, further lowering the continuous loss only changes the margin or the common logit scale; all compatible hard functions contract by approximately the same factor, and no stable reordering of the relative function mass occurs.

H2: loss-resolved static geometry

The parameter masses of different complete functions change at different rates as the training loss varies. A static low-loss cross-section can foreshadow part of the attraction direction of real SGD, but need not give the same strength.

H3: SGD equals static annealing

A stronger candidate explanation holds that the function distribution of real SGD at a given moment is approximately equal to the initialization measure truncated at the same loss threshold or reweighted by exp(-beta L). If, under equal conditions in the four-sample case, the static and SGD function rankings, masses, and transfer directions clearly separate, this equivalence fails.

3. Measurement targets

The experiment fixes the 3 -> 1024 x 3 -> 1 GELU+LayerNorm network and its initialization distribution, and fully enumerates the 256 hard functions on the 8 inputs. For each condition, it first keeps only the parameters whose hard predictions are entirely correct on the training points, and then applies two complementary measurements:

  1. Microcanonical sublevel sets: within the hard-exact samples, keep the 50% ... 0.1% with the lowest raw BCE;
  2. Canonical annealing: continuously reweight by exp(-beta L_D), and report the effective sample size ESS.

To exclude confounding by the overall logit scale, RMS-normalized BCE and fixed logit-scale subgroups are also reported. All losses are computed only on the finite training set D; the function ID is defined by the hard outputs on all 8 inputs.

The full run sampled 4,194,304 untrained networks. The four-sample hard-exact set still contained 365,248 of them, and the lowest 0.1% tail had 366 samples, meeting the preset reliability requirement.

5. Pre-declared boundaries

  • raw BCE simultaneously contains the hard function, the margin layout, and the overall logit scale;
  • Boolean formula length, ANF, Walsh, or influence are none of them ground truth for architecture-relative complexity;
  • the parameter "volume" always refers to probability mass under a given initialization distribution, not a coordinate-free raw volume;
  • this experiment does no training at all, so it cannot measure SGD inflow rates, escape rates, mixing, or dynamic stability;
  • the three training sets can only adjudicate the strong equivalence claim, and cannot establish a universal monotone law over all datasets.

Results, interpretation, and limits

1. Completeness

  • the full run sampled 4,194,304 untrained 1024x3 networks;
  • 255/256 hard functions were observed;
  • the GPU prior forward pass took 65.9 seconds;
  • the one-/two-/four-sample hard-exact counts were 2,096,325, 867,458, and 365,248 respectively;
  • the four-sample lowest 0.1% tail still had 366 samples.

2. One-sample: the raw effect is mainly driven by logit scale

From the hard-exact population to the lowest 0.1% raw BCE:

  • function entropy: 5.021 -> 1.098 bit;
  • constant-0 mass: 28.1% -> 86.4%;
  • agreement: 0.610 -> 0.946.

However, in the normalized and fixed-scale controls, the constant-0 mass decreases or reverses. Therefore this condition proves that the raw loss strongly reorders function mass, but cannot attribute this reordering entirely to pure hard-function geometry.

3. Two-sample: robust function selection after excluding scale

The main real-SGD attractor ID 113 can be written as:

majority(not x0, not x1, x2)

Its parameter mass is:

  • hard-exact static mass: 1.57%;
  • lowest 0.1% raw BCE: 23.0%;
  • lowest 0.1% normalized BCE: 50.7%;
  • lowest 0.5% fixed-scale: 44.1%.

Therefore, under the same hard constraints, the continuous loss does indeed strongly reorder the complete functions by a non-common factor, and the direction agrees with the function that real SGD later selects. ID 113 is not the shortest in ordinary AND/OR formula language, yet it is the symmetric linear threshold naturally expressed by the MLP — which simultaneously exposes the problem of architecture-relative complexity.

Real SGD once pushed ID 113 to 77.3% after one step, above the statically reliable range. The static geometry gives the direction, but does not fully give the optimizer transport strength.

4. Four-sample: static annealing and SGD cannot be equated

The total mass of the SGD attractors ID 48/243:

  • hard-exact: 21.4%;
  • raw intermediate low-loss region peaks at about 29.0%;
  • raw lowest 0.1% falls back to 23.0%;
  • the normalized lowest 0.1% still contains 48/366, about 13.11%; relative to hard-exact, these functions lose their advantage and mass shifts toward other functions, but their mass does not vanish.

The function entropy also does not decrease continuously: 3.715 bit at hard-exact, 3.724 bit at the raw lowest 0.1%, and 3.959 bit at the normalized lowest 0.1%. Yet real SGD pushed ID 48/243 to about 77.2% after one step.

Therefore the real SGD function distribution cannot be written as the static conditional distribution of the initialization measure on the same loss cross-section, nor as a simple equilibrium annealed ensemble.

5. Stage verdict and later corrections

E06 directly established the first static fact underlying the subsequent theory of this paper:

After the network, the parameter measure, the finite training set, and the hard constraints are fixed, further tightening the continuous training loss reorders the complete-function mass in a function-specific way; the separable picture in which a function constant multiplies a common loss factor does not hold.

It also established a second, hierarchical fact:

The static low-loss mass and the real multi-seed training distribution can be close in direction, but the real optimizer is a path-dependent pushforward of the initialization distribution, not an unbiased Bayesian sample of that static mass.

As of August 18, "lower loss generally increases the mass of simple functions" was retained as a high-confidence tendency; E06 by itself was not yet sufficient to elevate it to a law. The later full-truth SMC, the fixed-D measure closure, the volume-to-sample data transition, and the deep-tail crossing experiments replaced "simple" with the measurable Neural K-profile, and further proved that the ordering depends on the loss scale and can exhibit crossings.

The following cannot be claimed:

  • function entropy decreases monotonically with loss on every dataset;
  • the mass of any pre-specified "true function" increases monotonically with loss;
  • the raw BCE effects are all independent of logit scale;
  • SGD equals the static loss-conditioned posterior;
  • E06 has measured dynamic escape rates, stability, or Kolmogorov complexity.
