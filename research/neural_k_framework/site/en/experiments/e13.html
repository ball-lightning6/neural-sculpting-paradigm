E13 · Experiment details

E13: SGD Dynamics of the AND Shortcut and Balanced Intervention

Test whether static loss-stage reordering appears in actual optimizer trajectories and whether one sample causally changes the long-run function distribution.

Scripts
experiment_and_shortcut_sgd_dynamics.py

Experiment overview

Objective

E13 tests whether the static function reordering found in E12 also appears in real training, and uses a paired intervention with identical initialization and only a single training sample replaced to judge whether the data intervention can causally rewrite the function distribution within the observation budget. The replacement changes both coverage and the positive:negative label ratio (from 4:6 to 3:7), without isolating the coverage effect; finite long training also does not adjudicate the infinite-time endpoint.

Why this experiment was run, and how it was judged

1. Competing explanations

E12 found that the static low-loss region of the original AND, n=10 dataset is biased toward the F500/F550 shortcut. Possible explanations include:

  1. The static mass predicts that SGD enters the same shortcut family;
  2. The optimizer completely ignores this static structure;
  3. The initial seed predetermines the endpoint, independent of the data gap;
  4. Continued training eventually always recovers AND, and data insufficiency only affects speed.

2. Configuration

  • Network: 4 -> 64 x 3 -> 1 GELU+LayerNorm;
  • Full-batch AdamW, learning rate 1e-3, weight decay 0;
  • 2,048 seeds per condition;
  • Fully enumerated 16-point hard function;
  • The original-gap and minimal-balanced n=10 conditions use identical initialization seeds;
  • The release reproduction fixes 50,000 steps; the original archive is additionally extended to 127,458 steps to check plateau stability within the observation window.

The minimal intervention only does:

Remove 1101 -> 1
Add    1000 -> 0

The other 9 samples are unchanged; the positive:negative label ratio changes from 4:6 to 3:7. "Minimal balanced" refers to the adjustment of input-pattern coverage; the replacement does not separately isolate the effects of coverage and label ratio.

3. Criteria

  • The time at which the training set first reaches 100% hard-exact;
  • Mass trajectories of AND, F100, F500, F510, F550, and the single-point neighbors;
  • Mean number of unseen exceptions, function entropy, and agreement;
  • Sources of post-interpolation migration;
  • Stability of the distribution plateau after 50k;
  • Changes in the function and in the number of exceptions for the same seed before and after the data intervention.

4. Boundaries

  • The optimizer distribution should not be equated with the E12 static volume values;
  • The original data does not uniquely identify AND, so the long-run mixed plateau is not an internal definition of "having failed to learn the correct answer";
  • The 50k reproduction budget is used for the core pairing; 127,458 steps only test the original plateau's stability within that observation window and do not determine the infinite-time function distribution;
  • The small 4-bit space amplifies single-sample effects; cross-scale generality requires support from other experiments.

Results, interpretation, and limits

1. The original gap rapidly enters the shortcut family

In the first round, all 8,192 models across the four conditions fitted the training set around step 20. In the original n=10 condition:

step AND F100 F500 F510 F550 Mean exceptions
20 0.83% 10.94% 6.84% 26.71% 19.43% 2.870
100 0.63% 12.16% 8.45% 34.81% 22.71% 2.783
5,000 8.35% 22.41% 11.87% 21.24% 20.41% 2.300
20,000 21.19% 26.12% 11.33% 13.92% 12.55% 1.767

SGD reproduced the statically predicted shortcut family, but with different specific weights: F510 is the main winner early on, while F100 becomes first place after deep training. The static geometry identifies the candidate directions; the optimizer determines the intra-family transport.

2. Long training within the observation budget did not recover the unique AND

The original condition extended to 127,458 steps:

  • AND 22.51%;
  • F100 25.29%;
  • F550 14.21%;
  • Mean exceptions 1.771;
  • Function entropy about 2.83 bit;
  • Unseen accuracy about 70.5%.

After 50k all metrics enter a narrow plateau; from 100k to the end, 98.3% of the models keep an unchanged hard function. The loss still drops to 2.06e-9, but no continued contraction of the function distribution toward the unique AND is observed within this window. This only shows that continued training under the current protocol and the budget ending at 127,458 steps did not recover the unique AND. In general, the original training labels are insufficient to uniquely identify AND; that is a different question from a particular optimizer's infinite-time endpoint, which this experiment has not determined.

3. Replacing a single sample systematically changes the long-run distribution

Balanced condition at step 50,288:

AND             64.94%
D000            16.02%
F040             8.35%
F050             5.62%
Mean exceptions  0.450
Function entropy 1.711 bit
Unseen accuracy  92.50%

The network has already fully fitted the training set at step 20, at which point F050 is 42.58% and AND is 21.58%; subsequently F050 drops to 5.62% while AND rises to 64.94%. Of the final 1,330 AND models, 72.1% migrated from shortcuts after interpolation.

Compared seed-by-seed with the original condition up to 50k: for 69.97% of the seeds the number of exceptions decreased, for 21.73% it was unchanged, for 8.30% it increased, with a mean reduction of 1.337 error points. Among the original F100/F500/F510/F550 endpoints, the fractions that became AND after balancing are approximately 75.1%/66.4%/56.3%/52.8% respectively. The initialization did not fix the endpoint in advance.

4. Shared structure and differences between the static and dynamic pictures

The balanced static geometry already shows that medium loss first raises the relative advantage of F050 and deep loss then raises AND; SGD produces a stronger reordering along the same stage-wise direction. In the static lowest 0.2%, AND is 28.10%, whereas SGD ends at 64.94%, and the BCE reached in real training lies far below the coverage range of direct prior sampling.

5. Stage verdict

E13 establishes:

  1. The dominant function at lower loss reorders across training stages;
  2. Continued training after interpolation can transport probability mass from many-exception shortcuts toward fewer-exception rules;
  3. Under this protocol's underdetermined-data condition and observation budget ending at 127,458 steps, this compression manifests as a stable mixed plateau without convergence to the unique generator;
  4. Replacing only a single discriminative sample can causally change both the early shortcut and the end-of-observation distribution, but this replacement changes both coverage and the label ratio;
  5. The static loss geometry correlates with the SGD direction, but the optimizer is not a static sampler.

This directly refutes the claim that "the same predetermined simple function dominates along the entire loss axis," and it led the final theory to adopt the loss-resolved Neural K-profile rather than a single complexity ordering.
