E02 · Experiment details

E02: Rule-Bit Counterfactual Invariance

Determine whether a network automatically discards a control bit that is semantically irrelevant under the external rule but constant in training.

Scripts
experiment_rule_bit_invariance_completion.py

Experiment overview

Purpose

Test whether a fixed control bit is automatically recognized by the network as a semantically irrelevant variable, and how many counterfactual samples must be added before the two control branches strictly execute the same ECA rule. The experiment also distinguishes:

  • constant 0 versus constant 1 during training;
  • binary 0/1 versus centered -1/+1 encoding;
  • appending counterfactual samples after the rule has been learned (warm);
  • training the final data from scratch (cold);
  • continued training without adding counterfactual samples (k=0).

Why this experiment was run, and how it was judged

1. Background question

E01 showed that the optimizer is not a passive filter of a static hard prior, but this does not automatically imply that the network recovers the human-semantically shortest and cleanest program. In the old 31-bit experiment, training only ever presented one fixed rule bit; after flipping that bit, the output still broadly executed the learned rule, but was not strictly invariant.

This yields two competing explanations:

  1. Strong semantic-compression version: since the target rule is independent of the rule bit, training will automatically delete that variable;
  2. Training loss/parameterization version: the training set provides no counterfactual invariance, so the constant bit can participate in bias, gating, and representation; the network only needs to lower the visible training loss.

Here, the stipulation "the rule bit should be irrelevant" imposed by the external ECA generator is used only for counterfactual scoring. As far as the Stage 1 training set is concerned, every continuation that is correct on the fixed-bit branch fits the data equally well; merely because the researchers know the generation script, they cannot presume in advance that the strictly invariant function is the single true rule the network has already acquired.

2. Pre-experiment criteria

Invariance completion

If very few counterfactual samples make the flipped branch strictly equal to the original rule across all probes, while k=0 does not produce the same improvement, then data can complete the invariance at very small cost.

Representation reuse

If warm requires significantly fewer samples or steps than cold to reach the same strict success rate, then the learned body representation provides positive transfer for invariance completion. If there is no consistent advantage, representation reuse is not claimed.

Encoding/parameterization

If constant-0, constant-1, or binary versus centered results differ markedly, then semantic irrelevance is not a sufficient explanation, and network architecture and encoding must enter the theory.

3. Frozen protocol

  • Rule 30, Rule 110, one ECA step each;
  • Input: 1 rule bit + 30 state bits; output 30 bits;
  • 31 -> 1024 x 3 -> 30, GELU+LayerNorm;
  • 2,048 training states, 65,536 probes;
  • 8 seeds; Adam, learning rate 1e-3, batch 512;
  • dropout=0, weight_decay=0;
  • Stage 1 trains 8,000 steps with the rule bit fixed;
  • warm appends nested k=0,1,2,...,512 counterfactual samples and trains 5,000 steps;
  • cold trains the final data for 13,000 steps from the same initialization;
  • binary and centered encodings, with both directions of the fixed bit 0/1 swept.

4. Main measurements

  • bit accuracy and 30-bit exact accuracy on the original branch / flipped branch;
  • output agreement between the two branches;
  • hard strict success and the 8/8-seed strict success rate;
  • logit difference and the L2 norm of the rule-bit input column;
  • the minimum k at which warm/cold reach strict invariance.

5. Boundaries reserved in advance

  • The training objective does not contain the information of "true semantic irrelevance";
  • constant 1 may be unidentifiable from the bias, and a constant-0 input column may receive no gradient at all;
  • centered flipping is stronger than binary pathway deletion;
  • success only shows that the current protocol has an invariance-completion bias; it does not prove that any arbitrary network will automatically find irrelevant variables.

Results, interpretation, and limits

1. Stage 1: the original rule is fully learned, but the counterfactual branch still depends on the encoding

After 8,000 steps, all original rule-bit branches reach exact accuracy 1 on 65,536 probes. Median results after flipping the rule bit:

Encoding Rule Training fixed bit flip bit accuracy flip exact accuracy Strict-success seeds
binary 30 0 1.0000 1.0000 8/8
binary 30 1 0.99952 0.98561 0/8
binary 110 0 1.0000 1.0000 8/8
binary 110 1 0.79358 0.00151 0/8
centered 30 0 0.86071 0.01517 0/8
centered 30 1 0.85416 0.01137 0/8
centered 110 0 0.50286 0 0/8
centered 110 1 0.49822 0 0/8

For the same semantic task, merely changing the constant encoding moves counterfactual behavior from perfect invariance to near-random, directly refuting the strong version that "semantically irrelevant variables are necessarily deleted automatically".

2. Why all-0 and all-1 differ

The first layer can be written as

$$ h=W_xx+w_zz+b. $$
  • with binary fixed z=0: the w_z column receives no gradient in Stage 1;
  • with binary fixed z=1: the data only constrain w_z+b, and the rule-bit column becomes an extra bias pathway;
  • with centered flipping: the contribution is not only deleted but also applied in reverse.

The optimizer has no semantic information that "this variable is irrelevant in the external generator". As long as exploiting the constant input helps lower the training loss, it can serve thresholds, gating, and intermediate computation.

3. Counterfactual dose response

Minimum k for warm strict success (requiring 8/8 seeds)

Encoding Rule Fixed bit Minimum k
binary 30 0 1
binary 110 0 1
binary 30 1 not reached within 512
binary 110 1 not reached within 512
centered 30 0/1 not reached within 512
centered 110 0 not reached within 512
centered 110 1 512

With binary fixed 0, a single counterfactual sample (about 0.049% of the original training set) suffices to make both rules strictly invariant across 8/8 seeds. But the hard directions do not show the same one-example completion; many conditions still reach only 6/8 or 7/8 strict success at 512 samples.

Cold control

Cold already succeeds strictly at k=0 with binary fixed 0; with binary fixed 1 it usually needs k=64; most centered conditions need k=64, and a few need 512. Warm does not consistently reach the same success rate with fewer samples, so this experiment does not support the strong conclusion that "a pretrained body representation generally brings a strong sample-efficiency advantage".

4. Stage verdicts

What can be claimed:

  1. counterfactual branches unconstrained by the training set form structured continuations rather than automatically remaining random;
  2. semantic irrelevance does not mean non-participation in computation during training;
  3. constant encodings and the network bias structure systematically change the off-support function;
  4. a small amount of counterfactual evidence can rapidly complete strict invariance in some protocols;
  5. neural networks directly optimize the training objective; generalization and semantic invariance appear only as side effects when the data and the inductive bias are aligned.

What cannot be claimed:

  • SGD/Adam automatically deletes all irrelevant variables;
  • one counterfactual sample is universally sufficient;
  • warm is always more sample-efficient than cold;
  • the results prove that the program of minimal Kolmogorov complexity in human semantics was found;
  • any off-support failure can be lumped under "dynamics" and thereby exempted from falsification.

5. Revision to the overall framework

This experiment revises the theory from

training recovers the semantically shortest true program

to

architecture, encoding, data, and optimizer jointly define the training-loss geometry;
the network selects a low-loss implementation under this protocol, and external semantics is not an extra objective.

This is also the direct source of the later loss-resolved volume framework taking L_D — rather than validation or a teacher rule — as its primitive object.
