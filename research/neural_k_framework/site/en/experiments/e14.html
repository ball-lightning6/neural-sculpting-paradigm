E14: Weighted Rule-Bit Function Switching across Loss Scales

Construct an explicit dataset in which one fixed complete function is suppressed at shallow loss and rises only when rare constraints become unavoidable.

Scripts
experiment_weighted_rulebit_sgd.py

Experiment overview

Purpose

E14 artificially constructs a hierarchical constraint in which Rule110 is the majority and Rule30 the minority, so that at high loss it is most economical to ignore the minority branch, whereas at extremely low loss the full composite mapping must be satisfied. It directly tests whether the probability of a fixed hard function must be monotonic in loss.

Why this experiment was run, and how it was judged

1. Construction

The input contains one rule bit. Rule bit 0 corresponds to Rule110, and rule bit 1 corresponds to Rule30. The training objective is weighted according to:

Rule110 : Rule30 = 1, 10, 100, 1000, 10000

The minority Rule30 samples are still absolutely numerous enough to express the rule, but their contribution to a high weighted loss can be temporarily ignored by the majority branch.

2. Competing predictions

  • If the probability of a fixed hard function were monotonic in loss throughout, then Rule110-both should not first increase and then decrease;
  • If different loss depths activate different constraints, training should first optimize the majority branch, then correct the three conflicting neighborhoods bit by bit, and finally form the full composite mapping;
  • If the weight ratio only shifts the effective loss scale, then after normalization by the minority weight epsilon, the transitions at different ratios should collapse onto each other.

3. Configuration

  • 4 -> 64 x 3 -> 1 GELU+LayerNorm;
  • Plain full-batch SGD, learning rate 0.05, no momentum and no weight decay;
  • 512 paired seeds per ratio, 2,560 models in total;
  • Matched weighted raw-BCE first crossing;
  • Maximum run length 125,204 steps.

4. Boundary

This experiment deliberately uses sample weights to create a constraint takeover, demonstrating that non-monotonicity "can occur"; it does not claim that all natural datasets exhibit the same route. The full composite function is still enforced by a hard constraint at sufficiently low loss, so this cannot on its own be interpreted as evidence for an MDL endpoint.

Results, interpretation, and limits

1. The fixed hard function clearly rises first and then falls

The probability trajectory of Rule110-both=0x6E6E:

Rule110:Rule30 Peak Peak loss Full composite function takeover
10:1 25.78% 0.2 100% at 0.01
100:1 52.93% 0.05 100% at 0.001
1000:1 54.69% 0.005 100% at 0.0001
10000:1 51.76% 0.0005 100% of 501 at 0.00001

Same-seed transitions rule out replacement by a different seed population: for example, of the 280 Rule110-both models at the 1000:1 peak, 257 became full composite functions at deeper loss; the corresponding figure for 10000:1 is 260/260.

2. The transition is taken over step by step by three conflicting constraints

The majority branch first freezes to the Rule110 low byte 0x6E, and the minority branch then follows, in order:

0x6E -> {0x4E,0x2E} -> 0x0E -> 0x1E

correcting bit by bit the conflicts between Rule110 and Rule30 on 100, 101, 110. The transition is not a one-shot discovery of the full rule; rather, training constraints at different weight scales take over step by step as the loss deepens.

3. The weight ratio mainly shifts the loss scale

Let epsilon=1/(ratio+1); the transitions at 100:1, 1000:1, and 10000:1 approximately collapse in the loss/epsilon coordinate. The hard-function loss floor of Rule110-both satisfies:

$$ L_{floor}/\epsilon=(3/8)\ln2. $$

The final switch occurs precisely near this lower bound.

4. Training actively worsens the minority branch

Under the 10000:1 condition at step 500, the total weighted BCE had already fallen to 0.000979, yet the Rule30 branch BCE had risen from an initial 0.728 to 1.297; only later, as the total loss continued to decrease, did the Rule30 branch fall to 0.0145 and form the full mapping. The network has no external "full composite function" objective; it only optimizes the given weighted training loss.

5. Stage verdict

E14 directly refutes:

The relative probability of a fixed hard function across different loss regions is necessarily monotonic.

It supports: data weights and loss depth jointly determine the currently effective constraint; intermediate function mass can switch order in multiple stages, and training can even first move systematically away from the external full rule and then return. This result is a dynamical construction; it does not imply that the static volume has the same trajectory.
