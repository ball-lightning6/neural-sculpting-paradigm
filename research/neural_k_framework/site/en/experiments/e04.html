E04 · Experiment details

E04: Post-Fit Drift in the Mingard 2025 Boolean Protocol

Test whether first zero training error is the endpoint of function selection in a protocol used to support a static function-prior explanation.

Scripts
experiment_mingard_2025_postfit_drift.py

Experiment overview

Purpose

The Boolean experiments in Mingard et al. (2025), Deep Neural Networks Have an Inbuilt Occam's Razor stop when the model first reaches zero training classification error, and use that point to compare the initialization function prior, the complexity distribution, and the training endpoint. E04 keeps its core network, targets, initialization scales, and advSGD settings, and only extends the observation window to post-fit 100/1,000 steps, saving the complete 128-bit function of every trajectory.

Why this experiment was run, and how it was judged

1. Theoretical conflict

The static hard conditioning picture has no time variable after first interpolation. If the training set is unchanged, function odds should be determined by the fixed conditional prior. Grokking and E01/E03, however, show that functions can still migrate after interpolation.

Observing this directly on a self-designed tiny Boolean task could still be dismissed as protocol-specific, so E04 adopts the very Boolean setting that Mingard et al. (2025) themselves use to support the static interpretation, modifying only the stopping time.

2. Frozen settings

  • Inputs: 7 bit, the full 128 states;
  • Network: 7 -> 40 x 10 -> 1 tanh;
  • trainable biases initialized to 0;
  • sigma_w=1,8, scaled by fan-in;
  • the three paper targets, with LZ values 31.5/66.5/101.5;
  • training set size 64 per target;
  • Adam plus paper-style advSGD, batch 16;
  • 2,048 networks per condition, 6 conditions and 12,288 trajectories in total;
  • the training set of each network is independently resampled, but stays fixed within a single trajectory;
  • snapshots: initialization, first zero error, post-fit 100/1,000 steps;
  • prior: 262,144 untrained networks per initialization scale.

3. Criteria

Single-trajectory hard function migration

Record the complete function ID over the 128 inputs, and measure the fraction that changes post-fit together with the Hamming distance.

Distributional directional drift

Because the 2^128 function space is far larger than 2,048 seeds, per-function empirical TV would by itself be saturated by sparse sampling. We therefore additionally measure per-input prediction marginals, the full-space error-count distribution, and paired migration, and use a permutation null distribution to judge directionality. LZ is used only to reproduce the other side's metric and carries no complexity conclusion of this project.

Zero-error stable subset

Separately examine the models that maintain zero training-set error at both endpoints, to avoid miswriting a temporary departure from the interpolation set as "drift inside the interpolation set".

4. Competing predictions

  • Strong static picture: after first zero error there should be no systematic drift of function marginals;
  • Dynamic picture: with the training set unchanged, continuing to reduce the loss post-fit can still directionally move the function on unseen inputs;
  • if only LZ/mean error are examined without saving the complete function, the migration may be missed by coarse-grained metrics.

5. Pre-declared boundaries

  • the pilot averages over different training sets and does not directly equal the function posterior for a fixed single D;
  • the static importance sampling ESS at sigma_w=8 may be too low, so static posteriors must not be compared by force;
  • complete-function TV in an extremely sparse space must be accompanied by a null and cannot be interpreted alone;
  • the experiment tests only the training protocol and stopping rule used in the paper, and does not infer the authors' subsequent position.

Results, interpretation, and limits

1. Completeness

  • 2,048 trajectories for each of the 6 conditions; 12,288/12,288 all reached first fit and were recorded through post-fit 1,000;
  • main training about 145.9 s, prior sampling about 80.7 s, the complete cell about 4 min 20 s;
  • the slowest termination across the six conditions was about 1,770 steps, never hitting the 12,000-step cap;
  • the complete 128-bit functions, logits, training loss, and training-set agreement have all been saved.

2. The complete function keeps changing post-fit

From first zero error to age 1,000:

target sigma_w function-change rate mean Hamming distance/128 mean prediction-marginal drift marginal permutation p
low 1 59.96% 1.16 0.00529 0.00498
mid 1 87.74% 2.51 0.00407 0.00498
high 1 97.66% 4.03 0.00476 0.00498
low 8 99.66% 14.77 0.01467 0.00498
mid 8 99.80% 15.33 0.01387 0.00498
high 8 99.76% 15.37 0.01001 0.00498

Function migration is not an occasional one-or-two threshold flip. At sigma_w=8, about 15/128 unseen outputs change on average, and the per-input marginal drift of every condition exceeds the permutation null distribution. Keeping only the models that maintain zero training-set error at both endpoints leaves the qualitative conclusion unchanged.

3. The generalization direction depends on the protocol

At sigma_w=8, the mean full-space error of the three targets falls by about 1.81, 1.53, and 0.80 respectively; at sigma_w=1 the changes are +0.46, +0.11, and -0.03. Thus the post-fit migration is real, but it cannot be simply summarized as a monotonic improvement toward the external rule under every initialization scale and every target.

4. LZ is not a conclusion of this project

To align with the original paper, the result package keeps the LZ changes: sigma_w=8 broadly decreases, while the low-complexity target at sigma_w=1 instead rises by about 1.93. The direction is not uniform, and LZ is only a proxy of the 128-bit truth table. The core verdict of E04 rests entirely on complete-function migration and marginal drift, and does not use LZ to measure Kolmogorov complexity.

5. Reliability boundary of the static-posterior comparison

The prior importance ESS at sigma_w=1 is about 3,020--5,168, usable for static comparison; at sigma_w=8 it is only about 1.7--4.4 and is explicitly marked unreliable. E04 therefore does not use the latter to claim that "static posterior values are wrong", and instead uses only the post-fit time experiment, which requires no prior importance sampling.

6. Stage verdict

What can be claimed:

In the core Boolean protocol of Mingard et al. (2025), first zero training error is not the endpoint of function selection; continuing to optimize with the training set unchanged systematically migrates the complete hard function and its per-input marginals.

This directly refutes the strong version of "the first-interpolation snapshot already fully describes the subsequent function distribution", and also shows that the original paper's stopping time misses a time dimension with generalization significance.

What cannot be claimed:

  • that the initialization function prior has no predictive value;
  • that all six conditions contract monotonically toward the same complexity proxy;
  • that sparse empirical exact-function TV by itself reliably recovers the overall 2^128 distribution;
  • that the sigma_w=8 static importance posterior is interpretable;
  • that the results negate all Bayesian work or the authors' subsequent dynamics work;
  • that LZ is this project's measure of program complexity.
