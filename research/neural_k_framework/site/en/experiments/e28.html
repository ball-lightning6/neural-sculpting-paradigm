E28 · Experiment details

E28: Whole-Network HMC versus Adam on 50k MNIST

Test whether a finite-width static HMC ensemble can reach optimizer-level prediction quality on the full MNIST training set.

Scripts
experiment_mnist10_small_cnn_adam_same_protocol.pyexperiment_mnist10_small_cnn_full_hmc_demo.py

Experiment overview

Purpose

Test whether the full finite-width static HMC ensemble under a Gaussian reference measure can reach the predictive level of real Adam training on the full 50,000-sample MNIST ten-class task, and measure function agreement and residual inter-chain differences.

Why this experiment was run, and how it was judged

1. Question

The static volume in small Boolean tasks may merely be a toy phenomenon. E28 places the complete network parameters entirely into HMC, constructs a static function ensemble on 50,000 real images, and compares it with Adam using the same architecture, split, and initial function distribution.

2. Protocol

  • Network: Conv(1,4)->Conv(4,8)->Linear(392,10), 4,266 parameters;
  • HMC: 16 chains, beta=n=50,000, snapshots taken after 30 frozen step sizes, 480 samples in total;
  • Adam: 32 seeds, batch 256, 50 epochs;
  • Two kinds of Adam: plain and MAP with the corresponding Gaussian prior;
  • No data augmentation; validation/test labels do not participate in training or stopping.

3. Verdict

The primary question is whether static HMC can reach the same predictive magnitude as the real optimizer, rather than presupposing that HMC must win significantly. Member-count matching, per-sample paired errors, full function diversity, and within-chain/between-chain disagreement must also be reported. High accuracy does not automatically prove global MCMC mixing.

Results, interpretation, and limits

1. Predictive quality

Metric HMC plain Adam MAP Adam
ensemble test accuracy 99.03% 98.95% 98.82%
ensemble test NLL 0.03291 0.03415 0.03775
Single-parameter/single-seed mean accuracy 98.363% 98.180% 98.315%
train-test gap 0.442 pp 0.768 pp 0.466 pp
Mean function disagreement 0.01820 0.02049 0.01646

HMC and plain Adam differ on only 8 test samples. In the per-sample McNemar test, 19 images are correct only under HMC and 11 only under Adam, two-sided p=0.2005. This should therefore be stated as the same performance level, with HMC holding a slight but not significant numerical advantage.

2. Member count and time averaging

HMC has 480 parameter samples and Adam has 32 seeds. Splitting HMC into 15 mutually non-overlapping 32-member groups:

  • Mean 32-member HMC accuracy 99.012%;
  • Standard deviation 0.033 percentage points;
  • Range 98.96%--99.08%;
  • The Adam 32-seed ensemble is 98.95%.

All 15/15 HMC groups have hard-modal accuracy higher than plain Adam, but the advantage is only about 0.06 percentage points. When only the last 16-chain HMC snapshot is used, HMC is 98.93% and Adam is 98.95%, showing that the full HMC gain comes in part from posterior averaging across time.

3. Static ensemble condensation

The 480 HMC samples produce 480 distinct complete functions on the 10,000 test images, yet the pointwise mean agreement reaches 0.9877:

  • Agreement no lower than 0.99 covers 91.32% of the test set, with accuracy 99.989%;
  • Agreement equal to 1 covers 87.32%, with accuracy 99.989%.

High agreement is an extremely strong reliability signal, but not a logical guarantee: one test image is unanimously predicted incorrectly by all 480 samples.

Following the correct snapshot-major save order, the mean function disagreement within the same chain is 0.01190, and across chains 0.01860. Cross-chain remains systematically farther apart, so the results support high-quality prediction and function condensation, but do not prove that HMC has fully mixed over the global weight space.

4. Compute and interpretive boundaries

  • 50k HMC takes about 5,590 seconds;
  • All four Adam conditions take about 141 seconds in total, of which 50k plain Adam takes about 57 seconds;
  • HMC is a tool for measuring the static function ensemble, not a more practical training algorithm.

This experiment establishes: whole-network static HMC can reach 99.03% on the real 50k ten-class task, reaching the same level as real Adam with the same architecture.

This experiment does not establish:

  • HMC is generally better than Adam;
  • HMC has already mixed exactly at the global level;
  • The static distribution equals the optimizer's endpoint distribution;
  • The result has an exclusive accuracy advantage over NNGP or other kernels.
