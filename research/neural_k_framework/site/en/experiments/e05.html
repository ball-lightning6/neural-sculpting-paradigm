E05 · Experiment details

E05: Feature Learning When a Fixed NTK Is Already Sufficient

Separate the existence of a fixed-kernel solution from whether a finite network still reorganizes its features during end-to-end training.

Scripts
rule110_ntk_sufficient_feature_learning.py

Experiment overview

Purpose

This experiment tests an easily conflated proposition: if the fixed NTK at initialization of a matched architecture is already sufficient to learn one layer of Rule 110, will a finite-width network still change its empirical NTK, hidden representations, and ReLU gating when trained end-to-end?

The experiment does not attempt to prove that feature learning is a necessary condition for generalization. On the contrary, it separates two things: a fixed kernel being able to generalize does not mean a real network necessarily stays in the lazy regime; and feature learning occurring does not automatically mean extra generalization gains are obtained.

Why this experiment was run, and how it was judged

1. The question at the time

When reading Göring et al. (2025), Feature Learning Is Decoupled from Generalization in High Capacity Neural Networks, the research first accepted a conceptual distinction: large changes in representations or in the kernel do not imply that these changes necessarily improve generalization. It then posed the more direct reverse question:

If the fixed NTK at initialization is already sufficient to learn the rule, will a real finite-width network still undergo feature learning?

This distinguishes between two pictures: "feature learning is merely a patch applied when the fixed kernel is insufficient" and "feature learning is a form of representation transport that can appear independently while reducing the training objective".

2. Competing predictions

H1: Kernel sufficiency causes lazy staying

If the kernel at initialization already provides a zero-error rule solution, end-to-end training has no need to significantly change the normalized empirical NTK, the hidden-feature Gram, or the ReLU activation gating. After the network reaches full zero error on train/test, structural changes should be closer to numerical noise.

H2: Feature learning is separable from kernel sufficiency and generalization

The network only directly optimizes the training objective. Even if the fixed kernel can already generalize, the finite network may still reorganize its representations along the training loss; this change can happen after the full function is already correct, and need not be equivalent to extra generalization gains.

3. Three NTK objects that must be kept separate

  1. Analytic infinite-width NTK: the NTK proposed by Jacot, Gabriel, and Hongler (2018), recursed under the same three-hidden-layer He-ReLU parameterization, with KRR performed on 8,000 Rule 110 states and the full 30-bit outputs checked on 20,000 unseen states.
  2. Finite-width empirical NTK at initialization: the exact Jacobian Gram computed for a concrete initialization of 30 -> 1024 x 3 -> 30, with KRR performed separately on output bits 0, 15, and 29. It is only a finite-width sample of the infinite-width kernel and is not required to achieve exactly zero error.
  3. Multi-output block NTK during training: the three output bits and cross-output blocks tracked on a fixed 128-state probe, used to measure structural changes during end-to-end training.

The closed-form fast algorithm for the empirical NTK must first be compared against the per-parameter autograd Jacobian Gram on a tiny network; formal runs are allowed only after the error passes audit.

4. Formal configuration

  • Task: one-step update of the 30-bit one-dimensional cellular automaton Rule 110, outputting 30 bits;
  • Data: 8,000 training states and 20,000 fixed unseen states;
  • Network: 30 -> 1024 x 3 ReLU -> 30 without bias;
  • Seeds: 0, 1, 2;
  • Optimizer: Adam, learning rate 1e-3, weight decay 0;
  • Batch: 1,024; trained for 30,000 steps;
  • Loss: three trajectories each for BCE and MSE;
  • Snapshots: steps 0, 10, 30, 100, 300, 1,000, 3,000, 10,000, and 30,000.

MSE is a necessary control: it prevents pure scale changes caused by BCE continuing to grow logits/margins after zero classification error from being misjudged as feature learning.

5. Preregistered primary metrics

  • block_ntk_cka_to_init: centered CKA as systematized by Kornblith et al. (2019), comparing the empirical block NTK against initialization;
  • ck_cka_to_init: CKA of the hidden-activation Gram relative to initialization;
  • gate_flip_fraction_from_init: ReLU gate flip fraction on the fixed probe;
  • block_ntk_target_alignment and hidden CK target alignment: whether the changes have a task direction;
  • *_to_first_perfect: whether changes continue after the first time the training set and the 20,000 test set simultaneously reach zero error.

Looking only at the kernel norm does not constitute evidence. The core criterion is joint change in normalized CKA, gating, and task alignment; "continued change after full correctness" is reported separately as a stronger supplementary criterion.

6. Pre-declared boundaries

  • Zero error of the analytic infinite-width NTK and zero error of a particular width-1,024 empirical NTK are not the same proposition;
  • Feature learning does not automatically equal improved generalization, program compression, or redistribution of computational pressure;
  • This experiment only tests finite width, this parameterization, and this optimization protocol;
  • Overly sparse snapshots may register the true first fully-correct moment too late, causing the post-fit change to be underestimated.

Results, interpretation, and limits

1. Measurement audit and the fixed-kernel premise

The maximum absolute error between the fast empirical-NTK formula and the per-parameter autograd Jacobian Gram was 3.55e-15, and the maximum relative error was 2.72e-16.

The analytic infinite-width NTK matched to the three-hidden-layer ReLU network obtained, on 20,000 unseen states:

  • Zero errors across 600,000 output bits;
  • Zero exact errors across 20,000 full 30-bit outputs;
  • Both bit accuracy and exact accuracy at 100%.

The width-1,024 empirical NTK at initialization was evaluated only on output bits 0, 15, and 29. Across the three seeds, 220 of 180,000 predicted bits were wrong, for a mean bit accuracy of 99.8778%; the three-bit joint exact accuracies were 99.5800%, 99.7500%, and 99.5750%, respectively. Thus the finite-width empirical kernel is already close to the analytic limit, but it has not been smuggled into being strictly zero-error.

2. Structural change from initialization to the end

All six end-to-end trajectories eventually reached full 30-bit zero error on both the training set and the 20,000 test set. Three-seed averages:

Loss Hidden representation 1-CKA Block NTK 1-CKA ReLU gate flips Hidden representation target alignment
BCE 0.2400 0.01556 37.85% 0.1305 -> 0.2472
MSE 0.0920 0.00728 25.76% 0.1305 -> 0.1666

Under MSE there were still about a quarter of gates changed, clear hidden-representation CKA change, and stable task-alignment gains, so the results cannot be attributed solely to BCE growing margins without bound. The kernel norm under BCE did grow several-hundred-fold; under MSE the norm also grew about 3.7--5.1-fold, but the primary criterion uses normalized structural metrics.

3. After the full function is already correct

Five of the six trajectories passed the script's preset criterion of "CKA change and gate flips both exceeding 0.001". mse_seed2 did not pass the automatic Boolean decision, but from the registered first fully-correct snapshot to step 30,000 it still showed:

  • 1.145% of gates continuing to flip;
  • Block NTK 1-CKA=0.000169;
  • Hidden CK 1-CKA=0.000464.

This seed had only one exact error left at step 3,000, and the next snapshot jumped directly to full correctness at step 10,000, so the main changes after the true first fully-correct moment may fall in the unrecorded interval. The result should be written faithfully as "five trajectories crossed the preregistered double threshold; the sixth still had gate changes but its normalized kernel change was below threshold", and cannot be written as all six passing.

4. Phase verdict

What can be claimed:

The fixed infinite-width NTK of the matched architecture can already learn Rule 110 with zero error, but real finite-width networks still undergo task-related feature learning across seeds and across BCE/MSE during end-to-end training. Kernel sufficiency does not force the network to stay at the initialization kernel or in a lazy-training mechanism.

The result also supports a conceptual separation: the fixed NTK itself already generalizes, while the real network still changes its features, so "feature learning occurring" and "feature learning being necessary for generalization" are not the same proposition.

In the framework of this paper, feature learning is a mechanism by which the optimizer transports parameters and representations along the training objective; generalization depends on whether the low-loss mass defined by the training set and the protocol concentrates onto a common extension on unseen inputs. Therefore:

  • On structured and identifiable data, feature learning can appear together with generalization;
  • On under-constrained or randomly labeled data, representational change can also occur without producing rule generalization;
  • A suitable fixed kernel can generalize without any kernel change.

What cannot be claimed:

  • That the fixed NTK itself underwent feature learning;
  • That every width-1,024 empirical NTK at initialization was already fully zero-error;
  • That feature learning necessarily improves generalization;
  • That CKA or gate changes have already proven a decrease in program complexity;
  • That all six trajectories passed the post-fit preregistered double threshold.
