E09 · Experiment details

E09: Long Training with 80% Hidden Label Noise

Separate early learning of shared digit structure from later memorization of fixed incorrect labels.

Scripts
experiment_mnist_hidden_noise_long_training.py

Experiment overview

Purpose

This experiment separates two propositions that are often conflated:

  1. An MNIST training set with 80% wrong labels can still learn the true digit rule early in training;
  2. Whether the network still retains about 91% clean test accuracy after it has fully memorized the 80% wrong labels.

The experiment fixes a single label corruption, does not provide the noise identity to the network, and strictly separates the best-validation point, the first near-complete interpolation, and the long-training endpoint.

Why this experiment was run, and how it was judged

1. The disputed proposition

The related public claim is often paraphrased as: even with 80% of MNIST training labels wrong, a student network can still reach about 91% test accuracy. What really needs to be distinguished is: does that number appear early, when the model has only learned the 20% coherent signal, or at the interpolated end state after the wrong labels have already been fully memorized.

If it is the former, the phenomenon is merely "the strong shared signal is learned before noise memorization"; if it is the latter, it would require the optimizer to form a special decomposition in which training points are memorized locally while unseen inputs use the rule by default.

2. Experimental design

  • MNIST: 50,000 training, 10,000 clean validation, 10,000 clean test;
  • a fixed set of 40,000 corrupted training labels, with no noise marker added to the inputs;
  • clean/noise80 use elementwise-identical initialization and identical data order;
  • 3 seeds per architecture;
  • overparam_cnn: about 1,260,810 parameters;
  • hinton_small: about 23,603 parameters;
  • Adam, weight decay 0, at most 300 epochs.

3. Three frozen decision points

  1. best_validation: the early-stopping point selected by clean validation;
  2. first_interpolation: the first time noisy train accuracy reaches 99.99%;
  3. final: 40 epochs after interpolation, or the end of the 300-epoch budget.

Also recorded:

  • accuracy on the noisy training labels;
  • accuracy of the same training images relative to the hidden ground truth;
  • separate accuracies on the corrupted subset for the wrong labels and for the true labels;
  • clean validation/test accuracy;
  • agreement on test between the noise model and the paired clean model.

4. Pre-declared boundaries

  • If 99.99% noisy interpolation is not reached within 300 epochs, the experiment cannot adjudicate the fully interpolated end state;
  • clean validation is used for human model selection and is not part of the network's training objective;
  • fixed random label noise is a controlled amplification of non-reusable residuals and is not equivalent to all real-world data noise;
  • a drop in test accuracy only shows that the external ground truth has been corrupted; it does not mean the training objective has worsened.

Results, interpretation, and limits

1. The best-validation point reproduces the 91% phenomenon almost exactly

Architecture Best epoch Best test Noisy train at that time Corrupted subset fitting wrong labels Corrupted subset following ground truth
overparam CNN 4 91.890% 19.441% about 1.26% about 90.63%
Hinton small 5 93.893% 19.621% about 1.03% about 92.5%

The noisy train accuracy at the best point is about 19.5%, which is essentially the contribution of the 20% uncorrupted labels plus chance-correct guessing; the corrupted subset is still almost entirely following the true digit labels. The ~91% phenomenon therefore lies in an early stage where the rule has been learned but the noise has not yet been substantially memorized.

2. Continuing to reduce the noisy training loss destroys the rule

Architecture Final noisy train Final test Clean-control final test
overparam CNN 62.512% 22.793% about 99.29%
Hinton small 33.456% 32.423% about 99.25%

By epoch 300, the overparam model's accuracy on the corrupted subset is about 59.42% on the wrong labels and only about 11.47% on the true labels. Its test accuracy is 22.79%, almost exactly matching the 22.80% test agreement with the paired clean model. From epoch 5 onward, the correlation between noisy train accuracy and clean test accuracy is -0.941 for the large model and -0.980 for the small model.

The clean control trained for the same duration still maintains about 99.3%, ruling out "training time itself necessarily harms test performance". The harm comes from continuing to satisfy the fixed wrong training labels.

3. Rigorous boundaries

Neither architecture reaches 99.99% noisy interpolation within 300 epochs. Therefore one cannot claim that this experiment has measured "the final test accuracy after fully memorizing 80% noise". What can be robustly claimed is:

Long before noise fitting is complete, external rule performance has already dropped from about 92%--94% to about 23%--32%, and the entire 300-epoch trajectory shows no sign of late recovery.

4. Theoretical role

E09 amplifies ordinary overfitting into two clear stages:

reduce the loss of many samples simultaneously through shared structure
-> the shared signal is largely exhausted
-> continue reducing training loss through sample-level residuals
-> the overall function is continuously rewritten

It directly supports the statement "loss is the explicit objective, compression is a conditional path, and generalization is an external outcome". The network is given no oracle about which labels are ground truth and which are noise; clean validation is useful because the researcher re-injects the external semantics they actually care about into model selection.

This experiment also refutes any universal proposition of the form loss decreasing => external rule or program complexity continuously improving.
