# NTK批处理求解器 (NTK Batch Solver)

## 项目简介

本项目实现了基于神经正切核（NTK）理论的解析求解器，用于验证深度学习模型是否超越"懒惰学习"机制。

### 核心理论

本项目基于神经正切核（NTK）理论，通过计算**两层无限宽ReLU网络**的解析解，为深度学习任务设定了一个"懒惰学习精度基准"。

#### 为什么是懒惰学习的上限？

**1. 懒惰学习的核心特征**：NTK描述的是网络在初始化点附近的线性近似。在这一机制下，特征提取器（Hidden Features）近似**冻结**，模型主要通过线性组合初始随机特征来拟合数据。

**2. 无限宽度的代表性**：根据通用近似定理（Hornik, 1991），单层无限宽网络已具备拟合任何连续函数的能力。因此，单层NTK已拥有"理论上最完美的随机特征组合"。

**3. 深度与核退化**（理论严谨性补充）：
   - 理论上，多层网络在懒惰模式下拥有不同的核形式
   - 然而，研究表明（Hayou et al., 2019），随着层数增加，ReLU网络的NTK会逐渐发生**核退化（Kernel Degeneration）**，导致核函数变得越来越平滑且高度相关
   - 对于元胞自动机、XOR等对输入微扰极度敏感的**非平滑逻辑任务**，核函数的平滑化会导致捕捉逻辑跳变的能力**大幅下降**
   - 因此，**单层NTK实际上代表了ReLU系列核函数在保持局部逻辑敏感度方面的"性能高地"**

#### 推断逻辑

如果这个"完美的懒惰者"（单层NTK）在30,000样本下仅达1.4%精确匹配，而真实的4层网络训练后达到了100%，这表明：

- 多出的98.6%性能**难以通过深度堆叠单独解释**
- 可能来自于模型逃离固定核的限制，执行了主动的"特征雕刻"
- 这提供了**特征学习（Rich Training Regime）的实证支持**

### NTK解析公式

这是**懒惰学习的完整数学描述**，计算两层无限宽ReLU网络的核矩阵：

**核函数：**

```
K_σ(x, x') = (||x||·||x'||)/(2π) · [sin(θ) + (π - θ)cos(θ)]
K_dot(x, x') = (x·x')/(2π) · (π - θ)
Θ(x, x') = K_σ + K_dot

θ = arccos[(x·x')/(||x||·||x'||)]
```

**预测方程：**

```
α = (K_train + λI)^(-1) · Y_train
Y_pred = K_test · α
```

在NTK极限下，网络行为主要由这个**固定的核函数**决定，参数演化被近似冻结在初始值附近。**在懒惰学习机制下，模型的表现难以轻易超越这个解析解**。因此，这个公式的预测准确率可视为**懒惰学习的理论参考上限**。

### 1. ntk_batch_solver.py

- **用途:** 批处理NTK解析求解器
- **逻辑:** 一次性计算所有输出位，效率提升30倍；精确统计Exact Match（所有位同时正确）；GPU加速，支持大规模核矩阵计算

**关键参数:**

```python
DATA_PATH = "ca_rule110_layer3_30.jsonl"  # 数据集路径
N_TRAIN = 30000  # 训练样本数（最高支持5万）
N_TEST = 1000    # 测试样本数
LAMBDA = 1e-5    # 正则化系数（建议1e-5到1e-3）
BITS_TO_TEST = None  # None=测试所有位
```
